# CZON - AI ネイティブ Markdown コンテンツエンジン

- **C**: **C**ontent oriented | コンテンツは王様、コンテンツに集中
- **Z**: **Z**ero Configuration | ゼロ設定の執筆、邪魔を最小限に
- **O**: **O**rganic AI-Native | 有機的な AI ネイティブ、AI を深く統合
- **N**: **N**-shape Energy Curve | N 字型のエネルギーカーブ、作成-配信-フィードバックの各段階に介入

[> Web サイトデモ](https://czon.zccz14.com/)

AI 時代において、Web サイトコンテンツの作成者として、よりスマートなコンテンツ作成エンジンを活用できます。

**コンテンツの本質への回帰：最小限の干渉、執筆への集中**

ドキュメントの本質を取り戻し、執筆の静けさを取り戻しましょう。

その一、私は司書になりたくなりたい時もあります。何か内容を記録したいと思うこともあるけれど、タイトルはまだ決まっていなかったり、特別な構成がまだ固まっていなかったりすることもあります。LLM が自動的にタイトルを生成し、概要を作成し、分類し、ナビゲーションなどの整理作業をしてくれることを望みます。

その二、私の書斎はきれいにしておきたいです。複雑なビルドツールの設定費や、複雑なドキュメント構成に取り組みたくありません。複雑な構造が好きではありません。Docusaurus、VuePress、Astro などのツールの設定ファイルやプロジェクト構造を見るたびに、頭が痛くなります。今、CZON はすべての設定ファイルを .czon ディレクトリに隠すことを選び、隅に片付け、皆様は執筆コンテンツに集中するだけで、その他的一切は CZON が処理いたします。他のディレクトリはすべて皆様の執筆スペースであり、Markdown ファイルを自由に整理できます。

**母語への回帰：母語で執筆、スムーズな多言語バージョンの構築**

人生は短い、翻訳をするのは面倒です。人は母語を使用するときこそ、最も深い思考を発揮できます。しかし、同時に世界とつながりを保つことは必要であり、多言語での交流をあきらめたくありません。そこで、母語で執筆しながら、同時に より多くの人 に自分の内容を見てもらえるツールがあればと思います。現在の i18n では自分で翻訳する必要があるだけでなく、コンテンツの更新も自分で管理しなければならず、非常に面倒です。私は LLM を使用して翻訳を依頼することで、多くの時間を節約し、ワンボタンで多言語翻訳を完了できます。

## 基本機能

1. 🌍 **自動多言語翻訳**: AI を使用して差分翻訳を行い、ユーザーが母語で Markdown を記述できますが、複数言語に対応できます。
1. 💭 **自動概要抽出**: AI を使用して元のテキストを分析し、コンテンツを抽出します。
1. 🏷️ **自動タグ分類**: AI を使用してコンテンツからタグと分類を抽出・管理します。
1. 🧭 **スマート分類ナビゲーション**: AI を使用してサイトマップとナビゲーションを生成し、ソースファイルの位置は重要ではありません。

## 静的サイト生成 (SSG)

CZON には SSG 機能が組み込まれており、Markdown を含む git フォルダがあれば、静的な HTML サイトに変換できます。

⚠️ 注意: CZON は専門的な静的サイト生成器 (SSG) ではなく、AI 駆動の Markdown コンテンツエンジンであり、コンテンツの作成与管理に焦点を当てています。

✅ CZON はコンテンツの作成と公開のプロセスを簡素化し、複雑な設定やツールに惑わされることなく、ユーザーが執筆本身に集中できるようにすることを目的としています。

❌ CZON は複雑なテーマのカスタマイズやプラグインエコシステムを提供せず、AI を介してコンテンツの品質とアクセシビリティを向上させることに焦点を当てています。

🔔 しかし、CZON は依然として静的なサイトを生成できます。必要に応じて CZON をプリプロセッサとして使用し、他の SSG ソリューションと組み合わせて、パーソナライズされた美しいサイトを生成できます。

## クイックスタート

前提条件:

- [Node.js](https://nodejs.org/) がインストールされていること（バージョン 18 以上推奨、npx コマンドが必要）
- [OpenAI API Key](https://platform.openai.com/account/api-keys) を取得済みであること、または OPENAI 互換の API Key
- Git がインストールされていること（Git から Markdown ファイルを一覧表示し、.gitignore ルールのファイルを除外するため）

まず、Git で管理されているフォルダで作業します:

環境変数の構成

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # 必須: お使いの OpenAI API Key に置き換えてください
export OPENAI_BASE_URL="https://api.openai.com/v1"  # オプション: デフォルトでは OpenAI 公式 API を使用
export OPENAI_MODEL="gpt-3.5-turbo"  # オプション: デフォルトでは gpt-3.5-turbo モデルを使用
export OPENAI_MAX_TOKENS="4096"  # オプション: 最大トークン数を設定 (省略時はモデルのデフォルト値を使用、長文翻訳の場合はより高い値、例: 8192 を推奨、具体的な最大トークン数は使用するモデルに依存)
```

サイトを構築し、多言語翻訳をサポートします。現在のディレクトリをソースディレクトリとして使用し、`.czon/dist` ディレクトリに出力します。

- `--lang` パラメータを複数回使用して、生成する言語バージョンを指定できます（例: `--lang zh-Hans --lang en-US`）。
- ソース言語を設定する必要はなく、CZON が自動的に検出します。

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

**詳細パラメータやヘルプを表示**:

```bash
npx czon@latest
```
