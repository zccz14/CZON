# AI 分析レポート生成 - 基本ルール

## ドキュメント読み取りプロセス（厳密に遵守必須）

### 核心原則

このリポジトリには数百から数千の Markdown ファイルが含まれている可能性があります。あなたは**各ファイルを逐一読む**必要があり、スキップしてはいけません。
大量のファイルを処理するために、**段階的な読み取りと要約**戦略を採用します。

### 段階 1：完全なファイルリストの取得

1. `npx czon@latest ls-files` を実行してすべての Markdown ファイルを取得します
2. ファイル総数 N を記録します
3. ファイルリストを読み取り待ちキューとして保存します

### 段階 2：バッチ読み取りと要約

ファイルをバッチ処理します。1バッチあたり10〜20ファイルを推奨しますが、ファイルサイズや複雑さに応じて調整できます。

**各バッチについて：**

1.  **読み取り**：Read ツールを使用して、そのバッチの各ファイルの完全な内容を逐一読み取ります
2.  **抽出**：**現在のスタイルの関心点**（下記スタイルガイド参照）に基づいて、関連情報を抽出します
3.  **バッチ要約**：そのバッチから抽出した情報を構造化された要約として整理します
4.  **蓄積**：バッチ要約を「ナレッジベース」に統合します（ナレッジベースの構造は下記スタイルガイド参照）

### 段階 3：コンテキスト管理

コンテキストが制限に近づいた場合：

1.  **ナレッジベースの圧縮**：**現在のスタイルの圧縮戦略**（下記スタイルガイド参照）に基づいてナレッジベースを圧縮します
2.  **インデックスの保持**：どのように圧縮しても、すべてのファイルのパスとタイトルのインデックスは保持しなければなりません
3.  **読み取りの継続**：圧縮されたナレッジベースを使用して残りのファイルの処理を続けます

### 段階 4：完全性検証

レポート生成前に、以下を確認する必要があります：

1.  ファイルリスト内のすべての N 個のファイルが処理済みであること
2.  ナレッジベースに各ファイルの基本情報（少なくともパスとタイトル）が含まれていること

**見落としを発見した場合**：段階 2 に戻り、見落としたファイルを処理します。

### 段階 5：レポート生成

上記のすべての段階を完了した後にのみ、レポートの生成を開始できます。

### 禁止行為

- ❌ すべてのファイルを読み終える前にレポート生成を開始してはいけません
- ❌ ファイル数に関わらず、いかなるファイルもスキップしてはいけません
- ❌ 一部のファイルだけを読んで「全体像を把握した」と主張してはいけません
- ❌ ナレッジベースに存在しないファイルや内容を創作してはいけません

## 一般ルール

### 1. 事実に基づく原則

- 常に事実内容に基づくことを心がけ、事実から離れた状況を生み出してはいけません
- すべての見解は原文による裏付けがなければなりません
- 存在しない内容を創作してはいけません

### 2. 引用リンクの規範

- 原文リンクを引用する際は、リンクが有効であることを保証します
- **常に特定の Markdown ファイルにリンク**し、ディレクトリにはリンクしないでください
- **リンクテキストは対応するタイトル**とし、ファイル名にしてはいけません
- SUMMARY ディレクトリに生成されるため、参照時は `../` で始まる相対パスを使用します

**正しい例**：

```markdown
[資本持久戦：個人投資家が階級を超える戦略](../INSIGHTS/6.md)
[創作から配信へ——AIネイティブなコンテンツエンジンの構築](../INSIGHTS/4.md)
```

**誤った例**：

```markdown
[INSIGHTS/6.md](../INSIGHTS/6.md) ← ファイル名を使用しており、タイトルではありません
[資本持久戦](../INSIGHTS/) ← ディレクトリにリンクしています
```

### 3. ヘッダー形式

各レポートは以下の形式で始める必要があります：

```markdown
# [レポートタイトル]

**AI 分析日時**：YYYY年MM月DD日
**注**：本レポートは AI によって生成され、内容は参考情報です。

---
```

### 4. 時間的ウェイト

- 時間の経過を考慮し、より最近の記事に高いウェイトを与えます
- ただし、古い重要な内容を無視してはいけません

### 5. 出力先

- すべてのレポートは `SUMMARY/` ディレクトリに生成します
- ファイル名は指定された形式に従って命名します
