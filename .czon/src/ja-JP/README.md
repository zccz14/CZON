# CZON - AIネイティブ Markdown コンテンツエンジン

- **C**: **C**ontent oriented | コンテンツファースト、コンテンツに集中
- **Z**: **Z**ero Configuration | ゼロコンフィグレーション執筆、作業の妨げを最小化
- **O**: **O**rganic AI-Native | 有機的なAIネイティブ、AIを深く統合
- **N**: **N**-shaped Energy Curve | N字型エネルギー曲線、作成・配信・フィードバックの各段階に関与

AI時代において、ウェブサイトコンテンツクリエイターとして、私たちはよりスマートなコンテンツ作成エンジンを手に入れることができます。

**コンテンツへの回帰：最小限の妨げで、執筆に集中**

ドキュメントをその本質に戻し、執筆を静寂に帰します。

第一に、私は図書館司書になりたくありません。時々何かを書き留めたいと思うことがありますが、そのタイトルがまだ決まっていなかったり、特別な構成ができていなかったりすることがあります。LLMが自動的にタイトルを生成し、要約を作成し、分類し、ナビゲーションなどの整理作業を行ってくれることを望みます。

第二に、私の書斎はきれいに掃除されていなければなりません。複雑な設定のビルドツールや、複雑なドキュメント設定、複雑な構造をいじりたくありません。Docusaurus、VuePress、Astroといったツールの設定ファイルやプロジェクト構造を見るたびに、頭が痛くなります。現在、CZONはすべての設定を `.czon` ディレクトリに隠し、隅に追いやることを選択しました。ユーザーは執筆内容に集中するだけでよく、他のことはCZONが処理します。他のディレクトリはすべてあなたの執筆スペースであり、Markdownファイルを自由に整理することができます。

**母国語への回帰：母国語で執筆し、滑らかに多言語バージョンを構築**

人生は短いので、翻訳するのが面倒です。人は母国語を使用するとき、自身の思考の深みを最も発揮できます。しかし同時に、世界とつながりを保つことも必要であり、多言語でのコミュニケーションを諦めたくはありません。そこで、母国語で執筆しながら、より多くの人に私のコンテンツを見てもらえるツールを望みます。現在のi18nは自分で翻訳するだけでなく、コンテンツの更新も自分で管理しなければならず、非常に面倒です。私はLLMを使って翻訳を手伝ってもらうことを選択し、多くの時間を節約し、ワンクリックで複数の言語への翻訳を完了させることができます。

## ✨ コア機能

1. 🌍 **AI多言語翻訳**：AIを使用した差分翻訳により、ユーザーは母国語でMarkdownを記述できますが、ユーザーは多言語対応になります。
2. 📊 **AIメタデータ抽出**：タイトル、説明、要約、キーワード、ターゲット読者、URLフレンドリーなエイリアスなどを自動抽出します。
3. 🏷️ **AIタグ分類**：AIを使用してコンテンツのタグと分類を抽出・管理します。
4. 🧭 **AI分類ナビゲーション**：AIを使用してサイトマップとナビゲーションを生成します。ソースファイルの位置に依存しません。
5. 🤖 **AI全サイト要約**：複数のスタイルで全サイトの要約を生成できます。

および、いくつかの非AI機能：

1. ⚙️ **ゼロコンフィグレーション**：すべての設定とキャッシュは `.czon` ディレクトリに隠され、プロジェクト構造は整理された状態を保ちます。
2. 🔄 **差分ビルド**：コンテンツハッシュに基づいて変更を検出し、変更されたファイルのみを処理します。
3. 📚 **Markdown拡張サポート**：KaTeX数式、Mermaid図表、Emblaカルーセル、脚注などをネイティブサポートします。
4. 🚀 **静的サイト生成**：ReactベースのSSGを内蔵し、多言語静的サイトを生成します。
5. 🌐 **訪問者の言語に基づく自動ルーティング**：訪問者の言語に基づいて、対応する言語バージョンに自動的にルーティングします。

## 📦 クイックスタート

### 前提条件

- [Node.js](https://nodejs.org/) がインストールされていること（LTSバージョン24、またはバージョン18以上を推奨、npxコマンドが必要）
- [OpenAI API Key](https://platform.openai.com/account/api-keys) を取得済み、または OpenAI 互換の API Key を取得済み
- Git がインストールされていること（GitからMarkdownファイルをリストアップし、.gitignoreルールでフィルタリングされたファイルを無視するために使用）

### 環境変数の設定

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # 必須：ご自身のOpenAI API Keyに置き換えてください
export OPENAI_BASE_URL="https://api.openai.com/v1"  # オプション、デフォルトはOpenAI公式APIを使用
export OPENAI_MODEL="gpt-3.5-turbo"  # オプション、デフォルトは gpt-3.5-turbo モデルを使用
export OPENAI_MAX_TOKENS="4096"  # オプション、最大トークン数の制限を設定（省略した場合はモデルのデフォルト値を使用。長文翻訳の場合は、使用するモデルがサポートする最大トークン数に応じて、例えば8192などより高い値を設定することを推奨）

# OpenAI APIへのアクセスにHTTPプロキシが必要な場合は、以下の変数を設定できます
export HTTPS_PROXY="http://your-proxy.com:8080"  # オプション、HTTPSプロキシを設定
export HTTP_PROXY="http://your-proxy.com:8080"   # オプション、HTTPプロキシを設定
```

### 多言語サイトの構築

Gitで管理されている任意のフォルダで実行：

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

言語コードは静的サイト生成における多くの機能の一部として後続で使用されるため、BCP 47標準の言語コードを使用していることを確認してください。例えば、`zh-Hans` は簡体字中国語、`en-US` はアメリカ英語を表します。必要に応じて、`es-ES`（スペイン語）、`ja-JP`（日本語）、`ko-KR`（韓国語）など、さらに言語を追加できます。
標準的な言語コードのリストについては、[IETF language tag - Wikipedia](https://en.wikipedia.org/wiki/IETF_language_tag#List_of_common_primary_language_subtags) を参照してください。

出力ディレクトリ：`.czon/dist`。このディレクトリの内容を静的サイトホスティングプラットフォームにデプロイする必要があります。

詳細な使用方法については、`npx czon@latest --help` を実行してください。

## 🔗 他のツールとの比較

| 機能               | CZON                     | Docusaurus      | VuePress        | Astro           |
| ------------------ | ------------------------ | --------------- | --------------- | --------------- |
| **AIネイティブ**   | ✅ 深く統合              | ❌              | ❌              | ❌              |
| **ゼロコンフィグ** | ✅ 設定を隠蔽            | ❌ 設定ファイルが必要 | ❌ 設定ファイルが必要 | ❌ 設定ファイルが必要 |
| **多言語AI翻訳**   | ✅ 自動差分翻訳          | ❌ 手動翻訳     | ❌ 手動翻訳     | ❌ 手動翻訳     |
| **自動分類/タグ**  | ✅ AI抽出                | ❌ 手動設定     | ❌ 手動設定     | ❌ 手動設定     |
| **Markdown拡張**   | ✅ KaTeX, Mermaid, Embla | ✅ プラグイン経由 | ✅ プラグイン経由 | ✅ プラグイン経由 |
| **テーマカスタマイズ** | ❌ 限定的              | ✅ 豊富         | ✅ 豊富         | ✅ 豊富         |

CZONは、**AI拡張コンテンツエンジン**として位置づけられており、フル機能のSSGではありません。AIを通じてコンテンツ作成の効率を向上させることに焦点を当てており、コンテンツの質を重視し、設定の負担を減らしたいクリエイターに適しています。実際、CZONはDocusaurus、VuePress、AstroなどのSSGツールと組み合わせて、コンテンツ生成と管理のフロントエンジンとして使用することができます。
