# CZON - AIネイティブMarkdownコンテンツエンジン

- **C**: **C**ontent oriented | コンテンツを重視、コンテンツに集中
- **Z**: **Z**ero Configuration | ゼロコンフィグレーション執筆、煩わしさを軽減
- **O**: **O**rganic AI-Native | 有機的なAIネイティブ、AIとの深い統合
- **N**: **N**-shaped Energy Curve | N字型エネルギー曲線、創作-配信-フィードバックの各段階に関与

[> ウェブサイトデモ](https://czon.zccz14.com/)

AI時代において、ウェブサイトコンテンツクリエイターとして、よりスマートなコンテンツ作成エンジンを手に入れることができます。

**コンテンツへの回帰：最小限の煩わしさで、執筆に集中**

ドキュメントを本質に戻し、執筆を静寂に戻します。

第一に、私は図書館司書になりたくありません。時々何かを書き留めたいと思うことがありますが、タイトルがまだ決まっていなかったり、特別な組織化がまだできていなかったりすることがあります。LLMが自動的にタイトルを生成し、要約、分類、ナビゲーションなどの整理作業をしてくれることを望んでいます。

第二に、私の書斎はきれいに掃除されていなければなりません。複雑な設定ファイルやプロジェクト構造を見るたびに頭が痛くなるような、複雑なビルドツールの設定や複雑なドキュメント設定は望んでいません。現在、CZONはすべての設定を.czonディレクトリに隠し、隅に掃き出し、ユーザーは執筆内容に集中し、他のことはCZONに任せます。他のディレクトリはあなたの執筆スペースであり、Markdownファイルを自由に整理できます。

**母国語への回帰：母国語で執筆し、滑らかに多言語バージョンを構築**

人生は短いので、翻訳は面倒です。人は母国語を使用するとき、自身の思考の深さを最も発揮できます。しかし同時に世界とつながりを保つことも必要であり、多言語でのコミュニケーションを諦めたくはありません。そこで、母国語で執筆しながら、より多くの人々に私のコンテンツを見てもらえるツールを望んでいます。現在のi18nは自分で翻訳するだけでなく、コンテンツの更新も自分で管理しなければならず、非常に面倒です。私はLLMを使って翻訳を行うことを選択し、多くの時間を節約し、ワンクリックで複数言語の翻訳を完了できます。

## 基本機能

1. 🌍 **自動多言語翻訳**：AIを使用したインクリメンタル翻訳により、ユーザーは母国語でMarkdownを記述できますが、ユーザーは多言語対応になります。
2. 💭 **自動要約抽出**：AIを使用して元のテキストの内容分析と抽出を行います。
3. 🏷️ **自動タグ分類**：AIを使用してコンテンツのタグ付けと分類の抽出と管理を行います。
4. 🧭 **スマート分類ナビゲーション**：AIを使用してサイトマップとナビゲーションを生成し、ソースファイルの位置に依存しません。

## 静的サイト生成 (SSG)

CZONにはSSGソリューションが組み込まれており、Markdownを含む任意のgitフォルダを静的HTMLサイトに構築できます。

⚠️ ご注意：CZONは専門的な静的サイトジェネレーター（SSG）ではなく、AI駆動のMarkdownコンテンツエンジンであり、コンテンツ作成と管理に焦点を当てています。

✅ CZONはコンテンツ作成と公開のプロセスを簡素化し、ユーザーが複雑な設定やツールに悩まされることなく、執筆自体に集中できるようにすることを目的としています。

❌ CZONは複雑なテーマカスタマイズやプラグインエコシステムを提供せず、AIを通じてコンテンツの品質とアクセシビリティを向上させることに焦点を当てています。

🔔 ただし、CZONは依然として静的サイトを生成できます。必要に応じて、CZONをプリプロセッサとして使用し、他のSSGソリューションと統合して個性的で美しいサイトを生成できます。

## クイックスタート

前提条件:

- [Node.js](https://nodejs.org/)がインストールされていること（推奨バージョン18以上、npxコマンドが必要）
- [OpenAI API Key](https://platform.openai.com/account/api-keys)を取得していること、またはOpenAI互換のAPI Key
- Gitがインストールされていること（GitからMarkdownファイルをリストアップし、.gitignoreルールでフィルタリングされたファイルを無視するため）

まず、既にgitで管理されているフォルダで作業します：

環境変数の設定

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # 必須：OpenAI API Keyに置き換えてください
export OPENAI_BASE_URL="https://api.openai.com/v1"  # オプション、デフォルトはOpenAI公式APIを使用
export OPENAI_MODEL="gpt-3.5-turbo"  # オプション、デフォルトはgpt-3.5-turboモデルを使用
export OPENAI_MAX_TOKENS="4096"  # オプション、最大トークン数の制限を設定（省略するとモデルのデフォルト値を使用、長文翻訳の場合はより高い値（例：8192）を設定することを推奨、使用するモデルがサポートする最大トークン数に依存）
```

サイトを構築し、多言語翻訳をサポートします。現在のディレクトリをソースディレクトリとして使用し、`.czon/dist`ディレクトリに出力します。

- `--lang`パラメータを複数回使用して、生成する言語バージョンを指定できます（例：`--lang zh-Hans --lang en-US`）。
- ソース言語を設定する必要はありません。CZONが自動的に検出します。

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

**その他のパラメータやヘルプを表示**：

```bash
npx czon@latest
```
