# Custom Styling

CZON supports customizing site styles through the `.czon/style.css` file, allowing you to override default styles or add personalized appearances.

## How to Use

1. Create a `style.css` file in the project's `.czon` directory:

```
your-project/
├── .czon/
│   ├── meta.json
│   └── style.css    <-- Create this file
├── README.md
└── docs/
```

2. Write your custom CSS in `style.css`:

```css
/* Example: Change link color */
:root {
  --link-color: #0066cc;
}

/* Example: Modify background in dark mode */
html.dark {
  --bg-primary: #0d1117;
}
```

3. Re-run `czon build`, and the custom styles will automatically apply to all pages.

## How It Works

- During the build, CZON checks if `.czon/style.css` exists.
- If it exists, it is copied to the output directory as `.czon/dist/style.css`.
- In each generated HTML page, a style link is added within the `<head>`:
  ```html
  <link rel="stylesheet" href="style.css" />
  ```
- Custom styles load after built-in styles, allowing them to override default styles.

## Available CSS Variables

CZON uses CSS variables to define theme colors. You can quickly adjust the color scheme by overriding these variables:

```css
:root {
  /* Background colors */
  --bg-primary: #ffffff;
  --bg-secondary: #f8f9fa;
  --bg-tertiary: #e9ecef;

  /* Text colors */
  --text-primary: #333333;
  --text-secondary: #6c757d;
  --text-muted: #adb5bd;

  /* Link and accent colors */
  --link-color: #007bff;
  --link-hover-color: #0056b3;

  /* Border colors */
  --border-color: #dee2e6;
}

/* Dark mode variables */
html.dark {
  --bg-primary: #1a1a1a;
  --bg-secondary: #2d2d2d;
  --bg-tertiary: #404040;

  --text-primary: #e5e5e5;
  --text-secondary: #a0a0a0;
  --text-muted: #6c6c6c;

  --link-color: #58a6ff;
  --link-hover-color: #79b8ff;

  --border-color: #404040;
}
```

## Examples

### Custom Brand Colors

```css
:root {
  --link-color: #e91e63;
  --link-hover-color: #c2185b;
}

html.dark {
  --link-color: #f48fb1;
  --link-hover-color: #f8bbd9;
}
```

### Adjust Content Area Width

```css
.content {
  max-width: 60rem;
}
```

### Custom Code Block Styles

```css
pre code {
  font-family: 'Fira Code', 'JetBrains Mono', monospace;
  font-size: 0.875rem;
}
```

### Hide Specific Elements

```css
/* Hide the right sidebar table of contents */
.sidebar-right {
  display: none;
}
```

## Important Notes

- The custom style filename must be `style.css` and placed in the `.czon/` directory.
- After modifying styles, you must re-run `czon build` for changes to take effect.
- It is recommended to use CSS variable overrides for styling customization, as this ensures compatibility with both light and dark modes.
- CZON uses Tailwind CSS. If you need to override styles generated by Tailwind, you may need to use `!important`.
