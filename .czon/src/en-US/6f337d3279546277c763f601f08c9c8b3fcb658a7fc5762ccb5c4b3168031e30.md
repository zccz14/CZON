# CZON - AI-Native Markdown Content Engine

- **C**: **C**ontent oriented | Content is king, focus on content
- **Z**: **Z**ero Configuration | Zero-configuration writing, minimize distractions
- **O**: **O**rganic AI-Native | Organic AI-native, deeply integrated AI
- **N**: **N**-shaped Energy Curve | N-shaped energy curve, involved in creation-distribution-feedback cycles

[> Website Demo](https://czon.zccz14.com/)

In the AI era, as website content creators, we can have a more intelligent content creation engine.

**Return to Content: Minimize Distractions, Focus on Writing**

Let documents return to their essence, let writing return to tranquility.

First, I don't want to be a librarian. Sometimes I want to write down some content, but I may not have thought of its title yet, or formed a particular organization. I hope LLMs will automatically help me generate titles, create summaries, classify, navigate, and organize.

Second, my study must be kept clean. I don't want complex configuration tools, struggle with complicated documentation setups, or dislike complex structures. Every time I see configuration files and project structures of tools like Docusaurus, VuePress, Astro, I get a headache. Now, CZON chooses to hide all configurations in the .czon directory, sweeping them into a corner. Users only need to focus on writing content, leaving the rest to CZON. Other directories are your writing space, where you can freely organize your Markdown files.

**Return to Native Language: Write in Your Mother Tongue, Smoothly Build Multilingual Versions**

Life is short, I'm too lazy to translate. People can best express their thinking depth when using their native language. But staying connected with the world is also necessary, and I don't want to give up multilingual communication. So I want a tool that allows me to write in my native language while enabling more people to see my content. Current i18n solutions not only require manual translation but also self-maintenance of content updates, which is too troublesome. I choose to use LLMs to help with translation, saving me a lot of time, and enabling one-click multilingual translation.

## Basic Features

1. 🌍 **Automatic Multilingual Translation**: Uses AI for incremental translation, allowing users to write Markdown in their native language while supporting multiple languages.
2. 💭 **Automatic Summary Extraction**: Uses AI for content analysis and extraction from original text.
3. 🏷️ **Automatic Tag Classification**: Uses AI for content tagging, classification extraction, and management.
4. 🧭 **Intelligent Category Navigation**: Uses AI to generate site maps and navigation, independent of source file locations.

## Static Site Generation (SSG)

CZON has a built-in SSG solution that can build any git folder containing Markdown files into a static HTML site.

⚠️ Please note, CZON is not a professional static site generator (SSG), but an AI-driven Markdown content engine focused on content creation and management.

✅ CZON aims to simplify the content creation and publishing process, allowing users to focus on writing itself rather than being troubled by complex configurations and tools.

❌ CZON won't provide complex theme customization and plugin ecosystems, but focuses on improving content quality and accessibility through AI.

🔔 However, CZON can still generate static sites. If necessary, CZON can be used as a preprocessor and integrated with other SSG solutions to generate personalized, aesthetically pleasing sites.

## Quick Start

Prerequisites:

- [Node.js](https://nodejs.org/) installed (recommended version 18 or above, requires npx command)
- [OpenAI API Key](https://platform.openai.com/account/api-keys) obtained, or OPENAI-compatible API Key
- Git installed (for listing Markdown files from Git, ignoring files filtered by .gitignore rules)

First, work in a folder already managed by Git:

Configure environment variables

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Required: Replace with your OpenAI API Key
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Optional, defaults to OpenAI official API
export OPENAI_MODEL="gpt-3.5-turbo"  # Optional, defaults to gpt-3.5-turbo model
export OPENAI_MAX_TOKENS="4096"  # Optional, set maximum token limit (if omitted, uses model default; for long text translation, recommend setting higher values like 8192, depending on the model's maximum supported token count)
```

Build the site with multilingual translation support. Uses the current directory as source directory, outputs to `.czon/dist` directory.

- Multiple `--lang` parameters can be used to specify language versions to generate (e.g., `--lang zh-Hans --lang en-US`).
- No need to configure source language, CZON automatically detects it.

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

**View more parameters or help**:

```bash
npx czon@latest
```
