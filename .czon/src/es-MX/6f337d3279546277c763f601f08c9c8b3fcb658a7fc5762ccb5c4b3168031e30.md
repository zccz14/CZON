# CZON - Motor de contenido Markdown nativo de IA

- **C**: **C**ontent oriented | Orientado al contenido, enfocado en el contenido
- **Z**: **Z**ero Configuration | Escritura sin configuración, reduce las interrupciones
- **O**: **O**rganic AI-Native | Nativo de IA orgánico, integración profunda de IA
- **N**: **N**-shaped Energy Curve | Curva de energía en forma de N, interviene en todos los aspectos de creación-distribución-retroalimentación

[> Demostración del sitio web](https://czon.zccz14.com/)

En la era de la IA, como creadores de contenido web, podemos tener un motor de creación de contenido más inteligente.

**Regreso al contenido: Minimizar interrupciones, enfocarse en escribir**

Devolver los documentos a su esencia, devolver la escritura a la tranquilidad.

Primero, no quiero ser bibliotecario. A veces quiero escribir algo, pero puede que aún no haya pensado en su título, no haya formado una organización particular. Espero que la IA me ayude automáticamente a generar títulos, hacer resúmenes, clasificar, navegar y otras tareas de organización.

Segundo, mi estudio debe estar limpio. No quiero herramientas de construcción con configuraciones complejas, lidiar con configuraciones de documentos complicadas, no me gustan las estructuras complejas. Cada vez que veo archivos de configuración y estructuras de proyectos de herramientas como Docusaurus, VuePress, Astro, me duele la cabeza. Ahora, CZON elige ocultar toda la configuración en el directorio .czon, barrerla a un rincón, los usuarios solo necesitan enfocarse en escribir contenido, y CZON se encarga del resto. Los demás directorios son su espacio de escritura, puede organizar sus archivos Markdown como desee.

**Regreso al idioma nativo: Escribir en el idioma materno, construir versiones multilingües sin problemas**

La vida es corta, soy demasiado perezoso para traducir. Las personas solo pueden aprovechar al máximo su profundidad de pensamiento cuando usan su idioma nativo. Pero al mismo tiempo, mantener conexión con el mundo es necesario, no quiero renunciar a la comunicación multilingüe. Por lo tanto, espero tener una herramienta que me permita escribir en mi idioma nativo y al mismo tiempo permitir que más personas vean mi contenido. La i18n actual no solo requiere que uno mismo traduzca, sino que también debe mantener las actualizaciones de contenido, es demasiado complicado. Elijo usar IA para ayudarme con la traducción, me ahorra mucho tiempo y puede completar traducciones a múltiples idiomas con un solo clic.

## Funciones básicas

1. 🌍 **Traducción multilingüe automática**: Usa IA para traducción incremental, permite a los usuarios escribir Markdown en su idioma nativo, pero los usuarios pueden ser multilingües.
2. 💭 **Extracción automática de resúmenes**: Usa IA para análisis y extracción de contenido del texto original.
3. 🏷️ **Clasificación automática de etiquetas**: Usa IA para extracción y gestión de etiquetas y clasificación de contenido.
4. 🧭 **Navegación inteligente por categorías**: Usa IA para generar mapas del sitio y navegación, la ubicación de los archivos fuente no es sensible.

## Generación de sitios estáticos (SSG)

CZON tiene integrado un esquema SSG que puede construir cualquier carpeta git que contenga Markdown en un sitio HTML estático.

⚠️ Tenga en cuenta que CZON no es un generador de sitios estáticos (SSG) profesional, sino un motor de contenido Markdown impulsado por IA, enfocado en la creación y gestión de contenido.

✅ CZON tiene como objetivo simplificar el proceso de creación y publicación de contenido, permitiendo a los usuarios concentrarse en la escritura misma, en lugar de verse abrumados por configuraciones y herramientas complejas.

❌ CZON no proporcionará personalizaciones complejas de temas ni ecosistemas de complementos, sino que se enfocará en mejorar la calidad y accesibilidad del contenido a través de IA.

🔔 Sin embargo, CZON aún puede generar sitios estáticos. Si es necesario, se puede usar CZON como preprocesador, integrar otros esquemas SSG para generar sitios personalizados y atractivos.

## Comenzar rápidamente

Requisitos previos:

- Tener instalado [Node.js](https://nodejs.org/) (se recomienda versión 18 o superior, necesita tener el comando npx)
- Tener una [OpenAI API Key](https://platform.openai.com/account/api-keys), o una API Key compatible con OPENAI
- Tener instalado Git (para listar archivos Markdown desde Git, ignorando los archivos filtrados por reglas .gitignore)

Primero, trabaje en una carpeta ya gestionada por git:

Configurar variables de entorno

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Obligatorio: reemplace con su OpenAI API Key
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Opcional, por defecto usa la API oficial de OpenAI
export OPENAI_MODEL="gpt-3.5-turbo"  # Opcional, por defecto usa el modelo gpt-3.5-turbo
export OPENAI_MAX_TOKENS="4096"  # Opcional, establecer límite máximo de tokens (si se omite, usa el valor por defecto del modelo, para traducciones de texto largo se recomienda establecer un valor más alto, por ejemplo 8192, dependiendo del número máximo de tokens que admita el modelo utilizado)
```

Construir el sitio, compatible con traducción multilingüe. Usa el directorio actual como directorio fuente, la salida va al directorio `.czon/dist`.

- Se puede especificar las versiones de idioma que se desean generar mediante múltiples usos del parámetro `--lang` (por ejemplo `--lang zh-Hans --lang en-US`).
- No es necesario configurar el idioma fuente, CZON lo detecta automáticamente.

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

**Ver más parámetros o ayuda**:

