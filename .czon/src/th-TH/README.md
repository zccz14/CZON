# CZON - เครื่องยนต์เนื้อหา Markdown แบบ AI-Native

- **C**: **C**ontent oriented | เนื้อหาเป็นใหญ่ มุ่งเน้นที่เนื้อหา
- **Z**: **Z**ero Configuration | เขียนแบบไม่ต้องกำหนดค่า ลดการรบกวน
- **O**: **O**rganic AI-Native | AI-Native แบบออร์แกนิก ผสานรวม AI อย่างลึกซึ้ง
- **N**: **N**-shaped Energy Curve | เส้นโค้งพลังงานรูปตัว N เข้ามาเกี่ยวข้องในทุกขั้นตอนของการสร้าง-เผยแพร่-รับผลตอบรับ

ในยุค AI ในฐานะผู้สร้างเนื้อหาเว็บไซต์ เราสามารถมีเครื่องยนต์สร้างเนื้อหาที่ชาญฉลาดยิ่งขึ้นได้

**กลับสู่เนื้อหา: ลดการรบกวนให้น้อยที่สุด มุ่งเน้นที่การเขียน**

ให้เอกสารกลับสู่แก่นแท้ ให้การเขียนกลับสู่ความสงบ

ประการแรก ฉันไม่อยากเป็นบรรณารักษ์ บางครั้งฉันอยากเขียนอะไรบางอย่าง แต่ฉันอาจยังไม่ได้คิดชื่อเรื่องให้ดี หรือยังไม่ได้จัดระเบียบเป็นพิเศษ ฉันหวังว่า LLM จะช่วยสร้างชื่อเรื่อง สรุปใจความ จัดหมวดหมู่ สร้างการนำทาง และจัดระเบียบต่างๆ ให้โดยอัตโนมัติ

ประการที่สอง ห้องทำงานของฉันต้องสะอาดเรียบร้อย ฉันไม่ต้องการเครื่องมือสร้างที่ต้องกำหนดค่าซับซ้อน ไม่อยากยุ่งกับค่ากำหนดเอกสารที่ซับซ้อน ไม่ชอบโครงสร้างที่วุ่นวาย ทุกครั้งที่เห็นไฟล์กำหนดค่าและโครงสร้างโปรเจกต์ของเครื่องมืออย่าง Docusaurus, VuePress, Astro ฉันก็ปวดหัว ตอนนี้ CZON เลือกที่จะซ่อนการกำหนดค่าทั้งหมดไว้ในไดเรกทอรี `.czon` กวาดเก็บไว้ในมุม ผู้ใช้เพียงแค่ต้องมุ่งเน้นที่การเขียนเนื้อหา ส่วนที่เหลือให้ CZON จัดการ ไดเรกทอรีอื่นๆ ทั้งหมดคือพื้นที่เขียนของคุณ คุณสามารถจัดระเบียบไฟล์ Markdown ของคุณได้ตามต้องการ

**กลับสู่ภาษาหลัก: เขียนด้วยภาษาหลัก สร้างเวอร์ชันหลายภาษาได้อย่างราบรื่น**

ชีวิตสั้น ฉันขี้เกียจแปล คนเราจะสามารถใช้ความคิดได้ลึกซึ้งที่สุดก็ต่อเมื่อใช้ภาษาหลัก แต่การเชื่อมต่อกับโลกก็เป็นสิ่งจำเป็น ฉันไม่อยากเสียโอกาสในการสื่อสารหลายภาษา ดังนั้นฉันจึงหวังว่าจะมีเครื่องมือที่ให้ฉันเขียนด้วยภาษาหลัก และในขณะเดียวกันก็ทำให้ผู้คนมากมายได้เห็นเนื้อหาของฉัน ปัจจุบัน i18n ไม่เพียงแต่ต้องแปลเอง แต่ยังต้องดูแลการอัปเดตเนื้อหาเองด้วย ซึ่งยุ่งยากเกินไป ฉันเลือกใช้ LLM ช่วยแปล ประหยัดเวลาไปได้มาก และสามารถแปลเป็นหลายภาษาได้ด้วยคลิกเดียว

## ✨ ฟีเจอร์หลัก

1. 🌍 **การแปลหลายภาษาโดย AI**: ใช้ AI ในการแปลแบบเพิ่มส่วน (Incremental) ให้ผู้ใช้เขียน Markdown ด้วยภาษาหลัก แต่ผู้ใช้สามารถเป็นผู้ใช้หลายภาษาได้
2. 📊 **การดึงข้อมูลเมตาดาต้าโดย AI**: ดึงชื่อเรื่อง คำอธิบาย สรุปใจความ คำสำคัญ กลุ่มผู้อ่าน ชื่อ URL ที่เป็นมิตร ฯลฯ โดยอัตโนมัติ
3. 🏷️ **การจัดหมวดหมู่แท็กโดย AI**: ใช้ AI ในการดึงและจัดการแท็กและหมวดหมู่ของเนื้อหา
4. 🧭 **การนำทางหมวดหมู่โดย AI**: ใช้ AI ในการสร้างแผนที่ไซต์และการนำทาง ตำแหน่งของไฟล์ต้นทางไม่สำคัญ
5. 🤖 **สรุปใจความทั้งไซต์โดย AI**: สามารถสร้างสรุปใจความทั้งไซต์ได้หลายสไตล์

และฟีเจอร์ที่ไม่ใช่ AI บางส่วน:

1. ⚙️ **Zero Configuration**: การกำหนดค่าและแคชทั้งหมดถูกซ่อนไว้ในไดเรกทอรี `.czon` โครงสร้างโปรเจกต์สะอาดตา
2. 🔄 **การสร้างแบบเพิ่มส่วน (Incremental Build)**: ตรวจจับการเปลี่ยนแปลงตามแฮชของเนื้อหา ประมวลผลเฉพาะไฟล์ที่เปลี่ยนแปลง
3. 📚 **รองรับส่วนขยาย Markdown**: รองรับสูตรคณิตศาสตร์ KaTeX แผนภูมิ Mermaid สไลด์โชว์ Embla เชิงอรรถ ฯลฯ โดยตรง
4. 🚀 **การสร้างไซต์แบบสแตติก**: มี SSG ที่ใช้ React ในตัว สร้างไซต์แบบสแตติกหลายภาษา
5. 🌐 **กำหนดเส้นทางอัตโนมัติตามภาษาของผู้เยี่ยมชม**: กำหนดเส้นทางไปยังเวอร์ชันภาษาที่ตรงกันอัตโนมัติตามภาษาของผู้เยี่ยมชม

## 📦 เริ่มต้นอย่างรวดเร็ว

### ข้อกำหนดเบื้องต้น

- ติดตั้ง [Node.js](https://nodejs.org/) แล้ว (แนะนำให้ใช้เวอร์ชัน LTS 24 หรือเวอร์ชัน 18 ขึ้นไป ต้องมีคำสั่ง npx)
- ได้รับ [OpenAI API Key](https://platform.openai.com/account/api-keys) แล้ว หรือ OPENAI API Key ที่เข้ากันได้
- ติดตั้ง Git แล้ว (ใช้สำหรับแสดงรายการไฟล์ Markdown จาก Git และไม่รวมไฟล์ที่ถูกกรองโดยกฎ .gitignore)

### การกำหนดค่าตัวแปรสภาพแวดล้อม

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # จำเป็น: โปรดแทนที่ด้วย OpenAI API Key ของคุณ
export OPENAI_BASE_URL="https://api.openai.com/v1"  # ไม่บังคับ ใช้ API ทางการของ OpenAI เป็นค่าเริ่มต้น
export OPENAI_MODEL="gpt-3.5-turbo"  # ไม่บังคับ ใช้โมเดล gpt-3.5-turbo เป็นค่าเริ่มต้น
export OPENAI_MAX_TOKENS="4096"  # ไม่บังคับ กำหนดขีดจำกัดจำนวนโทเคนสูงสุด (หากไม่กำหนดจะใช้ค่าเริ่มต้นของโมเดล สำหรับการแปลข้อความยาวแนะนำให้ตั้งค่าสูงขึ้น เช่น 8192 ขึ้นอยู่กับจำนวนโทเคนสูงสุดที่โมเดลที่ใช้รองรับ)

# หากต้องการใช้พร็อกซี HTTP เพื่อเข้าถึง OpenAI API สามารถตั้งค่าตัวแปรต่อไปนี้ได้
export HTTPS_PROXY="http://your-proxy.com:8080"  # ไม่บังคับ ตั้งค่าพร็อกซี HTTPS
export HTTP_PROXY="http://your-proxy.com:8080"   # ไม่บังคับ ตั้งค่าพร็อกซี HTTP
```

### การสร้างไซต์หลายภาษา

รันคำสั่งในโฟลเดอร์ใดๆ ที่จัดการด้วย Git:

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

เนื่องจากรหัสภาษาจะถูกใช้ในฟีเจอร์ต่างๆ ของการสร้างไซต์แบบสแตติกในภายหลัง โปรดตรวจสอบให้แน่ใจว่าใช้รหัสภาษามาตรฐาน BCP 47 ตัวอย่างเช่น `zh-Hans` หมายถึงภาษาจีนตัวย่อ `en-US` หมายถึงภาษาอังกฤษแบบอเมริกัน คุณสามารถเพิ่มภาษาอื่นๆ ตามต้องการได้ เช่น `es-ES` (ภาษาสเปน) `ja-JP` (ภาษาญี่ปุ่น) `ko-KR` (ภาษาเกาหลี) เป็นต้น
รายการรหัสภาษามาตรฐาน โปรดดูที่ [IETF language tag - Wikipedia](https://en.wikipedia.org/wiki/IETF_language_tag#List_of_common_primary_language_subtags)

ไดเรกทอรีผลลัพธ์: `.czon/dist` จำเป็นต้องนำเนื้อหาในไดเรกทอรีนี้ไปปรับใช้บนแพลตฟอร์มโฮสติ้งไซต์แบบสแตติกในภายหลัง

สำหรับวิธีใช้โดยละเอียด โปรดรัน `npx czon@latest --help`
