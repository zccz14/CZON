# CZON - เครื่องยนต์เนื้อหา Markdown แบบ AI-Native

- **C**: **C**ontent oriented | เนื้อหาคือราชา มุ่งเน้นที่เนื้อหา
- **Z**: **Z**ero Configuration | เขียนแบบไม่ต้องกำหนดค่า ลดการรบกวน
- **O**: **O**rganic AI-Native | AI-Native แบบออร์แกนิก ผสานรวม AI อย่างลึกซึ้ง
- **N**: **N**-shaped Energy Curve | เส้นโค้งพลังงานรูปตัว N เข้ามาเกี่ยวข้องในทุกขั้นตอนของการสร้าง-เผยแพร่-รับคำติชม

[> ตัวอย่างเว็บไซต์](https://czon.zccz14.com/)

ในยุค AI ในฐานะผู้สร้างเนื้อหาเว็บไซต์ เราสามารถมีเครื่องยนต์สร้างเนื้อหาที่ชาญฉลาดยิ่งขึ้นได้

**กลับสู่เนื้อหา: ลดการรบกวนให้น้อยที่สุด มุ่งเน้นการเขียน**

ให้เอกสารกลับสู่แก่นแท้ ให้การเขียนกลับสู่ความสงบ

ประการแรก ฉันไม่อยากเป็นบรรณารักษ์ บางครั้งฉันอยากเขียนอะไรบางอย่าง แต่ฉันอาจยังไม่ได้คิดชื่อเรื่องให้ดี หรือยังไม่ได้จัดระเบียบเป็นพิเศษ ฉันหวังว่า LLM จะช่วยฉันสร้างชื่อเรื่อง สรุปใจความ จัดหมวดหมู่ สร้างการนำทาง และงานจัดระเบียบอื่นๆ โดยอัตโนมัติ

ประการที่สอง ห้องทำงานของฉันต้องสะอาดเรียบร้อย ฉันไม่ต้องการเครื่องมือสร้างที่กำหนดค่าซับซ้อน ไม่อยากยุ่งกับการกำหนดค่าเอกสารที่ซับซ้อน ไม่ชอบโครงสร้างที่ซับซ้อน ทุกครั้งที่เห็นไฟล์กำหนดค่าและโครงสร้างโปรเจกต์ของเครื่องมืออย่าง Docusaurus, VuePress, Astro ฉันก็ปวดหัว ตอนนี้ CZON เลือกที่จะซ่อนการกำหนดค่าทั้งหมดไว้ในไดเรกทอรี `.czon` กวาดไปไว้ในมุม ผู้ใช้เพียงแค่ต้องมุ่งเน้นที่การเขียนเนื้อหา ส่วนที่เหลือให้ CZON จัดการ ไดเรกทอรีอื่นๆ ทั้งหมดคือพื้นที่เขียนของคุณ คุณสามารถจัดระเบียบไฟล์ Markdown ของคุณได้ตามต้องการ

**กลับสู่ภาษาแม่: เขียนด้วยภาษาแม่ สร้างเวอร์ชันหลายภาษาได้อย่างลื่นไหล**

ชีวิตสั้น ฉันขี้เกียจแปล เวลาที่คนใช้ภาษาแม่ นั่นคือเวลาที่สามารถดึงเอาความลึกซึ้งของการคิดออกมาได้มากที่สุด แต่ในขณะเดียวกัน การเชื่อมต่อกับโลกก็เป็นสิ่งจำเป็น ฉันไม่อยากทิ้งการสื่อสารหลายภาษา ดังนั้นฉันจึงหวังว่าจะมีเครื่องมือที่ให้ฉันเขียนด้วยภาษาแม่ และในขณะเดียวกันก็ให้คนอื่นๆ ได้เห็นเนื้อหาของฉันด้วย i18n ในปัจจุบันนอกจากต้องแปลเองแล้ว ยังต้องคอยอัปเดตเนื้อหาด้วยตัวเองอีก ซึ่งยุ่งยากเกินไป ฉันเลือกใช้ LLM ช่วยฉันแปล ประหยัดเวลาไปได้มาก และสามารถแปลเป็นหลายภาษาได้ด้วยคลิกเดียว

## ฟังก์ชันพื้นฐาน

1.  🌍 **แปลหลายภาษาอัตโนมัติ**: ใช้ AI ในการแปลแบบเพิ่มส่วน (Incremental) ให้ผู้ใช้เขียน Markdown ด้วยภาษาแม่ แต่ผู้ใช้สามารถเป็นผู้ใช้หลายภาษาได้
2.  💭 **สรุปใจความอัตโนมัติ**: ใช้ AI ในการวิเคราะห์และดึงใจความสำคัญจากข้อความต้นฉบับ
3.  🏷️ **จัดหมวดหมู่แท็กอัตโนมัติ**: ใช้ AI ในการดึงและจัดการแท็กและหมวดหมู่ของเนื้อหา
4.  🧭 **นำทางจัดหมวดหมู่อย่างชาญฉลาด**: ใช้ AI ในการสร้างแผนที่ไซต์และการนำทาง ตำแหน่งของไฟล์ต้นทางไม่สำคัญ

## การสร้างไซต์แบบสแตติก (SSG)

CZON มีโซลูชัน SSG ในตัว ซึ่งสามารถสร้างโฟลเดอร์ git ที่มี Markdown อยู่ภายในให้กลายเป็นไซต์ HTML แบบสแตติกได้

⚠️ โปรดทราบว่า CZON ไม่ใช่เครื่องมือสร้างไซต์แบบสแตติก (SSG) มืออาชีพ แต่เป็นเครื่องยนต์เนื้อหา Markdown ที่ขับเคลื่อนด้วย AI โดยมุ่งเน้นที่การสร้างและจัดการเนื้อหา

✅ CZON ออกแบบมาเพื่อทำให้กระบวนการสร้างและเผยแพร่เนื้อหาง่ายขึ้น ให้ผู้ใช้สามารถมุ่งเน้นที่การเขียนเอง แทนที่จะถูกกวนใจด้วยการกำหนดค่าและเครื่องมือที่ซับซ้อน

❌ CZON จะไม่ให้บริการการปรับแต่งธีมที่ซับซ้อนและระบบปลั๊กอิน แต่จะมุ่งเน้นที่การยกระดับคุณภาพและความสามารถในการเข้าถึงของเนื้อหาผ่าน AI

🔔 อย่างไรก็ตาม CZON ยังคงสามารถสร้างไซต์แบบสแตติกได้ หากจำเป็น สามารถใช้ CZON เป็นตัวประมวลผลล่วงหน้า (Preprocessor) เพื่อผสานรวมกับโซลูชัน SSG อื่นๆ ในการสร้างไซต์ที่ปรับแต่งได้และสวยงาม

## เริ่มต้นอย่างรวดเร็ว

ข้อกำหนดเบื้องต้น:

-   ติดตั้ง [Node.js](https://nodejs.org/) แล้ว (แนะนำเวอร์ชัน 18 ขึ้นไป ต้องมีคำสั่ง npx)
-   ได้รับ [OpenAI API Key](https://platform.openai.com/account/api-keys) แล้ว หรือมี OpenAI Compatible API Key
-   ติดตั้ง Git แล้ว (ใช้สำหรับแสดงรายการไฟล์ Markdown จาก Git โดยไม่รวมไฟล์ที่ถูกกรองโดยกฎ .gitignore)

ขั้นแรก ให้ทำงานในโฟลเดอร์ที่ถูกจัดการโดย git อยู่แล้ว:

กำหนดค่าตัวแปรสภาพแวดล้อม

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # จำเป็น: โปรดแทนที่ด้วย OpenAI API Key ของคุณ
export OPENAI_BASE_URL="https://api.openai.com/v1"  # ไม่บังคับ ใช้ค่าเริ่มต้นคือ OpenAI Official API
export OPENAI_MODEL="gpt-3.5-turbo"  # ไม่บังคับ ใช้ค่าเริ่มต้นคือโมเดล gpt-3.5-turbo
export OPENAI_MAX_TOKENS="4096"  # ไม่บังคับ กำหนดขีดจำกัดจำนวนโทเคนสูงสุด (หากไม่กำหนดจะใช้ค่าเริ่มต้นของโมเดล สำหรับการแปลข้อความยาวแนะนำให้ตั้งค่าสูงขึ้น เช่น 8192 ขึ้นอยู่กับจำนวนโทเคนสูงสุดที่โมเดลที่ใช้รองรับ)
```

สร้างไซต์ รองรับการแปลหลายภาษา ใช้ไดเรกทอรีปัจจุบันเป็นไดเรกทอรีต้นทาง ผลลัพธ์ไปที่ไดเรกทอรี `.czon/dist`

-   สามารถระบุเวอร์ชันภาษาที่ต้องการสร้างได้โดยใช้พารามิเตอร์ `--lang` หลายครั้ง (เช่น `--lang zh-Hans --lang en-US`)
-   ไม่จำเป็นต้องกำหนดค่าภาษาต้นทาง CZON จะตรวจจับอัตโนมัติ

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

**ดูพารามิเตอร์เพิ่มเติมหรือความช่วยเหลือ**:

```bash
npx czon@latest
```
