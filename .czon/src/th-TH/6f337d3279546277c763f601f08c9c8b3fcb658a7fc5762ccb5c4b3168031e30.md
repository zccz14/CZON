# CZON - เครื่องมือจัดการเนื้อหา Markdown แบบ AI-Native

- **C**: **C**ontent oriented | เน้นเนื้อหาเป็นหลัก
- **Z**: **Z**ero Configuration | การเขียนแบบไม่ต้องกำหนดค่า ลดสิ่งรบกวน
- **O**: **O**rganic AI-Native | AI-Native แบบออร์แกนิก ผสานรวม AI อย่างลึกซึ้ง
- **N**: **N**-shaped Energy Curve | เส้นโค้งพลังงานรูปตัว N เข้าแทรกแซงทุกขั้นตอนของการสร้าง-เผยแพร่-รับฟีดแบ็ก

[> Website Demo](https://czon.zccz14.com/)

ในยุค AI ผู้สร้างเนื้อหาเว็บไซต์สามารถมีเครื่องมือสร้างเนื้อหาที่ชาญฉลาดยิ่งขึ้นได้

**กลับสู่เนื้อหา: ลดการรบกวนให้น้อยที่สุด โฟกัสที่การเขียน**

ให้เอกสารกลับสู่แก่นแท้ ให้การเขียนกลับสู่ความสงบ

ประการแรก ฉันไม่อยากเป็นบรรณารักษ์ บางครั้งฉันอยากเขียนเนื้อหาบางอย่าง แต่ฉันอาจยังไม่ได้คิดหัวข้อให้ดี หรือยังไม่ได้จัดระเบียบเป็นพิเศษ ฉันหวังว่า LLM จะช่วยสร้างหัวข้อ สรุป จัดหมวดหมู่ นำทาง และจัดระเบียบต่างๆ ให้โดยอัตโนมัติ

ประการที่สอง ห้องทำงานของฉันต้องสะอาด ฉันไม่ต้องการเครื่องมือสร้างที่ตั้งค่าซับซ้อน ไม่ชอบการตั้งค่าเอกสารที่ยุ่งยาก ไม่ชอบโครงสร้างที่ซับซ้อน ทุกครั้งที่เห็นไฟล์การตั้งค่าและโครงสร้างโปรเจกต์ของ Docusaurus, VuePress, Astro ฉันก็ปวดหัว ตอนนี้ CZON เลือกที่จะซ่อนการตั้งค่าทั้งหมดไว้ในไดเรกทอรี .czon เก็บไว้ในมุม ผู้ใช้เพียงแค่โฟกัสที่การเขียนเนื้อหา ส่วนที่เหลือให้ CZON จัดการ ไดเรกทอรีอื่นๆ เป็นพื้นที่เขียนของคุณ คุณสามารถจัดระเบียบไฟล์ Markdown ของคุณได้ตามต้องการ

**กลับสู่ภาษาแม่: เขียนด้วยภาษาแม่ สร้างเวอร์ชันหลายภาษาได้อย่างราบรื่น**

ชีวิตสั้น ฉันขี้เกียจแปล คนเราใช้ภาษาแม่ได้ดีที่สุดเมื่อต้องการแสดงความคิดลึกซึ้ง แต่การเชื่อมต่อกับโลกก็จำเป็น ฉันไม่อยากเสียโอกาสสื่อสารหลายภาษา ดังนั้นฉันหวังว่าจะมีเครื่องมือที่ให้ฉันเขียนด้วยภาษาแม่ และให้คนอื่นเห็นเนื้อหาของฉันด้วย ปัจจุบัน i18n ไม่เพียงแต่ต้องแปลเอง แต่ยังต้องดูแลอัปเดตเนื้อหาเองด้วย มันยุ่งยากเกินไป ฉันเลือกใช้ LLM ช่วยแปล ประหยัดเวลาฉันไปมาก และสามารถแปลหลายภาษาได้ด้วยคลิกเดียว

## ฟังก์ชันพื้นฐาน

1. 🌍 **การแปลหลายภาษาอัตโนมัติ**: ใช้ AI ในการแปลแบบเพิ่มเติม ให้ผู้ใช้เขียน Markdown ด้วยภาษาแม่ แต่ผู้ใช้สามารถเป็นหลายภาษาได้
2. 💭 **การสรุปเนื้อหาอัตโนมัติ**: ใช้ AI ในการวิเคราะห์และดึงเนื้อหาจากข้อความต้นฉบับ
3. 🏷️ **การจัดหมวดหมู่แท็กอัตโนมัติ**: ใช้ AI ในการดึงและจัดการแท็กและหมวดหมู่ของเนื้อหา
4. 🧭 **การนำทางจัดหมวดหมู่แบบอัจฉริยะ**: ใช้ AI ในการสร้างแผนที่ไซต์และการนำทาง ตำแหน่งของไฟล์ต้นฉบับไม่สำคัญ

## การสร้างเว็บไซต์แบบสแตติก (SSG)

CZON มีโซลูชัน SSG ในตัว สามารถสร้างโฟลเดอร์ git ที่มี Markdown ใดๆ ก็ได้ให้เป็นเว็บไซต์ HTML แบบสแตติก

⚠️ โปรดทราบว่า CZON ไม่ใช่เครื่องมือสร้างเว็บไซต์แบบสแตติก (SSG) มืออาชีพ แต่เป็นเครื่องมือจัดการเนื้อหา Markdown ที่ขับเคลื่อนด้วย AI โดยเน้นการสร้างและจัดการเนื้อหา

✅ CZON ออกแบบมาเพื่อทำให้กระบวนการสร้างและเผยแพร่เนื้อหาง่ายขึ้น ให้ผู้ใช้สามารถโฟกัสที่การเขียนเอง แทนที่จะถูกกวนใจด้วยการกำหนดค่าและเครื่องมือที่ซับซ้อน

❌ CZON จะไม่ให้การปรับแต่งธีมที่ซับซ้อนและระบบปลั๊กอิน แต่จะโฟกัสที่การเพิ่มคุณภาพและความสามารถในการเข้าถึงของเนื้อหาผ่าน AI

🔔 อย่างไรก็ตาม CZON ยังคงสามารถสร้างเว็บไซต์แบบสแตติกได้ หากจำเป็น สามารถใช้ CZON เป็นตัวประมวลผลล่วงหน้า ผสานรวมกับโซลูชัน SSG อื่นๆ เพื่อสร้างไซต์ที่ปรับแต่งได้และสวยงาม

## เริ่มต้นอย่างรวดเร็ว

ข้อกำหนดเบื้องต้น:

- ติดตั้ง [Node.js](https://nodejs.org/) (แนะนำเวอร์ชัน 18 ขึ้นไป ต้องมีคำสั่ง npx)
- ได้รับ [OpenAI API Key](https://platform.openai.com/account/api-keys) หรือ API Key ที่เข้ากันได้กับ OPENAI
- ติดตั้ง Git (ใช้สำหรับแสดงรายการไฟล์ Markdown จาก Git ไม่รวมไฟล์ที่ถูกกรองโดยกฎ .gitignore)

ขั้นแรก ทำงานในโฟลเดอร์ที่ถูกจัดการโดย git อยู่แล้ว:

กำหนดค่าตัวแปรสภาพแวดล้อม

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # จำเป็น: โปรดแทนที่ด้วย OpenAI API Key ของคุณ
export OPENAI_BASE_URL="https://api.openai.com/v1"  # ไม่บังคับ ใช้ API ทางการของ OpenAI เป็นค่าเริ่มต้น
export OPENAI_MODEL="gpt-3.5-turbo"  # ไม่บังคับ ใช้โมเดล gpt-3.5-turbo เป็นค่าเริ่มต้น
export OPENAI_MAX_TOKENS="4096"  # ไม่บังคับ กำหนดขีดจำกัดจำนวนโทเค็นสูงสุด (ถ้าไม่กำหนดจะใช้ค่าเริ่มต้นของโมเดล สำหรับการแปลข้อความยาวแนะนำให้ตั้งค่าสูงกว่า เช่น 8192 ขึ้นอยู่กับจำนวนโทเค็นสูงสุดที่โมเดลที่ใช้รองรับ)
```

สร้างไซต์ รองรับการแปลหลายภาษา ใช้ไดเรกทอรีปัจจุบันเป็นไดเรกทอรีต้นทาง ผลลัพธ์ไปที่ไดเรกทอรี `.czon/dist`

- สามารถใช้พารามิเตอร์ `--lang` หลายครั้งเพื่อระบุเวอร์ชันภาษาที่ต้องการสร้าง (เช่น `--lang zh-Hans --lang en-US`)
- ไม่ต้องกำหนดค่าภาษาต้นทาง CZON จะตรวจจับอัตโนมัติ

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

**ดูพารามิเตอร์เพิ่มเติมหรือความช่วยเหลือ**:

```bash
npx czon@latest
```
