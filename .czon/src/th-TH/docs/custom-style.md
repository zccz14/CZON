# สไตล์แบบกำหนดเอง

CZON รองรับการกำหนดสไตล์ไซต์แบบกำหนดเองผ่านไฟล์ `.czon/style.css` ช่วยให้คุณสามารถแทนที่สไตล์เริ่มต้นหรือเพิ่มรูปลักษณ์ส่วนบุคคลได้

## วิธีการใช้

1. สร้างไฟล์ `style.css` ในไดเรกทอรี `.czon` ของโปรเจกต์:

```
your-project/
├── .czon/
│   ├── meta.json
│   └── style.css    <-- สร้างไฟล์นี้
├── README.md
└── docs/
```

2. เขียน CSS แบบกำหนดเองของคุณใน `style.css`:

```css
/* ตัวอย่าง: แก้ไขสีลิงก์ */
:root {
  --link-color: #0066cc;
}

/* ตัวอย่าง: แก้ไขพื้นหลังในโหมดมืด */
html.dark {
  --bg-primary: #0d1117;
}
```

3. รัน `czon build` อีกครั้ง สไตล์แบบกำหนดเองจะถูกนำไปใช้กับทุกหน้าอัตโนมัติ

## หลักการทำงาน

- ในระหว่างการ build, CZON จะตรวจจับว่าไฟล์ `.czon/style.css` มีอยู่หรือไม่
- หากมีอยู่ จะคัดลอกไปยังไดเรกทอรีเอาต์พุต `.czon/dist/style.css`
- ในทุกหน้า HTML ที่สร้างขึ้น จะเพิ่มลิงก์สไตล์ภายใน `<head>`:
  ```html
  <link rel="stylesheet" href="style.css" />
  ```
- สไตล์แบบกำหนดเองจะโหลดหลังจากสไตล์ในตัว ดังนั้นจึงสามารถแทนที่สไตล์เริ่มต้นได้

## ตัวแปร CSS ที่ใช้ได้

CZON ใช้ตัวแปร CSS ในการกำหนดสีธีม คุณสามารถปรับแต่งโทนสีได้อย่างรวดเร็วโดยการแทนที่ตัวแปรเหล่านี้:

```css
:root {
  /* สีพื้นหลัง */
  --bg-primary: #ffffff;
  --bg-secondary: #f8f9fa;
  --bg-tertiary: #e9ecef;

  /* สีข้อความ */
  --text-primary: #333333;
  --text-secondary: #6c757d;
  --text-muted: #adb5bd;

  /* สีลิงก์และสีเน้น */
  --link-color: #007bff;
  --link-hover-color: #0056b3;

  /* สีเส้นขอบ */
  --border-color: #dee2e6;
}

/* ตัวแปรโหมดมืด */
html.dark {
  --bg-primary: #1a1a1a;
  --bg-secondary: #2d2d2d;
  --bg-tertiary: #404040;

  --text-primary: #e5e5e5;
  --text-secondary: #a0a0a0;
  --text-muted: #6c6c6c;

  --link-color: #58a6ff;
  --link-hover-color: #79b8ff;

  --border-color: #404040;
}
```

## ตัวอย่าง

### กำหนดสีแบรนด์แบบกำหนดเอง

```css
:root {
  --link-color: #e91e63;
  --link-hover-color: #c2185b;
}

html.dark {
  --link-color: #f48fb1;
  --link-hover-color: #f8bbd9;
}
```

### ปรับความกว้างของพื้นที่เนื้อหา

```css
.content {
  max-width: 60rem;
}
```

### กำหนดสไตล์บล็อกโค้ดแบบกำหนดเอง

```css
pre code {
  font-family: 'Fira Code', 'JetBrains Mono', monospace;
  font-size: 0.875rem;
}
```

### ซ่อนองค์ประกอบเฉพาะ

```css
/* ซ่อนแถบด้านข้างด้านขวา (สารบัญ) */
.sidebar-right {
  display: none;
}
```

## ข้อควรระวัง

- ชื่อไฟล์สไตล์แบบกำหนดเองต้องเป็น `style.css` และต้องอยู่ในไดเรกทอรี `.czon/`
- หลังแก้ไขสไตล์ ต้องรัน `czon build` ใหม่จึงจะมีผล
- แนะนำให้ใช้วิธีการแทนที่ด้วยตัวแปร CSS ในการกำหนดสไตล์แบบกำหนดเอง เพื่อให้เข้ากันได้กับทั้งโหมดสว่างและโหมดมืด
- CZON ใช้ Tailwind CSS หากต้องการแทนที่สไตล์ที่สร้างโดย Tailwind อาจจำเป็นต้องใช้ `!important`
