# เทคนิคการใช้งาน

## การประกาศวันที่ในเนื้อหาเอกสาร

ภายในเนื้อหาสามารถใช้การประกาศวันที่ เช่น "วันนี้คือวันที่ 8 มกราคม 2026" (รูปแบบอิสระ) CZON จะตรวจจับและประมวลผลโดยอัตโนมัติ

เอกสาร Markdown แบบดั้งเดิมประกาศวันที่ผ่าน YAML Frontmatter ซึ่งจำเป็นต้องจำฟิลด์ที่เกี่ยวข้อง มิฉะนั้นอาจทำให้ระบบไม่สามารถระบุวันที่ได้อย่างถูกต้อง

CZON รองรับการประกาศวันที่โดยตรงในเนื้อหาเอกสาร ช่วยหลีกเลี่ยงปัญหาการลืมกรอกข้อมูลในฟิลด์ Frontmatter

AI จะทำการดึงข้อมูลและอนุมานข้อมูลวันที่จากเนื้อหาโดยอัตโนมัติ และประมวลผลเป็นวันที่สร้างเอกสาร

วิธีนี้มีความยืดหยุ่นและชาญฉลาดมากกว่า ช่วยยกระดับประสบการณ์ผู้ใช้

นอกจากนี้ เอกสารที่มีวันที่สามารถสร้างมุมมองไทม์ไลน์ได้ เพื่อความสะดวกในการเรียกดูและจัดการ เหมาะอย่างยิ่งสำหรับประเภทเนื้อหาที่ต้องการไทม์ไลน์ เช่น ไดอารี่ บล็อก
