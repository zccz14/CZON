# ทดสอบลิงก์ภายในไซต์

## การทดสอบลิงก์ Markdown ภายในไซต์

นี่คือเอกสารทดสอบ ใช้สำหรับตรวจสอบความถูกต้องของลิงก์ภายในไซต์

กรุณาคลิกลิงก์ด้านล่างเพื่อทดสอบ:

- [ลิงก์ไปยังเอกสารทดสอบ KaTeX](test-katex.md)
- [ลิงก์ไปยังตัวอย่างไดอะแกรม Mermaid](test-mermaid.md)

## ทดสอบเชิงอรรถ:

นี่คือการทดสอบเชิงอรรถ[^1]

[^1]: นี่คือเนื้อหาของเชิงอรรถ เนื้อหาของเชิงอรรถควรแสดงผลที่ด้านล่างของหน้าอย่างถูกต้อง
