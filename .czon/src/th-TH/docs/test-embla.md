# การทดสอบเอฟเฟกต์ Embla Carousel

นี่คือเอกสารสำหรับทดสอบเอฟเฟกต์ของ Embla Carousel

รูปภาพต่อเนื่องหลายรูปจะถูกแสดงเป็น Carousel ผู้ใช้สามารถสลับมุมมองได้โดยการคลิกลูกศรหรือลากรูปภาพ

![รูปภาพ1](../logo.png)
![รูปภาพ2](../logo.png)
![รูปภาพ3](../logo.png)
