# CZON - Motor de Conteúdo Markdown Nativo em IA

- **C**: **C**ontent oriented | Orientado para conteúdo, foco no conteúdo
- **Z**: **Z**ero Configuration | Escrita sem configuração, reduzir interrupções
- **O**: **O**rganic AI-Native | IA nativa orgânica, integração profunda com IA
- **N**: **N**-shaped Energy Curve | Curva de energia em forma de N, intervém em todas as fases de criação-distribuição-feedback

[> Demonstração do Website](https://czon.zccz14.com/)

Na era da IA, como criadores de conteúdo web, podemos ter um motor de criação de conteúdo mais inteligente.

**Regresso ao conteúdo: minimizar interrupções, focar na escrita**

Devolver a essência aos documentos, devolver a tranquilidade à escrita.

Primeiro, não quero ser um bibliotecário. Por vezes quero escrever algum conteúdo, mas posso ainda não ter pensado no seu título, ainda não ter formado uma organização específica. Espero que a LLM me ajude automaticamente a gerar títulos, fazer resumos, classificar, navegar e outras tarefas de organização.

Segundo, o meu escritório tem de estar arrumado. Não quero ferramentas de construção com configurações complexas, não quero mexer em configurações complexas de documentos, não gosto de estruturas complexas. Cada vez que vejo os ficheiros de configuração e estruturas de projeto de ferramentas como Docusaurus, VuePress, Astro, fico com dor de cabeça. Agora, o CZON opta por esconder todas as configurações no diretório .czon, varrendo-as para um canto, permitindo que os utilizadores se concentrem apenas na escrita do conteúdo, deixando o resto para o CZON tratar. Os outros diretórios são o seu espaço de escrita, pode organizar os seus ficheiros Markdown como desejar.

**Regresso à língua materna: escrever na língua materna, construir versões multilingues de forma fluida**

A vida é curta, não tenho paciência para traduzir. As pessoas só conseguem explorar plenamente a profundidade do seu pensamento quando utilizam a sua língua materna. Mas, ao mesmo tempo, manter a ligação com o mundo é necessário, não quero desistir da comunicação multilingue. Por isso, espero ter uma ferramenta que me permita escrever na minha língua materna, ao mesmo tempo que permite que mais pessoas vejam o meu conteúdo. Atualmente, o i18n não só exige que traduzamos nós próprios, como também temos de manter as atualizações de conteúdo, o que é demasiado trabalhoso. Opto por utilizar a LLM para me ajudar com as traduções, poupando-me muito tempo e permitindo completar traduções para vários idiomas com um único clique.

## Funcionalidades Básicas

1. 🌍 **Tradução automática multilingue**: Utiliza IA para tradução incremental, permitindo que os utilizadores escrevam Markdown na sua língua materna, mas os utilizadores podem ser multilingues.
2. 💭 **Extração automática de resumos**: Utiliza IA para análise e extração de conteúdo do texto original.
3. 🏷️ **Classificação automática por etiquetas**: Utiliza IA para extração e gestão de etiquetas e classificação de conteúdo.
4. 🧭 **Navegação inteligente por categorias**: Utiliza IA para gerar mapas do site e navegação, a localização dos ficheiros de origem não é sensível.

## Geração de Sites Estáticos (SSG)

O CZON inclui uma solução SSG integrada que pode transformar qualquer pasta git contendo Markdown num site HTML estático.

⚠️ Note que o CZON não é um gerador de sites estáticos (SSG) profissional, mas sim um motor de conteúdo Markdown orientado por IA, focado na criação e gestão de conteúdo.

✅ O CZON visa simplificar o processo de criação e publicação de conteúdo, permitindo que os utilizadores se concentrem na escrita em si, em vez de serem incomodados por configurações e ferramentas complexas.

❌ O CZON não oferece personalizações complexas de temas nem ecossistemas de plugins, focando-se em melhorar a qualidade e acessibilidade do conteúdo através da IA.

🔔 No entanto, o CZON ainda pode gerar sites estáticos e, se necessário, pode ser utilizado como pré-processador, integrando outras soluções SSG para gerar sites personalizados e esteticamente agradáveis.

## Início Rápido

Pré-requisitos:

- [Node.js](https://nodejs.org/) instalado (versão 18 ou superior recomendada, precisa do comando npx)
- [OpenAI API Key](https://platform.openai.com/account/api-keys) obtida, ou chave de API compatível com OPENAI
- Git instalado (para listar arquivos Markdown do Git, ignorando arquivos filtrados pelas regras .gitignore)

Primeiro, trabalhe numa pasta já gerida pelo git:

Configurar variáveis de ambiente

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Obrigatório: substitua pela sua OpenAI API Key
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Opcional, utiliza por defeito a API oficial da OpenAI
export OPENAI_MODEL="gpt-3.5-turbo"  # Opcional, utiliza por defeito o modelo gpt-3.5-turbo
export OPENAI_MAX_TOKENS="4096"  # Opcional, define o limite máximo de tokens (se ignorado, utiliza o valor por defeito do modelo, para tradução de textos longos recomenda-se definir um valor mais alto, por exemplo 8192, dependendo do número máximo de tokens suportado pelo modelo utilizado)
```

Construir o site, suportando tradução multilingue. Utiliza o diretório atual como diretório de origem, saída para o diretório `.czon/dist`.

- Pode especificar as versões de idioma a gerar utilizando várias vezes o parâmetro `--lang` (por exemplo `--lang pt-PT --lang en-US`).
- Não é necessário configurar o idioma de origem, o CZON deteta automaticamente.

```bash
npx czon@latest build --lang pt-PT --lang en-US
```

**Ver mais parâmetros ou ajuda**:

```bash
npx czon@latest
```
