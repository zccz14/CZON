# Técnicas de Utilização

## Declarar a Data no Corpo do Texto

No corpo do texto, pode utilizar uma declaração de data como "Hoje é 8 de janeiro de 2026" (o estilo do formato é livre), e o CZON irá reconhecê-la e processá-la automaticamente.

Os documentos Markdown tradicionais declaram a data através do YAML Frontmatter, exigindo que se memorize o campo correspondente; caso contrário, a data pode não ser corretamente identificada.

O CZON suporta a declaração direta da data no corpo do texto, evitando o problema de esquecer de preencher os campos do Frontmatter.

A IA extrai e infere automaticamente as informações de data presentes no corpo do texto e trata-as como a data de criação do documento.

Esta abordagem é mais flexível e inteligente, melhorando a experiência do utilizador.

A propósito, os documentos que possuem uma data podem gerar uma vista cronológica, facilitando a navegação e gestão. É especialmente adequado para tipos de conteúdo que necessitam de uma linha do tempo, como diários e blogs.
