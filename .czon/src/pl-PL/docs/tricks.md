# Techniki użycia

## Deklarowanie daty w treści dokumentu

W treści dokumentu można użyć deklaracji daty takiej jak "Dzisiaj jest 8 stycznia 2026 roku" (format i styl są dowolne), a CZON automatycznie ją rozpozna i przetworzy.

Tradycyjne dokumenty Markdown deklarują datę za pomocą YAML Frontmatter, co wymaga zapamiętania odpowiednich pól, w przeciwnym razie data może nie zostać poprawnie rozpoznana.

CZON obsługuje bezpośrednie deklarowanie daty w treści dokumentu, eliminując problem zapominania o wypełnieniu pól Frontmatter.

Sztuczna inteligencja automatycznie wyodrębnia i wnioskuje informacje o dacie z treści dokumentu, a następnie przetwarza ją jako datę utworzenia dokumentu.

To podejście jest bardziej elastyczne i inteligentne, poprawiając doświadczenia użytkownika.

Warto dodać, że dokumenty posiadające datę mogą generować widok osi czasu, ułatwiając przeglądanie i zarządzanie. Jest to szczególnie przydatne w typach treści wymagających osi czasu, takich jak dzienniki czy blogi.
