# CZON - Motor de contenido Markdown nativo de IA

- **C**: **C**ontent oriented | Orientado al contenido, enfocado en el contenido
- **Z**: **Z**ero Configuration | Escritura sin configuración, reduce las distracciones
- **O**: **O**rganic AI-Native | IA nativa orgánica, integración profunda de IA
- **N**: **N**-shaped Energy Curve | Curva de energía en forma de N, interviene en todos los aspectos de creación-distribución-retroalimentación

[> Demostración del sitio web](https://czon.zccz14.com/)

En la era de la IA, como creadores de contenido web, podemos tener un motor de creación de contenido más inteligente.

**Regreso al contenido: Minimizar las distracciones, enfocarse en escribir**

Devolver la documentación a su esencia, devolver la escritura a la tranquilidad.

Primero, no quiero ser bibliotecario. A veces quiero escribir algo, pero puede que aún no haya pensado en su título, no haya formado una organización particular. Espero que la LLM me ayude automáticamente a generar títulos, hacer resúmenes, clasificar, navegar y otras tareas de organización.

Segundo, mi estudio debe estar limpio. No quiero herramientas de construcción con configuración compleja, lidiar con configuraciones de documentos complejas, no me gustan las estructuras complejas. Cada vez que veo los archivos de configuración y estructuras de proyectos de herramientas como Docusaurus, VuePress, Astro, me duele la cabeza. Ahora, CZON elige ocultar toda la configuración en el directorio .czon, barrerla a un rincón, los usuarios solo necesitan enfocarse en escribir contenido, y CZON maneja el resto. Los otros directorios son su espacio de escritura, puede organizar sus archivos Markdown como desee.

**Regreso al idioma nativo: Escribir en el idioma nativo, construir versiones multilingües sin problemas**

La vida es corta, soy demasiado perezoso para traducir. Las personas solo pueden aprovechar al máximo la profundidad de su pensamiento cuando usan su idioma nativo. Pero al mismo tiempo, mantener la conexión con el mundo es necesario, no quiero renunciar a la comunicación multilingüe. Por lo tanto, espero tener una herramienta que me permita escribir en mi idioma nativo y al mismo tiempo permitir que más personas vean mi contenido. La i18n actual no solo requiere que uno mismo traduzca, sino que también requiere mantener las actualizaciones de contenido, es demasiado complicado. Elijo usar LLM para ayudarme con la traducción, ahorrándome mucho tiempo y pudiendo completar la traducción a múltiples idiomas con un solo clic.

## Funciones básicas

1. 🌍 **Traducción automática multilingüe**: Usa IA para traducción incremental, permitiendo a los usuarios escribir Markdown en su idioma nativo, pero los usuarios pueden ser multilingües.
2. 💭 **Extracción automática de resúmenes**: Usa IA para analizar y extraer contenido del texto original.
3. 🏷️ **Clasificación automática de etiquetas**: Usa IA para extraer y gestionar etiquetas y clasificaciones de contenido.
4. 🧭 **Navegación inteligente por categorías**: Usa IA para generar mapas del sitio y navegación, la ubicación de los archivos fuente no es sensible.

## Generación de sitios estáticos (SSG)

CZON tiene integrado un esquema SSG que puede construir cualquier carpeta git que contenga Markdown en un sitio HTML estático.

⚠️ Tenga en cuenta que CZON no es un generador de sitios estáticos (SSG) profesional, sino un motor de contenido Markdown impulsado por IA, enfocado en la creación y gestión de contenido.

✅ CZON tiene como objetivo simplificar el proceso de creación y publicación de contenido, permitiendo a los usuarios concentrarse en la escritura en sí, en lugar de verse obstaculizados por configuraciones y herramientas complejas.

❌ CZON no proporcionará personalizaciones complejas de temas y ecosistemas de complementos, sino que se enfocará en mejorar la calidad y accesibilidad del contenido a través de la IA.

🔔 Sin embargo, CZON aún puede generar sitios estáticos. Si es necesario, CZON puede usarse como preprocesador, integrando otros esquemas SSG para generar sitios personalizados y atractivos.

## Comenzar rápidamente

Requisitos previos:

- [Node.js](https://nodejs.org/) instalado (se recomienda versión 18 o superior, necesita tener el comando npx)
- [Clave API de OpenAI](https://platform.openai.com/account/api-keys) obtenida, o clave API compatible con OPENAI
- Git instalado (para listar archivos Markdown desde Git, ignorando archivos filtrados por reglas .gitignore)

Primero, trabaje en una carpeta ya gestionada por git:

Configurar variables de entorno

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Requerido: reemplace con su clave API de OpenAI
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Opcional, usa la API oficial de OpenAI por defecto
export OPENAI_MODEL="gpt-3.5-turbo"  # Opcional, usa el modelo gpt-3.5-turbo por defecto
export OPENAI_MAX_TOKENS="4096"  # Opcional, establece el límite máximo de tokens (si se omite, usa el valor predeterminado del modelo, para traducciones de texto largo se recomienda establecer un valor más alto, como 8192, dependiendo del número máximo de tokens admitido por el modelo utilizado)
```

Construir el sitio, compatible con traducción multilingüe. Usa el directorio actual como directorio fuente, la salida va al directorio `.czon/dist`.

- Puede especificar las versiones de idioma que necesita generar usando múltiples veces el parámetro `--lang` (por ejemplo, `--lang zh-Hans --lang en-US`).
- No es necesario configurar el idioma fuente, CZON lo detectará automáticamente.

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

**Ver más parámetros o ayuda**:

