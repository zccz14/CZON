# Налаштування сайту

CZON підтримує налаштування параметрів сайту через файл `.czon/meta.json`. Ці налаштування є необов'язковими та не блокують перше використання.

## Розташування конфігурації

Параметри конфігурації знаходяться в полі `options.site` файлу `.czon/meta.json`:

```json
{
  "version": "1.0.0",
  "options": {
    "langs": ["zh-Hans", "en-US"],
    "site": {
      "baseUrl": "https://example.com",
      "title": "My Docs",
      "gaID": "G-XXXXXXXXXX",
      "clarityID": "your-clarity-id",
      "navLinks": [
        { "title": "Головна", "href": "index.html" },
        { "title": "Про нас", "href": "about.html" }
      ]
    }
  },
  "files": []
}
```

## Доступні параметри конфігурації

### `site.baseUrl`

Базова URL-адреса сайту, що використовується для генерації `sitemap.xml` та `robots.txt`.

- **Тип**: `string`
- **Формат**: Повна URL-адреса, наприклад `https://example.com`

```json
{
  "options": {
    "site": {
      "baseUrl": "https://example.com"
    }
  }
}
```

Після налаштування автоматично генеруються:

- `sitemap.xml` — карта сайту, що містить усі сторінки
- Оголошення Sitemap у файлі `robots.txt`

### `site.title`

Назва сайту, що відображається у верхній частині сторінки.

- **Тип**: `string`
- **Значення за замовчуванням**: `"CZON"`

```json
{
  "options": {
    "site": {
      "title": "Мій сайт документації"
    }
  }
}
```

### `site.gaID`

Google Analytics Measurement ID, що використовується для інтеграції статистики Google Analytics.

- **Тип**: `string`
- **Формат**: `G-XXXXXXXXXX`

```json
{
  "options": {
    "site": {
      "gaID": "G-XXXXXXXXXX"
    }
  }
}
```

**Як отримати**: Перейдіть на [Google Analytics](https://analytics.google.com/), створіть ресурс і отримайте Measurement ID у розділі «Потоки даних».

### `site.clarityID`

Microsoft Clarity Project ID, що використовується для інтеграції аналітики поведінки користувачів Clarity.

- **Тип**: `string`

```json
{
  "options": {
    "site": {
      "clarityID": "your-project-id"
    }
  }
}
```

**Як отримати**: Перейдіть на [Microsoft Clarity](https://clarity.microsoft.com/), створіть проект і отримайте Project ID у налаштуваннях проекту.

### `site.navLinks`

Конфігурація швидких навігаційних посилань, що відображаються у верхній частині сторінки.

- **Тип**: `Array<{ title: string, href: string }>`
- **Значення за замовчуванням**: `undefined` (навігація не відображається)

```json
{
  "options": {
    "site": {
      "navLinks": [
        { "title": "Головна", "href": "index.html" },
        { "title": "Документація", "href": "docs.html" },
        { "title": "Про нас", "href": "about.html" }
      ]
    }
  }
}
```

**Адаптивна поведінка**:

- **Мобільні пристрої**: Відображається іконка гамбургер-меню. При натисканні розгортаються всі навігаційні посилання.
- **Десктоп**: Навігаційні посилання відображаються безпосередньо в заголовку, але не більше ніж 40% ширини екрана. Посилання, що не вміщуються, відображаються у випадаючому меню «Більше».

## Повний приклад

```json
{
  "version": "1.0.0",
  "options": {
    "langs": ["zh-Hans", "en-US", "ja-JP"],
    "site": {
      "baseUrl": "https://example.com",
      "title": "Технічний блог",
      "gaID": "G-ABC123DEF4",
      "clarityID": "abc123xyz",
      "navLinks": [
        { "title": "Головна", "href": "index.html" },
        { "title": "Документація", "href": "docs.html" },
        { "title": "Блог", "href": "blog.html" }
      ]
    }
  },
  "files": []
}
```

## Важливі зауваження

- Після зміни конфігурації необхідно повторно запустити `czon build`, щоб зміни набули чинності.
- Усі параметри в полі `site` є необов'язковими. Можна налаштувати лише потрібні частини.
- Інструменти аналітики (GA, Clarity) завантажуються лише після налаштування відповідного ID, що не впливає на продуктивність сторінки.
- Якщо `baseUrl` не налаштовано, генерація `sitemap.xml` буде пропущена.
