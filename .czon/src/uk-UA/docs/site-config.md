# Конфігурація сайту

CZON підтримує налаштування параметрів сайту через файл `.czon/meta.json`. Ці налаштування є необов'язковими та не блокують перше використання.

## Розташування конфігурації

Параметри конфігурації знаходяться в полі `options.site` файлу `.czon/meta.json`:

```json
{
  "version": "1.0.0",
  "options": {
    "langs": ["zh-Hans", "en-US"],
    "site": {
      "baseUrl": "https://example.com",
      "title": "My Docs",
      "home": "guide.html",
      "gaID": "G-XXXXXXXXXX",
      "clarityID": "your-clarity-id",
      "navLinks": [
        { "title": "Головна", "href": "index.html" },
        { "title": "Про нас", "href": "about.html" }
      ]
    }
  },
  "files": []
}
```

## Доступні параметри конфігурації

### `site.baseUrl`

Базова URL-адреса сайту, що використовується для генерації `sitemap.xml` та `robots.txt`.

- **Тип**: `string`
- **Формат**: Повна URL-адреса, наприклад `https://example.com`

```json
{
  "options": {
    "site": {
      "baseUrl": "https://example.com"
    }
  }
}
```

Після налаштування автоматично генеруються:

- `sitemap.xml` — карта сайту, що містить усі сторінки
- Оголошення Sitemap у `robots.txt`

### `site.title`

Заголовок сайту, що відображається у верхній частині сторінки.

- **Тип**: `string`
- **Значення за замовчуванням**: `"CZON"`

```json
{
  "options": {
    "site": {
      "title": "Моя документація"
    }
  }
}
```

### `site.gaID`

Google Analytics Measurement ID, що використовується для інтеграції статистики Google Analytics.

- **Тип**: `string`
- **Формат**: `G-XXXXXXXXXX`

```json
{
  "options": {
    "site": {
      "gaID": "G-XXXXXXXXXX"
    }
  }
}
```

**Як отримати**: Перейдіть на [Google Analytics](https://analytics.google.com/), створіть ресурс і отримайте Measurement ID у розділі «Потоки даних».

### `site.clarityID`

Microsoft Clarity Project ID, що використовується для інтеграції аналітики поведінки користувачів Clarity.

- **Тип**: `string`

```json
{
  "options": {
    "site": {
      "clarityID": "your-project-id"
    }
  }
}
```

**Як отримати**: Перейдіть на [Microsoft Clarity](https://clarity.microsoft.com/), створіть проект і отримайте Project ID у налаштуваннях проекту.

### `site.home`

Налаштування шляху до головної сторінки для кастомізації цілі перенаправлення.

- **Тип**: `string`
- **Значення за замовчуванням**: `"index.html"`

```json
{
  "options": {
    "site": {
      "home": "guide.html"
    }
  }
}
```

**Пояснення поведінки**:

- **При відвідуванні кореневої головної сторінки**: Коли користувач відвідує `/index.html`, він автоматично перенаправляється на `/{визначена мова}/{home}` відповідно до мови браузера.
- **При кліку на заголовок у верхній частині сторінки (Header)**: Перенаправлення на шлях `home` у поточній мовній директорії.

**Сценарії використання**:

- Бажання, щоб користувач при першому відвідуванні потрапляв на певну сторінку (наприклад, посібник зі старту, опис продукту тощо).
- Головна сторінка сайту не є списком статей, а конкретною сторінкою документації.

### `site.navLinks`

Налаштування швидких навігаційних посилань, що відображаються у верхній частині сторінки.

- **Тип**: `Array<{ title: string, href: string }>`
- **Значення за замовчуванням**: `undefined` (навігація не відображається)

```json
{
  "options": {
    "site": {
      "navLinks": [
        { "title": "Головна", "href": "index.html" },
        { "title": "Документація", "href": "docs.html" },
        { "title": "Про нас", "href": "about.html" }
      ]
    }
  }
}
```

**Адаптивна поведінка**:

- **Мобільні пристрої**: Відображається іконка гамбургер-меню, клік розгортає всі навігаційні посилання.
- **Десктоп**: Навігаційні посилання відображаються безпосередньо у верхній частині сторінки (Header), але не більше ніж 40% ширини екрана; посилання, що не вміщуються, відображаються у випадаючому меню «Більше».

## Повний приклад

```json
{
  "version": "1.0.0",
  "options": {
    "langs": ["zh-Hans", "en-US", "ja-JP"],
    "site": {
      "baseUrl": "https://example.com",
      "title": "Технічний блог",
      "home": "getting-started.html",
      "gaID": "G-ABC123DEF4",
      "clarityID": "abc123xyz",
      "navLinks": [
        { "title": "Головна", "href": "index.html" },
        { "title": "Документація", "href": "docs.html" },
        { "title": "Блог", "href": "blog.html" }
      ]
    }
  },
  "files": []
}
```

## Важливі зауваження

- Після зміни конфігурації необхідно повторно запустити `czon build`, щоб зміни набули чинності.
- Усі параметри конфігурації в полі `site` є необов'язковими, можна налаштовувати лише потрібні частини.
- Інструменти аналітики (GA, Clarity) завантажуються лише після налаштування відповідного ID, що не впливає на продуктивність сторінки.
- Якщо `baseUrl` не налаштовано, генерація `sitemap.xml` буде пропущена.
