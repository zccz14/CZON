# Техніки використання

## Оголошення дати в тексті

У тексті можна використовувати оголошення дати на кшталт "Сьогодні 8 січня 2026 року" (формат і стиль вільні), CZON автоматично розпізнає та обробить його.

Традиційні документи Markdown оголошують дату через YAML Frontmatter, що вимагає пам'ятати відповідні поля, інакше дата може бути неправильно розпізнана.

CZON підтримує безпосереднє оголошення дати в тексті, що дозволяє уникнути проблеми забуття заповнити поля Frontmatter.

ШІ автоматично витягне та виведе інформацію про дату з тексту та обробить її як дату створення документа.

Цей спосіб є більш гнучким та розумним, покращуючи користувацький досвід.

До речі, документи з датами можуть генерувати подання у вигляді часової шкали, що зручно для перегляду та управління. Особливо підходить для таких типів контенту, як щоденники, блоги, які потребують часової шкали.
