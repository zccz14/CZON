# Користувацькі стилі

CZON підтримує налаштування стилів сайту через файл `.czon/style.css`, що дозволяє перевизначати стилі за замовчуванням або додавати індивідуальний вигляд.

## Використання

1. Створіть файл `style.css` у каталозі `.czon` вашого проекту:

```
ваш-проект/
├── .czon/
│   ├── meta.json
│   └── style.css    <-- створіть цей файл
├── README.md
└── docs/
```

2. Напишіть ваш CSS-код у файлі `style.css`:

```css
/* Приклад: зміна кольору посилань */
:root {
  --link-color: #0066cc;
}

/* Приклад: зміна фону в темному режимі */
html.dark {
  --bg-primary: #0d1117;
}
```

3. Запустіть `czon build` знову — користувацькі стилі автоматично застосуються до всіх сторінок.

## Принцип роботи

- Під час збірки CZON перевіряє наявність файлу `.czon/style.css`
- Якщо файл існує, він копіюється у вихідний каталог `.czon/dist/style.css`
- У кожній згенерованій HTML-сторінці в `<head>` додається посилання на стилі:
  ```html
  <link rel="stylesheet" href="style.css" />
  ```
- Користувацькі стилі завантажуються після вбудованих, тому можуть їх перевизначати

## Доступні CSS-змінні

CZON використовує CSS-змінні для визначення кольорів теми. Ви можете швидко змінити палітру, перевизначивши ці змінні:

```css
:root {
  /* Кольори фону */
  --bg-primary: #ffffff;
  --bg-secondary: #f8f9fa;
  --bg-tertiary: #e9ecef;

  /* Кольори тексту */
  --text-primary: #333333;
  --text-secondary: #6c757d;
  --text-muted: #adb5bd;

  /* Кольори посилань та акцентів */
  --link-color: #007bff;
  --link-hover-color: #0056b3;

  /* Кольори рамок */
  --border-color: #dee2e6;
}

/* Змінні для темного режиму */
html.dark {
  --bg-primary: #1a1a1a;
  --bg-secondary: #2d2d2d;
  --bg-tertiary: #404040;

  --text-primary: #e5e5e5;
  --text-secondary: #a0a0a0;
  --text-muted: #6c6c6c;

  --link-color: #58a6ff;
  --link-hover-color: #79b8ff;

  --border-color: #404040;
}
```

## Приклади

### Налаштування фірмового кольору

```css
:root {
  --link-color: #e91e63;
  --link-hover-color: #c2185b;
}

html.dark {
  --link-color: #f48fb1;
  --link-hover-color: #f8bbd9;
}
```

### Зміна ширини області вмісту

```css
.content {
  max-width: 60rem;
}
```

### Стилізація блоків коду

```css
pre code {
  font-family: 'Fira Code', 'JetBrains Mono', monospace;
  font-size: 0.875rem;
}
```

### Приховування певних елементів

```css
/* Приховує праву бічну панель змісту */
.sidebar-right {
  display: none;
}
```

## Важливі зауваження

- Файл користувацьких стилів має називатися `style.css` і розташовуватися в каталозі `.czon/`
- Після зміни стилів потрібно знову запустити `czon build`, щоб зміни набули чинності
- Рекомендується використовувати перевизначення CSS-змінних для налаштування стилів — це забезпечить сумісність зі світлим і темним режимами
- CZON використовує Tailwind CSS; якщо потрібно перевизначити стилі, згенеровані Tailwind, можливо, знадобиться використати `!important`
