# Розгортання на GitHub Pages

Цей посібник описує, як розгорнути багатомовний статичний сайт, згенерований CZON, на GitHub Pages за допомогою GitHub CLI.

Спочатку встановіть інструмент [GitHub CLI](https://cli.github.com/) (якщо він ще не встановлений) і переконайтеся, що ви увійшли в систему (якщо ще не увійшли):

```bash
$ gh --version # Перевірте версію, щоб переконатися в успішному встановленні
```

Переконайтеся, що ви увійшли в систему і маєте дозвіл `repo` для доступу до цільового репозиторію:

```bash
$ gh auth login -s repo # Увійдіть у обліковий запис GitHub; буде запропоновано увійти через браузер або використовуючи токен
$ gh auth status # Перевірте статус входу, переконайтеся, що успішно увійшли та маєте дозвіл repo для доступу до цільового репозиторію
```

Після цього достатньо виконати наступну команду та дотримуватися підказок:

```bash
$ npx czon@latest config github
```

Ця команда проведе вас через наступні кроки:

1.  Перевірить, чи включає дозвіл `gh` доступ до `repo`; якщо ні, запропонує увійти знову та додати дозвіл `repo`.
2.  Якщо локальна директорія не є Git-репозиторієм, запропонує ініціалізувати новий Git-репозиторій.
3.  Перевірить налаштування віддаленого Git-репозиторію для локальної директорії, щоб переконатися, чи є віддалений репозиторій GitHub. Якщо віддаленого репозиторію GitHub немає, запропонує створити новий віддалений репозиторій та додати його як `origin`. Якщо `origin` вже існує, але не є репозиторієм GitHub, запропонує додати новий віддалений репозиторій GitHub як `upstream`.
4.  Перевірить, чи увімкнено GitHub Pages і чи має він тип `workflow`. Якщо ні, через API `gh api` увімкне його та налаштує розгортання з Actions. Також налаштує CNAME (якщо у вас є власний домен).
5.  Перевірить файл GitHub Workflow. Якщо він не створений, створить файл Workflow для Pages; якщо він вже існує, але не є останньою версією, запропонує оновити файл Workflow.
6.  Зробить коміт файлу Workflow та відправить зміни до віддаленого репозиторію.
7.  Запропонує перейти за URL-адресою сайту GitHub Pages, отримавши останню URL-адресу Pages через `gh api`.
