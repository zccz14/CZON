# CZON - AI-нативний рушій вмісту Markdown

- **C**: **C**ontent oriented | Контент — це король, фокус на вмісті
- **Z**: **Z**ero Configuration | Написання без конфігурації, менше відволікань
- **O**: **O**rganic AI-Native | Органічна AI-нативність, глибока інтеграція AI
- **N**: **N**-shaped Energy Curve | N-подібна крива енергії, що охоплює всі етапи: створення, поширення, зворотний зв'язок

[> Демо сайту](https://czon.zccz14.com/)

В епоху AI ми, як творці веб-контенту, можемо мати більш розумний рушій для створення контенту.

**Повернення до контенту: мінімум відволікань, фокус на написанні**

Поверніть документам їхню сутність, а написанню — спокій.

По-перше, я не хочу бути бібліотекарем. Іноді я хочу щось записати, але можливо ще не визначився з заголовком або структурою. Я хочу, щоб LLM автоматично генерував заголовки, робив резюме, класифікував, створював навігацію та виконував іншу організаційну роботу.

По-друге, мій кабінет має бути чистим. Я не хочу складних інструментів збірки, заплутаних конфігурацій документів або складної структури. Кожного разу, коли я бачу конфігураційні файли та структуру проектів таких інструментів, як Docusaurus, VuePress, Astro, у мене починає боліти голова. Тепер CZON вирішив сховати всю конфігурацію в каталог `.czon`, засунувши її в кут, щоб користувач міг зосередитися лише на написанні контенту, а все інше залишити CZON. Всі інші каталоги — це ваш робочий простір, ви можете організовувати свої файли Markdown як завгодно.

**Повернення до рідної мови: пишіть рідною мовою, легко створюйте багатомовні версії**

Життя коротке, мені ліньки перекладати. Людина найкраще розкриває глибину своїх думок, коли використовує рідну мову. Але водночас необхідно підтримувати зв'язок зі світом, і я не хочу відмовлятися від багатомовного спілкування. Тому мені потрібен інструмент, який дозволить мені писати рідною мовою, але водночас дозволить більшій кількості людей побачити мій контент. Сучасні рішення i18n не лише вимагають самостійного перекладу, але й самостійного оновлення контенту, що занадто складно. Я вирішив використовувати LLM для перекладу, що заощадило мені багато часу та дозволяє одним клацанням перекласти контент на кілька мов.

## Основні функції

1.  🌍 **Автоматичний багатомовний переклад**: Використовує AI для інкрементного перекладу, дозволяючи користувачам писати Markdown рідною мовою, але отримувати багатомовний контент.
2.  💭 **Автоматичне витягнення резюме**: Використовує AI для аналізу та витягнення ключових моментів з оригінального тексту.
3.  🏷️ **Автоматична класифікація тегів**: Використовує AI для витягнення та управління тегами та категоріями контенту.
4.  🧭 **Інтелектуальна навігація за категоріями**: Використовує AI для генерації карти сайту та навігації, незалежно від розташування вихідних файлів.

## Генерація статичних сайтів (SSG)

CZON має вбудоване рішення SSG, яке може перетворити будь-яку папку Git з файлами Markdown на статичний HTML-сайт.

⚠️ Будь ласка, зверніть увагу, що CZON не є професійним генератором статичних сайтів (SSG), а є AI-орієнтованим рушієм вмісту Markdown, зосередженим на створенні та управлінні контентом.

✅ CZON покликаний спростити процес створення та публікації контенту, дозволяючи користувачам зосередитися на самому написанні, а не на складних налаштуваннях та інструментах.

❌ CZON не надаватиме складних опцій кастомізації тем та екосистеми плагінів, а зосередиться на покращенні якості та доступності контенту за допомогою AI.

🔔 Однак CZON все одно може генерувати статичні сайти. За потреби, CZON можна використовувати як препроцесор, інтегруючи його з іншими рішеннями SSG для створення персоналізованих та естетичних сайтів.

## Швидкий старт

Передумови:

-   Встановлений [Node.js](https://nodejs.org/) (рекомендована версія 18 або вище, потрібна команда `npx`)
-   Отриманий [OpenAI API Key](https://platform.openai.com/account/api-keys) або сумісний з OpenAI API Key
-   Встановлений Git (для отримання списку файлів Markdown з Git, ігноруючи файли, відфільтровані за правилами `.gitignore`)

Спочатку працюйте в папці, яка вже знаходиться під управлінням Git:

Налаштуйте змінні середовища

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Обов'язково: замініть на ваш OpenAI API Key
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Опціонально, за замовчуванням використовується офіційний API OpenAI
export OPENAI_MODEL="gpt-3.5-turbo"  # Опціонально, за замовчуванням використовується модель gpt-3.5-turbo
export OPENAI_MAX_TOKENS="4096"  # Опціонально, встановіть обмеження на максимальну кількість токенів (якщо пропустити, використовується значення за замовчуванням моделі; для перекладу довгих текстів рекомендується встановити більше значення, наприклад 8192, залежно від максимальної кількості токенів, що підтримується використовуваною моделлю)
```

Зберіть сайт з підтримкою багатомовного перекладу. Використовуйте поточний каталог як вихідний, результат буде в каталозі `.czon/dist`.

-   Можна вказати мовні версії для генерації, багаторазово використовуючи параметр `--lang` (наприклад, `--lang uk-UA --lang en-US`).
-   Вихідну мову налаштовувати не потрібно, CZON визначить її автоматично.

```bash
npx czon@latest build --lang uk-UA --lang en-US
```

**Переглянути більше параметрів або отримати довідку**:

```bash
npx czon@latest
```
