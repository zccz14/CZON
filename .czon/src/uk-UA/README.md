# CZON - AI-нативний рушій вмісту Markdown

- **C**: **C**ontent oriented | Контент — це король, зосередженість на вмісті
- **Z**: **Z**ero Configuration | Написання без конфігурації, менше відволікань
- **O**: **O**rganic AI-Native | Органічна AI-нативність, глибока інтеграція AI
- **N**: **N**-shaped Energy Curve | N-подібна крива енергії, втручання в кожен етап: створення-розповсюдження-зворотний зв'язок

В епоху AI ми, як творці веб-контенту, можемо мати більш розумний рушій для створення контенту.

**Повернення до контенту: мінімізація відволікань, зосередженість на написанні**

Поверніть документам їхню сутність, а написанню — спокій.

По-перше, я не хочу бути бібліотекарем. Іноді я хочу щось записати, але можливо ще не визначився з заголовком або структурою. Я хочу, щоб LLM автоматично генерував для мене заголовки, робив резюме, класифікував, створював навігацію та іншу організаційну роботу.

По-друге, мій кабінет має бути чистим. Я не хочу складних інструментів збірки, заплутаної конфігурації документів, складної структури. Кожного разу, коли я бачу файли конфігурації та структуру проектів таких інструментів, як Docusaurus, VuePress, Astro, у мене болить голова. Тепер CZON вирішив сховати всю конфігурацію в каталог `.czon`, засунути її в куток, щоб користувач міг зосередитися лише на написанні контенту, а все інше залишити CZON. Всі інші каталоги — це ваш робочий простір, ви можете організовувати свої файли Markdown як завгодно.

**Повернення до рідної мови: пишіть рідною мовою, легко створюйте багатомовні версії**

Життя коротке, мені ліньки перекладати. Людина найкраще розкриває глибину своїх думок, коли використовує рідну мову. Але водночас необхідно підтримувати зв'язок зі світом, я не хочу відмовлятися від багатомовного спілкування. Тому я хочу мати інструмент, який дозволить мені писати рідною мовою, але водночас дозволить більшій кількості людей побачити мій контент. Сучасні i18n вимагають не лише власного перекладу, але й самостійного оновлення контенту, це занадто складно. Я вибираю використання LLM для перекладу, це заощаджує мені багато часу та дозволяє одним кліком перекласти на багато мов.

## ✨ Основні функції

1.  🌍 **AI багатомовний переклад**: Використання AI для інкрементного перекладу, дозволяє користувачам писати Markdown рідною мовою, але контент може бути багатомовним.
2.  📊 **AI витягнення метаданих**: Автоматичне витягнення заголовків, описів, резюме, ключових слів, цільової аудиторії, URL-дружніх псевдонімів тощо.
3.  🏷️ **AI класифікація тегів**: Використання AI для витягнення та управління тегами та категоріями контенту.
4.  🧭 **AI навігація за категоріями**: Використання AI для генерації карти сайту та навігації, розташування вихідних файлів не має значення.
5.  🤖 **AI резюме всього сайту**: Можливість генерації резюме всього сайту в різних стилях.

А також деякі не-AI функції:

1.  ⚙️ **Нульова конфігурація**: Вся конфігурація та кеш сховані в каталозі `.czon`, структура проекту залишається акуратною.
2.  🔄 **Інкрементна збірка**: Виявлення змін на основі хешу вмісту, обробляються лише змінені файли.
3.  📚 **Підтримка розширень Markdown**: Нативна підтримка математичних формул KaTeX, діаграм Mermaid, каруселей Embla, виносок тощо.
4.  🚀 **Генерація статичних сайтів**: Вбудована SSG на основі React, що генерує багатомовні статичні сайти.
5.  🌐 **Автоматична маршрутизація за мовою відвідувача**: Автоматичне перенаправлення на відповідну мовну версію залежно від мови відвідувача.

## 📦 Швидкий старт

### Передумови

-   Встановлений [Node.js](https://nodejs.org/) (рекомендовано використовувати LTS версію 24 або версію 18 та вище, потрібна команда `npx`)
-   Отриманий [OpenAI API Key](https://platform.openai.com/account/api-keys) або сумісний з OPENAI API Key
-   Встановлений Git (для отримання списку файлів Markdown з Git, ігноруючи файли, відфільтровані за правилами .gitignore)

### Налаштування змінних середовища

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Обов'язково: замініть на ваш OpenAI API Key
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Опціонально, за замовчуванням використовується офіційний API OpenAI
export OPENAI_MODEL="gpt-3.5-turbo"  # Опціонально, за замовчуванням використовується модель gpt-3.5-turbo
export OPENAI_MAX_TOKENS="4096"  # Опціонально, встановлює обмеження на максимальну кількість токенів (якщо пропустити, використовується значення за замовчуванням моделі; для перекладу довгих текстів рекомендується встановити більше значення, наприклад 8192, залежно від максимальної кількості токенів, що підтримується використовуваною моделлю)

# Якщо потрібен HTTP-проксі для доступу до OpenAI API, можна встановити наступні змінні
export HTTPS_PROXY="http://your-proxy.com:8080"  # Опціонально, встановлює HTTPS-проксі
export HTTP_PROXY="http://your-proxy.com:8080"   # Опціонально, встановлює HTTP-проксі
```

### Побудова багатомовного сайту

Запустіть у будь-якій папці, що керується Git:

```bash
npx czon@latest build --lang uk-UA --lang en-US
```

Оскільки коди мов надалі будуть використовуватися в багатьох функціях генерації статичних сайтів, переконайтеся, що використовуєте коди мов за стандартом BCP 47. Наприклад, `uk-UA` представляє українську мову, `en-US` — американську англійську. Ви можете додати більше мов за потребою, наприклад `es-ES` (іспанська), `ja-JP` (японська), `ko-KR` (корейська) тощо.
Список стандартних кодів мов дивіться за посиланням [IETF language tag - Wikipedia](https://en.wikipedia.org/wiki/IETF_language_tag#List_of_common_primary_language_subtags).

Вихідний каталог: `.czon/dist`. Потім потрібно розгорнути вміст цього каталогу на платформі для хостингу статичних сайтів.

Детальніше про використання: запустіть `npx czon@latest --help`.

CZON позиціонується як **AI-покращений рушій вмісту**, а не повноцінний SSG. Він зосереджений на підвищенні ефективності створення контенту за допомогою AI і підходить для авторів, які цінують якість контенту та хочуть зменшити навантаження від конфігурації. Фактично, CZON можна використовувати разом з інструментами SSG, такими як Docusaurus, VuePress, Astro, як фронтенд-рушій для генерації та управління контентом.
