# CZON - Motore di contenuti Markdown AI-Native

- **C**: **C**ontent oriented | Orientato al contenuto, concentrato sul contenuto
- **Z**: **Z**ero Configuration | Scrittura a configurazione zero, riduzione delle interruzioni
- **O**: **O**rganic AI-Native | AI-Native organica, integrazione profonda dell'AI
- **N**: **N**-shaped Energy Curve | Curva energetica a forma di N, coinvolta in tutte le fasi di creazione-distribuzione-feedback

[> Demo del sito web](https://czon.zccz14.com/)

Nell'era dell'AI, come creatori di contenuti per siti web, possiamo avere un motore di creazione di contenuti più intelligente.

**Ritorno al contenuto: minimizzare le interruzioni, concentrarsi sulla scrittura**

Riportare i documenti alla loro essenza, riportare la scrittura alla tranquillità.

In primo luogo, non voglio fare il bibliotecario. A volte voglio scrivere qualcosa, ma potrei non aver ancora pensato al titolo, non aver formato un'organizzazione particolare. Spero che l'LLM generi automaticamente titoli, crei riassunti, classifichi, navighi e organizzi il lavoro.

In secondo luogo, il mio studio deve essere pulito. Non voglio strumenti di costruzione con configurazioni complesse, non voglio configurazioni di documenti complicate, non mi piacciono strutture complesse. Ogni volta che vedo i file di configurazione e le strutture di progetto di strumenti come Docusaurus, VuePress, Astro, mi viene il mal di testa. Ora, CZON sceglie di nascondere tutte le configurazioni nella directory .czon, spazzandole in un angolo, permettendo agli utenti di concentrarsi solo sulla scrittura dei contenuti, lasciando il resto a CZON. Le altre directory sono il vostro spazio di scrittura, potete organizzare i vostri file Markdown come preferite.

**Ritorno alla lingua madre: scrivere nella lingua madre, costruire versioni multilingue senza intoppi**

La vita è breve, sono troppo pigro per tradurre. Quando si usa la lingua madre, si esprime al meglio la profondità del proprio pensiero. Ma allo stesso tempo, rimanere connessi con il mondo è necessario, non voglio rinunciare alla comunicazione multilingue. Quindi spero che ci sia uno strumento che mi permetta di scrivere nella mia lingua madre, ma anche di far vedere i miei contenuti a più persone. L'attuale i18n non solo richiede di tradurre da soli, ma anche di mantenere aggiornati i contenuti, è troppo complicato. Scelgo di usare l'LLM per aiutarmi a tradurre, risparmiandomi molto tempo, e posso completare la traduzione in più lingue con un clic.

## Funzionalità di base

1. 🌍 **Traduzione automatica multilingue**: Utilizza l'AI per la traduzione incrementale, permettendo agli utenti di scrivere Markdown nella loro lingua madre, ma gli utenti possono essere multilingue.
2. 💭 **Estrazione automatica di riassunti**: Utilizza l'AI per analizzare ed estrarre contenuti dal testo originale.
3. 🏷️ **Classificazione automatica dei tag**: Utilizza l'AI per estrarre e gestire tag e classificazioni dei contenuti.
4. 🧭 **Navigazione intelligente per categorie**: Utilizza l'AI per generare mappe del sito e navigazione, la posizione dei file sorgente non è sensibile.

## Generazione di siti statici (SSG)

CZON include una soluzione SSG integrata che può costruire qualsiasi cartella git contenente Markdown in un sito HTML statico.

⚠️ Nota: CZON non è un generatore di siti statici (SSG) professionale, ma un motore di contenuti Markdown guidato dall'AI, concentrato sulla creazione e gestione dei contenuti.

✅ CZON mira a semplificare il processo di creazione e pubblicazione dei contenuti, permettendo agli utenti di concentrarsi sulla scrittura stessa, piuttosto che essere ostacolati da configurazioni e strumenti complessi.

❌ CZON non fornirà personalizzazioni complesse di temi ed ecosistemi di plugin, ma si concentrerà sul miglioramento della qualità e dell'accessibilità dei contenuti attraverso l'AI.

🔔 Tuttavia, CZON può ancora generare siti statici, se necessario, CZON può essere utilizzato come preprocessore, integrato con altre soluzioni SSG per generare siti personalizzati e belli.

## Inizio rapido

Prerequisiti:

- Installato [Node.js](https://nodejs.org/) (versione consigliata 18 o superiore, necessario il comando npx)
- Ottenuta [OpenAI API Key](https://platform.openai.com/account/api-keys), o una chiave API compatibile con OPENAI
- Installato Git (utilizzato per elencare i file Markdown da Git, ignorando i file filtrati dalle regole .gitignore)

Innanzitutto, lavorare in una cartella già gestita da git:

Configurare le variabili d'ambiente

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Obbligatorio: sostituire con la propria chiave API OpenAI
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Opzionale, per impostazione predefinita utilizza l'API ufficiale OpenAI
export OPENAI_MODEL="gpt-3.5-turbo"  # Opzionale, per impostazione predefinita utilizza il modello gpt-3.5-turbo
export OPENAI_MAX_TOKENS="4096"  # Opzionale, impostare il limite massimo di token (se ignorato, utilizza il valore predefinito del modello, per la traduzione di testi lunghi si consiglia di impostare un valore più alto, ad esempio 8192, a seconda del numero massimo di token supportato dal modello utilizzato)
```

Costruire il sito, supportando la traduzione multilingue. Utilizzare la directory corrente come directory sorgente, output nella directory `.czon/dist`.

- È possibile specificare le versioni linguistiche da generare utilizzando più volte il parametro `--lang` (ad esempio `--lang it-IT --lang en-US`).
- Non è necessario configurare la lingua sorgente, CZON rileverà automaticamente.

```bash
npx czon@latest build --lang it-IT --lang en-US
```

**Visualizzare più parametri o aiuto**:

```bash
npx czon@latest
```
