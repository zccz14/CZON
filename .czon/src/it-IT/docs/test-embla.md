# Test degli Effetti del Carosello Embla

Questo è un documento per testare gli effetti del carosello Embla.

Più immagini consecutive vengono visualizzate come un carosello, e gli utenti possono passare da una vista all'altra cliccando sulle frecce o trascinando le immagini.

Se invece si inserisce del testo tra le immagini, la continuità del carosello viene interrotta, formando un nuovo gruppo di caroselli.
