# Tecniche di Utilizzo

## Dichiarare la Data nel Corpo del Testo

Nel corpo del testo, puoi utilizzare dichiarazioni di data come "Oggi è l'8 gennaio 2026" (lo stile del formato è libero). CZON le riconoscerà e le elaborerà automaticamente.

I documenti Markdown tradizionali dichiarano la data tramite il Frontmatter YAML, richiedendo di ricordare il campo corrispondente; altrimenti, la data potrebbe non essere riconosciuta correttamente.

CZON supporta la dichiarazione diretta della data nel corpo del testo, evitando il problema di dimenticare di compilare i campi del Frontmatter.

L'IA estrae e deduce automaticamente le informazioni sulla data dal corpo del testo e le elabora come data di creazione del documento.

Questo metodo è più flessibile e intelligente, migliorando l'esperienza utente.

Inoltre, i documenti con date possono generare una vista cronologica, facilitando la navigazione e la gestione. È particolarmente adatto per tipi di contenuto che richiedono una cronologia, come diari e blog.
