# CZON - AI-Native Markdown İçerik Motoru

- **C**: **C**ontent oriented | İçerik odaklı, içeriğe konsantre
- **Z**: **Z**ero Configuration | Sıfır yapılandırma yazımı, rahatsızlığı azaltır
- **O**: **O**rganic AI-Native | Organik AI-native, AI'ı derinlemesine entegre eder
- **N**: **N**-shaped Energy Curve | N şekilli enerji eğrisi, yaratım-dağıtım-geri bildirim döngüsünün her aşamasına müdahale eder

[> Website Demo](https://czon.zccz14.com/)

AI çağında, web sitesi içerik yaratıcıları olarak daha akıllı içerik oluşturma motorlarına sahip olabiliriz.

**İçeriğe Dönüş: Minimum Rahatsızlık, Yazmaya Odaklanma**

Belgeleri özüne döndürün, yazmayı huzura döndürün.

Birincisi, kütüphaneci olmak istemiyorum. Bazen bazı içerikler yazmak istiyorum ama henüz başlığını düşünmemiş olabilirim, özel bir organizasyon oluşturmamış olabilirim. LLM'in otomatik olarak başlık oluşturmasını, özet çıkarmasını, sınıflandırma yapmasını, gezinme gibi düzenleme işlerini yapmasını umuyorum.

İkincisi, çalışma odam temiz olmalı. Karmaşık yapılandırma araçları, karmaşık belge yapılandırmaları, karmaşık yapılar istemiyorum. Docusaurus, VuePress, Astro gibi araçların yapılandırma dosyalarını ve proje yapılarını her gördüğümde başım ağrıyor. Şimdi, CZON tüm yapılandırmaları .czon dizinine gizlemeyi, köşeye süpürmeyi seçiyor. Kullanıcılar sadece yazma içeriğine odaklanıyor, gerisini CZON hallediyor. Diğer dizinler sizin yazma alanınızdır, Markdown dosyalarınızı istediğiniz gibi düzenleyebilirsiniz.

**Ana Dile Dönüş: Ana Dilinizde Yazın, Çok Dilli Sürümleri Sorunsuz Oluşturun**

Hayat kısa, çeviri yapmaya üşeniyorum. İnsanlar ana dillerini kullanırken kendi düşünme derinliklerini en iyi şekilde ortaya koyabilirler. Ancak aynı zamanda dünyayla bağlantıda kalmak gereklidir, çok dilli iletişimi bırakmak istemiyorum. Bu nedenle, ana dilimde yazmama izin veren, aynı zamanda içeriğimi daha fazla kişinin görmesini sağlayan bir araç istiyorum. Mevcut i18n kendiniz çeviri yapmanızı gerektirmez, ayrıca içerik güncellemelerini kendiniz yönetmeniz gerekir, bu çok zahmetli. Çeviri yapmak için LLM kullanmayı seçiyorum, bu bana çok zaman kazandırıyor ve tek tıklamayla çoklu dil çevirisi yapabiliyorum.

## Temel Özellikler

1. 🌍 **Otomatik Çok Dilli Çeviri**: AI kullanarak artımlı çeviri yapar, kullanıcıların ana dillerinde Markdown yazmalarını sağlar, ancak kullanıcılar çok dilli olabilir.
2. 💭 **Otomatik Özet Çıkarma**: AI kullanarak orijinal metni analiz eder ve özet çıkarır.
3. 🏷️ **Otomatik Etiket Sınıflandırması**: AI kullanarak içeriği etiketler ve sınıflandırır, yönetir.
4. 🧭 **Akıllı Sınıflandırma Gezinmesi**: AI kullanarak site haritası ve gezinme oluşturur, kaynak dosya konumu hassas değildir.

## Statik Site Oluşturma (SSG)

CZON, herhangi bir Markdown içeren git klasörünü statik bir HTML sitesine dönüştürebilen yerleşik bir SSG çözümüne sahiptir.

⚠️ Lütfen dikkat: CZON profesyonel bir statik site oluşturucu (SSG) değil, AI destekli bir Markdown içerik motorudur, içerik oluşturma ve yönetime odaklanır.

✅ CZON, içerik oluşturma ve yayınlama sürecini basitleştirmeyi amaçlar, kullanıcıların yazmanın kendisine odaklanmasını sağlar, karmaşık yapılandırma ve araçlarla uğraşmaz.

❌ CZON karmaşık tema özelleştirmeleri ve eklenti ekosistemi sağlamaz, AI aracılığıyla içeriğin kalitesini ve erişilebilirliğini artırmaya odaklanır.

🔔 Ancak, CZON yine de statik site oluşturabilir, gerekirse CZON'u ön işlemci olarak kullanabilir, diğer SSG çözümleriyle entegre ederek kişiselleştirilmiş, güzel siteler oluşturabilirsiniz.

## Hızlı Başlangıç

Ön koşullar:

- [Node.js](https://nodejs.org/) kurulu (önerilen sürüm 18 ve üzeri, npx komutu olmalı)
- [OpenAI API Key](https://platform.openai.com/account/api-keys) alınmış veya OPENAI uyumlu API Key
- Git kurulu (Git'ten Markdown dosyalarını listelemek, .gitignore kurallarıyla filtrelenen dosyaları yok saymak için)

İlk olarak, git tarafından yönetilen bir klasörde çalışın:

Ortam değişkenlerini yapılandırın

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Zorunlu: Lütfen OpenAI API Key'inizle değiştirin
export OPENAI_BASE_URL="https://api.openai.com/v1"  # İsteğe bağlı, varsayılan olarak OpenAI resmi API'sini kullanır
export OPENAI_MODEL="gpt-3.5-turbo"  # İsteğe bağlı, varsayılan olarak gpt-3.5-turbo modelini kullanır
export OPENAI_MAX_TOKENS="4096"  # İsteğe bağlı, maksimum token sayısı sınırını ayarlar (yok sayılırsa modelin varsayılan değeri kullanılır, uzun metin çevirileri için daha yüksek değerler önerilir, örneğin 8192, kullanılan modelin desteklediği maksimum token sayısına bağlı olarak)
```

Siteyi oluşturun, çok dilli çeviriyi destekler. Kaynak dizin olarak geçerli dizini kullanır, `.czon/dist` dizinine çıktı verir.

- `--lang` parametresini birden çok kez kullanarak oluşturulacak dil sürümlerini belirtebilirsiniz (örneğin `--lang zh-Hans --lang en-US`).
- Kaynak dili yapılandırmaya gerek yoktur, CZON otomatik olarak algılar.

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

**Daha fazla parametre veya yardım görüntüleyin**:

```bash
npx czon@latest
```
