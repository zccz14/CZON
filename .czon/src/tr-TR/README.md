# CZON - AI-Native Markdown İçerik Motoru

- **C**: **C**ontent oriented | İçerik Kraldır, İçeriğe Odaklan
- **Z**: **Z**ero Configuration | Sıfır Yapılandırmalı Yazma, Rahatsızlığı Azalt
- **O**: **O**rganic AI-Native | Organik AI-Native, AI'ı Derinlemesine Entegre Et
- **N**: **N**-shaped Energy Curve | N Şekilli Enerji Eğrisi, Oluşturma-Dağıtım-Geri Bildirim Süreçlerinin Her Aşamasına Dahil Ol

AI çağında, web sitesi içerik üreticileri olarak daha akıllı bir içerik oluşturma motoruna sahip olabiliriz.

**İçeriğe Dönüş: Müdahaleyi En Aza İndir, Yazmaya Odaklan**

Belgeleri özüne döndür, yazmayı huzura kavuştur.

Birincisi, kütüphaneci olmak istemiyorum. Bazen bir şeyler yazmak istiyorum ama henüz başlığını düşünmemiş, özel bir organizasyon oluşturmamış olabilirim. LLM'nin başlık oluşturma, özet çıkarma, sınıflandırma, navigasyon gibi düzenleme işlerini otomatik olarak yapmasını umuyorum.

İkincisi, çalışma odam temiz olmalı. Karmaşık yapılandırmalı derleme araçları, karmaşık belge yapılandırmalarıyla uğraşmak, karmaşık yapıları istemiyorum. Docusaurus, VuePress, Astro gibi araçların yapılandırma dosyalarını ve proje yapılarını her gördüğümde başım ağrıyor. Şimdi, CZON tüm yapılandırmaları `.czon` dizinine gizlemeyi, köşeye süpürmeyi seçiyor; kullanıcı sadece yazma içeriğine odaklanıyor, gerisini CZON hallediyor. Diğer tüm dizinler sizin yazma alanınız, Markdown dosyalarınızı istediğiniz gibi düzenleyebilirsiniz.

**Ana Dile Dönüş: Ana Dilinde Yaz, Sorunsuz Çok Dilli Sürümler Oluştur**

Hayat kısa, çeviri yapmaya üşeniyorum. İnsan ana dilini kullanırken düşünme derinliğini en iyi şekilde ortaya koyabilir. Ancak aynı zamanda dünyayla bağlantıyı sürdürmek de gerekli, çok dilli iletişimi bırakmak istemiyorum. Bu yüzden, ana dilimde yazmama izin veren, aynı zamanda içeriğimi daha fazla kişinin görmesini sağlayan bir araç istiyorum. Mevcut i18n sadece kendi çevirinizi yapmanızı değil, aynı zamanda içerik güncellemelerini de kendinizin yönetmesini gerektiriyor, çok zahmetli. Çevirilerimi yapması için LLM kullanmayı seçiyorum, bu bana çok zaman kazandırıyor ve tek tıkla çok sayıda dil çevirisi yapılabiliyor.

## ✨ Temel Özellikler

1. 🌍 **AI Çok Dilli Çeviri**: Kullanıcıların ana dilinde Markdown yazmasına izin veren, ancak kullanıcıların çok dilli olabileceği, AI kullanarak artımlı çeviri.
2. 📊 **AI Meta Veri Çıkarımı**: Başlık, açıklama, özet, anahtar kelimeler, hedef kitle, URL dostu takma ad vb. otomatik çıkarım.
3. 🏷️ **AI Etiket Sınıflandırması**: İçeriğin etiket ve kategori çıkarımı ve yönetimi için AI kullanımı.
4. 🧭 **AI Sınıflandırma Navigasyonu**: Site haritası ve navigasyon oluşturmak için AI kullanımı, kaynak dosya konumu duyarsız.
5. 🤖 **AI Tüm Site Özeti**: Çeşitli stillerde tüm site özeti oluşturma.

Ve bazı AI olmayan özellikler:

1. ⚙️ **Sıfır Yapılandırma**: Tüm yapılandırma ve önbellekler `.czon` dizininde gizli, proje yapısı temiz kalır.
2. 🔄 **Artımlı Derleme**: İçerik hash'ine dayalı değişiklik tespiti, sadece değişen dosyaları işler.
3. 📚 **Markdown Uzantı Desteği**: KaTeX matematik formülleri, Mermaid diyagramları, Embla slayt gösterisi, dipnotlar vb. için yerel destek.
4. 🚀 **Statik Site Oluşturma**: React tabanlı SSG yerleşik, çok dilli statik siteler oluşturur.
5. 🌐 **Ziyaretçi Diline Göre Otomatik Yönlendirme**: Ziyaretçinin diline göre otomatik olarak ilgili dil sürümüne yönlendirir.

## 📦 Hızlı Başlangıç

### Ön Koşullar

- [Node.js](https://nodejs.org/) kurulu (LTS sürüm 24 veya 18 ve üzeri önerilir, npx komutu gereklidir)
- [OpenAI API Anahtarı](https://platform.openai.com/account/api-keys) edinilmiş veya OPENAI uyumlu bir API Anahtarı
- Git kurulu (Git'ten Markdown dosyalarını listelemek ve .gitignore kurallarıyla filtrelenen dosyaları yok saymak için)

### Ortam Değişkenleri Yapılandırması

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Zorunlu: Lütfen OpenAI API Anahtarınızla değiştirin
export OPENAI_BASE_URL="https://api.openai.com/v1"  # İsteğe bağlı, varsayılan olarak OpenAI resmi API'sini kullanır
export OPENAI_MODEL="gpt-3.5-turbo"  # İsteğe bağlı, varsayılan olarak gpt-3.5-turbo modelini kullanır
export OPENAI_MAX_TOKENS="4096"  # İsteğe bağlı, maksimum token sınırını ayarlar (yok sayılırsa modelin varsayılanı kullanılır, uzun metin çevirileri için daha yüksek bir değer, örn. 8192, kullanılan modelin desteklediği maksimum token sayısına bağlı olarak önerilir)

# OpenAI API'sine erişmek için HTTP proxy kullanmanız gerekiyorsa, aşağıdaki değişkenleri ayarlayabilirsiniz
export HTTPS_PROXY="http://proxy-adresiniz.com:8080"  # İsteğe bağlı, HTTPS proxy'sini ayarlar
export HTTP_PROXY="http://proxy-adresiniz.com:8080"   # İsteğe bağlı, HTTP proxy'sini ayarlar
```

### Çok Dilli Site Oluşturma

Herhangi bir Git yönetimli klasörde çalıştırın:

```bash
npx czon@latest build --lang tr-TR --lang en-US
```

Dil kodları daha sonra statik site oluşturmada birçok işlevin parçası olarak kullanılacağından, lütfen BCP 47 standardına uygun dil kodları kullandığınızdan emin olun. Örneğin, `tr-TR` Türkçe (Türkiye), `en-US` Amerikan İngilizcesi'ni temsil eder. İhtiyacınıza göre daha fazla dil ekleyebilirsiniz, örneğin `es-ES` (İspanyolca), `ja-JP` (Japonca), `ko-KR` (Korece) vb.
Standart dil kodları listesi için lütfen [IETF language tag - Wikipedia](https://en.wikipedia.org/wiki/IETF_language_tag#List_of_common_primary_language_subtags) adresine bakın.

Çıktı dizini: `.czon/dist`, daha sonra bu dizindeki içeriğin statik site barındırma platformuna dağıtılması gerekecektir.

Detaylı kullanım için `npx czon@latest --help` komutunu çalıştırın.
