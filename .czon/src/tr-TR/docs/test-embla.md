# Embla Slayt Gösterisi Efekti Testi

Bu, Embla slayt gösterisi efektlerini test etmek için kullanılan bir dokümandır.

Birden fazla ardışık resim, bir slayt gösterisi olarak gösterilir; kullanıcılar oklara tıklayarak veya resimleri sürükleyerek görünümü değiştirebilir.
