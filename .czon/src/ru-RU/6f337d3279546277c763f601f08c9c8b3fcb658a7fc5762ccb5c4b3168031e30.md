# CZON - AI-нативный движок для контента на Markdown

- **C**: **C**ontent oriented | Контент-ориентированный, фокус на контенте
- **Z**: **Z**ero Configuration | Написание с нулевой конфигурацией, минимум отвлекающих факторов
- **O**: **O**rganic AI-Native | Органическая AI-нативность, глубокая интеграция AI
- **N**: **N**-shaped Energy Curve | N-образная кривая энергии, вовлечение во все этапы: создание-распространение-обратная связь

[> Демо сайта](https://czon.zccz14.com/)

В эпоху AI, как создатели контента для сайтов, мы можем иметь более интеллектуальный движок для создания контента.

**Возвращение к контенту: минимизация отвлекающих факторов, фокус на написании**

Вернуть документам их сущность, вернуть написанию спокойствие.

Во-первых, я не хочу быть библиотекарем. Иногда я хочу записать что-то, но, возможно, еще не придумал заголовок или не сформировал четкую структуру. Я хочу, чтобы LLM автоматически генерировала заголовки, делала резюме, классифицировала, создавала навигацию и другую организационную работу.

Во-вторых, мой рабочий кабинет должен быть чистым. Я не хочу сложных инструментов сборки с запутанными конфигурациями, не люблю сложные структуры. Каждый раз, когда я вижу конфигурационные файлы и структуры проектов таких инструментов, как Docusaurus, VuePress, Astro, у меня болит голова. Теперь CZON выбирает скрытие всех настроек в каталоге .czon, убирая их в угол, чтобы пользователи могли сосредоточиться только на написании контента, а все остальное оставить CZON. Все остальные каталоги — это ваше пространство для написания, вы можете организовывать свои файлы Markdown как угодно.

**Возвращение к родному языку: пишите на родном языке, плавно создавайте многоязычные версии**

Жизнь коротка, мне лень переводить. Когда человек использует родной язык, он может наиболее полно раскрыть глубину своего мышления. Но при этом необходимость поддерживать связь с миром остается, и я не хочу отказываться от многоязычного общения. Поэтому я хочу иметь инструмент, который позволит мне писать на родном языке, но при этом позволит большему количеству людей увидеть мой контент. Текущие решения i18n требуют не только самостоятельного перевода, но и самостоятельного поддержания обновлений контента, что слишком сложно. Я выбираю использование LLM для помощи в переводе, что экономит мне много времени и позволяет выполнить перевод на несколько языков одним кликом.

## Основные функции

1. 🌍 **Автоматический многоязычный перевод**: Использование AI для инкрементного перевода, позволяя пользователям писать на Markdown на родном языке, но при этом быть многоязычными.
2. 💭 **Автоматическое извлечение резюме**: Использование AI для анализа и извлечения контента из исходного текста.
3. 🏷️ **Автоматическая классификация тегов**: Использование AI для извлечения и управления тегами и классификацией контента.
4. 🧭 **Интеллектуальная классификация и навигация**: Использование AI для генерации карты сайта и навигации, нечувствительной к расположению исходных файлов.

## Статическая генерация сайтов (SSG)

CZON имеет встроенное решение SSG, которое может преобразовать любую папку с Markdown, управляемую git, в статический HTML-сайт.

⚠️ Обратите внимание, CZON не является профессиональным генератором статических сайтов (SSG), а представляет собой AI-движимый движок для контента на Markdown, ориентированный на создание и управление контентом.

✅ CZON направлен на упрощение процесса создания и публикации контента, позволяя пользователям сосредоточиться на самом написании, а не на сложных настройках и инструментах.

❌ CZON не предоставляет сложную настройку тем и экосистему плагинов, а сосредоточен на повышении качества и доступности контента с помощью AI.

🔔 Однако CZON все еще может генерировать статические сайты, и при необходимости CZON можно использовать как препроцессор, интегрируя другие решения SSG для создания персонализированных, красивых сайтов.

## Быстрый старт

Предварительные требования:

- Установлен [Node.js](https://nodejs.org/) (рекомендуется версия 18 и выше, должна быть команда npx)
- Получен [OpenAI API Key](https://platform.openai.com/account/api-keys) или совместимый API Key от OPENAI
- Установлен Git (для получения списка файлов Markdown из Git, игнорируя файлы, отфильтрованные правилами .gitignore)

Сначала работайте в папке, которая уже управляется git:

Настройка переменных окружения

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Обязательно: замените на ваш OpenAI API Key
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Опционально, по умолчанию используется официальный API OpenAI
export OPENAI_MODEL="gpt-3.5-turbo"  # Опционально, по умолчанию используется модель gpt-3.5-turbo
export OPENAI_MAX_TOKENS="4096"  # Опционально, установите ограничение на максимальное количество токенов (если не указано, используется значение по умолчанию модели, для перевода длинных текстов рекомендуется установить более высокое значение, например 8192, в зависимости от максимального количества токенов, поддерживаемого используемой моделью)
```

Сборка сайта с поддержкой многоязычного перевода. Используйте текущий каталог как исходный каталог, вывод в каталог `.czon/dist`.

- Можно указать языковые версии, которые нужно сгенерировать, используя параметр `--lang` несколько раз (например `--lang ru-RU --lang en-US`).
- Не нужно настраивать исходный язык, CZON определит его автоматически.

```bash
npx czon@latest build --lang ru-RU --lang en-US
```

**Просмотреть больше параметров или получить справку**:

```bash
npx czon@latest
```
