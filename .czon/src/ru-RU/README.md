# CZON - AI-нативный движок контента на Markdown

- **C**: **C**ontent oriented | Контент — король, фокус на содержании
- **Z**: **Z**ero Configuration | Написание с нулевой конфигурацией, меньше отвлечений
- **O**: **O**rganic AI-Native | Органическая AI-нативность, глубокая интеграция ИИ
- **N**: **N**-shaped Energy Curve | N-образная кривая энергии, вовлечение во все этапы: создание-распространение-обратная связь

В эпоху ИИ мы, как создатели контента для сайтов, можем иметь более интеллектуальный движок для создания контента.

**Возвращение к контенту: минимизация отвлечений, фокус на написании**

Вернуть документам их суть, вернуть письму его спокойствие.

Во-первых, я не хочу быть библиотекарем. Иногда я хочу что-то записать, но, возможно, ещё не придумал заголовок или не сформировал чёткую структуру. Я хочу, чтобы LLM автоматически помогала мне генерировать заголовки, делать резюме, классифицировать, создавать навигацию и выполнять другую организационную работу.

Во-вторых, мой кабинет должен быть чистым. Мне не нужны сложные инструменты сборки с запутанной конфигурацией, не нравится возиться со сложными настройками документов и структурой. Каждый раз, когда я вижу конфигурационные файлы и структуру проектов таких инструментов, как Docusaurus, VuePress, Astro, у меня начинает болеть голова. Теперь CZON прячет всю конфигурацию в каталог `.czon`, сметает её в угол, и пользователю нужно сосредоточиться только на написании контента, а всё остальное CZON берёт на себя. Все остальные каталоги — это ваше пространство для письма, вы можете организовывать свои Markdown-файлы как угодно.

**Возвращение к родному языку: пишите на родном языке, плавно создавайте многоязычные версии**

Жизнь коротка, мне лень переводить. Человек наиболее полно раскрывает глубину своего мышления, когда использует родной язык. Но при этом оставаться на связи с миром необходимо, и я не хочу отказываться от многоязычного общения. Поэтому мне нужен инструмент, который позволит мне писать на родном языке и одновременно показывать мой контент большему количеству людей. Текущие решения i18n требуют не только самостоятельного перевода, но и поддержки обновлений контента, что слишком хлопотно. Я выбираю использование LLM для помощи в переводе, это экономит мне много времени и позволяет выполнить перевод на множество языков одним кликом.

## ✨ Ключевые функции

1. 🌍 **AI многоязычный перевод**: Использование ИИ для инкрементного перевода, позволяющее пользователю писать на Markdown на родном языке, но при этом быть многоязычным.
2. 📊 **AI извлечение метаданных**: Автоматическое извлечение заголовка, описания, резюме, ключевых слов, целевой аудитории, URL-дружественных псевдонимов и т.д.
3. 🏷️ **AI классификация тегов**: Использование ИИ для извлечения и управления тегами и категориями контента.
4. 🧭 **AI навигация по категориям**: Использование ИИ для генерации карты сайта и навигации, независимо от расположения исходных файлов.
5. 🤖 **AI общее резюме сайта**: Возможность генерации общего резюме сайта в различных стилях.

А также некоторые функции, не связанные с ИИ:

1. ⚙️ **Нулевая конфигурация**: Вся конфигурация и кэш скрыты в каталоге `.czon`, структура проекта остаётся чистой.
2. 🔄 **Инкрементная сборка**: Обнаружение изменений на основе хэша контента, обработка только изменённых файлов.
3. 📚 **Поддержка расширений Markdown**: Нативная поддержка математических формул KaTeX, диаграмм Mermaid, каруселей Embla, сносок и т.д.
4. 🚀 **Генерация статических сайтов**: Встроенный SSG на основе React, генерирующий многоязычные статические сайты.
5. 🌐 **Автоматическая маршрутизация по языку посетителя**: Автоматическое перенаправление на соответствующую языковую версию в зависимости от языка посетителя.

## 📦 Быстрый старт

### Предварительные требования

- Установлен [Node.js](https://nodejs.org/) (рекомендуется LTS версия 24 или версия 18 и выше, должна быть доступна команда `npx`)
- Получен [OpenAI API Key](https://platform.openai.com/account/api-keys) или совместимый с OPENAI API-ключ
- Установлен Git (для получения списка Markdown-файлов из Git, игнорируются файлы, отфильтрованные по правилам .gitignore)

### Настройка переменных окружения

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Обязательно: замените на ваш OpenAI API Key
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Опционально, по умолчанию используется официальный API OpenAI
export OPENAI_MODEL="gpt-3.5-turbo"  # Опционально, по умолчанию используется модель gpt-3.5-turbo
export OPENAI_MAX_TOKENS="4096"  # Опционально, установка ограничения на максимальное количество токенов (если не указано, используется значение по умолчанию модели; для перевода длинных текстов рекомендуется установить более высокое значение, например 8192, в зависимости от максимального количества токенов, поддерживаемого используемой моделью)

# Если необходим HTTP-прокси для доступа к OpenAI API, можно установить следующие переменные
export HTTPS_PROXY="http://your-proxy.com:8080"  # Опционально, настройка HTTPS-прокси
export HTTP_PROXY="http://your-proxy.com:8080"   # Опционально, настройка HTTP-прокси
```

### Сборка многоязычного сайта

Запустите в любой папке, управляемой Git:

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

Поскольку языковые коды впоследствии будут использоваться во многих функциях генерации статического сайта, убедитесь, что используются языковые коды стандарта BCP 47. Например, `zh-Hans` означает упрощённый китайский, `en-US` — американский английский. Вы можете добавить больше языков по мере необходимости, например `es-ES` (испанский), `ja-JP` (японский), `ko-KR` (корейский) и т.д.
Список стандартных языковых кодов см. [IETF language tag - Wikipedia](https://en.wikipedia.org/wiki/IETF_language_tag#List_of_common_primary_language_subtags).

Выходной каталог: `.czon/dist`. Содержимое этого каталога впоследствии необходимо развернуть на платформе хостинга статических сайтов.

Подробное использование: запустите `npx czon@latest --help`.

| **Автоматическая классификация/теги** | ✅ Извлечение с помощью ИИ | ❌ Ручная настройка | ❌ Ручная настройка | ❌ Ручная настройка |
| **Расширения Markdown** | ✅ KaTeX, Mermaid, Embla | ✅ Через плагины | ✅ Через плагины | ✅ Через плагины |
| **Настройка темы**    | ❌ Ограниченная          | ✅ Богатая      | ✅ Богатая      | ✅ Богатая      |

CZON позиционируется как **движок контента с усилением ИИ**, а не как полнофункциональный SSG. Он фокусируется на повышении эффективности создания контента с помощью ИИ и подходит для создателей, которые ценят качество контента и хотят уменьшить нагрузку по настройке. Фактически, CZON можно использовать совместно с такими инструментами SSG, как Docusaurus, VuePress, Astro, в качестве фронтенд-движка для генерации и управления контентом.
