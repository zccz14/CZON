# CZON - AI-нативный движок контента на Markdown

- **C**: **C**ontent oriented | Контент — это король, фокус на содержании
- **Z**: **Z**ero Configuration | Написание без конфигурации, меньше отвлекающих факторов
- **O**: **O**rganic AI-Native | Органическая AI-нативность, глубокая интеграция ИИ
- **N**: **N**-shaped Energy Curve | N-образная кривая энергии, охватывающая все этапы: создание, распространение, обратная связь

[> Демо сайта](https://czon.zccz14.com/)

В эпоху ИИ мы, как создатели контента для сайтов, можем иметь более интеллектуальный движок для создания контента.

**Возвращение к содержанию: минимум помех, фокус на написании**

Вернуть документам их суть, вернуть спокойствие в процесс письма.

Во-первых, я не хочу быть библиотекарем. Иногда я хочу что-то записать, но, возможно, ещё не придумал заголовок или не организовал это должным образом. Я хочу, чтобы LLM автоматически помогала мне генерировать заголовки, делать резюме, классифицировать, создавать навигацию и выполнять другую организационную работу.

Во-вторых, мой кабинет должен быть чистым. Мне не нужны сложные инструменты сборки с запутанной конфигурацией, не нравится возиться со сложными настройками документов и структурой. Каждый раз, когда я вижу конфигурационные файлы и структуру проектов таких инструментов, как Docusaurus, VuePress, Astro, у меня начинает болеть голова. Теперь CZON выбирает путь, при котором вся конфигурация скрыта в каталоге `.czon`, убрана в угол, и пользователю нужно сосредоточиться только на написании контента, а всё остальное CZON берёт на себя. Все остальные каталоги — это ваше рабочее пространство для письма, вы можете организовывать свои Markdown-файлы как угодно.

**Возвращение к родному языку: пишите на родном языке, плавно создавайте многоязычные версии**

Жизнь коротка, мне лень переводить. Человек наиболее полно раскрывает глубину своего мышления, когда использует родной язык. Но при этом оставаться на связи с миром необходимо, и я не хочу отказываться от многоязычного общения. Поэтому я хочу иметь инструмент, который позволит мне писать на родном языке и одновременно сделать мой контент доступным для большего числа людей. Современные решения i18n требуют не только самостоятельного перевода, но и поддержки обновлений контента, что слишком хлопотно. Я выбираю использование LLM для помощи в переводе, что экономит мне много времени и позволяет выполнить перевод на множество языков одним нажатием.

## Основные функции

1. 🌍 **Автоматический многоязычный перевод**: Использование ИИ для инкрементного перевода, позволяющее пользователям писать Markdown на родном языке, но при этом быть многоязычными.
2. 💭 **Автоматическое извлечение резюме**: Использование ИИ для анализа и извлечения ключевой информации из исходного текста.
3. 🏷️ **Автоматическая классификация тегов**: Использование ИИ для извлечения и управления тегами и категориями контента.
4. 🧭 **Интеллектуальная навигация по категориям**: Использование ИИ для генерации карты сайта и навигации, независимо от расположения исходных файлов.

## Генерация статических сайтов (SSG)

CZON имеет встроенное решение SSG, которое может преобразовать любую папку Git, содержащую Markdown-файлы, в статический HTML-сайт.

⚠️ Обратите внимание, что CZON — это не профессиональный генератор статических сайтов (SSG), а AI-движок контента на Markdown, ориентированный на создание и управление контентом.

✅ CZON призван упростить процесс создания и публикации контента, позволяя пользователям сосредоточиться на самом написании, а не на сложных настройках и инструментах.

❌ CZON не предоставляет сложной настройки тем и экосистемы плагинов, а фокусируется на повышении качества и доступности контента с помощью ИИ.

🔔 Тем не менее, CZON всё ещё может генерировать статические сайты. При необходимости CZON можно использовать как препроцессор, интегрировав его с другими решениями SSG для создания персонализированных и красивых сайтов.

## Быстрый старт

Предварительные требования:

- Установлен [Node.js](https://nodejs.org/) (рекомендуется версия 18 и выше, необходима команда `npx`)
- Получен [OpenAI API Key](https://platform.openai.com/account/api-keys) или совместимый с OPENAI API Key
- Установлен Git (для получения списка Markdown-файлов из Git, игнорируются файлы, отфильтрованные по правилам .gitignore)

Сначала работайте в папке, которая уже находится под управлением Git:

Настройте переменные окружения

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Обязательно: замените на ваш OpenAI API Key
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Опционально, по умолчанию используется официальный API OpenAI
export OPENAI_MODEL="gpt-3.5-turbo"  # Опционально, по умолчанию используется модель gpt-3.5-turbo
export OPENAI_MAX_TOKENS="4096"  # Опционально, установите ограничение на максимальное количество токенов (если не указано, используется значение по умолчанию модели; для перевода длинных текстов рекомендуется установить более высокое значение, например 8192, в зависимости от максимального количества токенов, поддерживаемого используемой моделью)
```

Соберите сайт с поддержкой многоязычного перевода. Используйте текущий каталог как исходный, вывод будет в каталог `.czon/dist`.

- Можно указать языковые версии для генерации, несколько раз используя параметр `--lang` (например, `--lang zh-Hans --lang en-US`).
- Исходный язык настраивать не нужно, CZON определит его автоматически.

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

**Посмотреть больше параметров или получить справку**:

```bash
npx czon@latest
```
