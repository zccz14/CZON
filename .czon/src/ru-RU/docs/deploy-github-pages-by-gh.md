# Развертывание на GitHub Pages

В этом руководстве описывается, как развернуть многоязычный статический сайт, сгенерированный CZON, на GitHub Pages с помощью GitHub CLI.

Сначала установите инструмент [GitHub CLI](https://cli.github.com/) (если он еще не установлен) и убедитесь, что вы вошли в систему (если еще не вошли):

```bash
$ gh --version # Проверьте версию, чтобы убедиться в успешной установке
```

Убедитесь, что вы вошли в систему и имеете разрешение `repo` для доступа к целевому репозиторию:

```bash
$ gh auth login -s repo # Войдите в учетную запись GitHub; будет предложено войти через браузер или использовать токен
$ gh auth status # Проверьте статус входа, убедитесь, что вход выполнен успешно и у вас есть разрешение repo для доступа к целевому репозиторию
```

После этого достаточно выполнить следующую команду и следовать подсказкам:

```bash
$ npx czon@latest config github
```

Эта команда проведет вас через следующие шаги:

1.  Проверит, включает ли разрешение gh `repo`. Если нет, предложит повторно войти в систему и добавить разрешение `repo`.
2.  Если локальная директория не является Git-репозиторием, предложит инициализировать новый Git-репозиторий.
3.  Проверит настройки удаленного Git-репозитория для локальной директории, чтобы узнать, есть ли удаленный репозиторий GitHub. Если удаленного репозитория GitHub нет, предложит создать новый удаленный репозиторий и добавить его как `origin`. Если `origin` уже существует, но не является репозиторием GitHub, предложит добавить новый удаленный репозиторий GitHub как `upstream`.
4.  Проверит, включены ли GitHub Pages и имеют ли они тип `workflow`. Если нет, включит их через API `gh api` и исправит настройки для развертывания из Actions. Также настроит CNAME (если у вас есть пользовательский домен).
5.  Проверит файл GitHub Workflow. Если он не создан, создаст файл Workflow для Pages; если он уже существует, но не является последней версией, предложит обновить файл Workflow.
6.  Зафиксирует файл Workflow и отправит изменения в удаленный репозиторий.
7.  Предоставит URL-адрес сайта GitHub Pages, получив последний URL-адрес Pages через `gh api`.
