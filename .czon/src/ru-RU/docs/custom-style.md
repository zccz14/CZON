# Пользовательские стили

CZON поддерживает настройку стилей сайта через файл `.czon/style.css`, что позволяет переопределять стили по умолчанию или добавлять персонализированный внешний вид.

## Как использовать

1. Создайте файл `style.css` в каталоге `.czon` вашего проекта:

```
ваш-проект/
├── .czon/
│   ├── meta.json
│   └── style.css    <-- создайте этот файл
├── README.md
└── docs/
```

2. Напишите ваш пользовательский CSS в файле `style.css`:

```css
/* Пример: изменение цвета ссылок */
:root {
  --link-color: #0066cc;
}

/* Пример: изменение фона в темном режиме */
html.dark {
  --bg-primary: #0d1117;
}
```

3. Запустите `czon build` заново, пользовательские стили автоматически применятся ко всем страницам.

## Принцип работы

- При сборке CZON проверяет наличие файла `.czon/style.css`
- Если файл существует, он копируется в выходной каталог `.czon/dist/style.css`
- В каждой сгенерированной HTML-странице в `<head>` добавляется ссылка на стили:
  ```html
  <link rel="stylesheet" href="style.css" />
  ```
- Пользовательские стили загружаются после встроенных, поэтому могут переопределять стили по умолчанию

## Доступные CSS-переменные

CZON использует CSS-переменные для определения цветов темы. Вы можете быстро настроить цветовую схему, переопределив эти переменные:

```css
:root {
  /* Цвета фона */
  --bg-primary: #ffffff;
  --bg-secondary: #f8f9fa;
  --bg-tertiary: #e9ecef;

  /* Цвета текста */
  --text-primary: #333333;
  --text-secondary: #6c757d;
  --text-muted: #adb5bd;

  /* Цвета ссылок и акцентов */
  --link-color: #007bff;
  --link-hover-color: #0056b3;

  /* Цвета границ */
  --border-color: #dee2e6;
}

/* Переменные для темного режима */
html.dark {
  --bg-primary: #1a1a1a;
  --bg-secondary: #2d2d2d;
  --bg-tertiary: #404040;

  --text-primary: #e5e5e5;
  --text-secondary: #a0a0a0;
  --text-muted: #6c6c6c;

  --link-color: #58a6ff;
  --link-hover-color: #79b8ff;

  --border-color: #404040;
}
```

## Примеры

### Настройка фирменных цветов

```css
:root {
  --link-color: #e91e63;
  --link-hover-color: #c2185b;
}

html.dark {
  --link-color: #f48fb1;
  --link-hover-color: #f8bbd9;
}
```

### Изменение ширины области контента

```css
.content {
  max-width: 60rem;
}
```

### Настройка стилей блоков кода

```css
pre code {
  font-family: 'Fira Code', 'JetBrains Mono', monospace;
  font-size: 0.875rem;
}
```

### Скрытие определенных элементов

```css
/* Скрыть правую боковую панель с оглавлением */
.sidebar-right {
  display: none;
}
```

## Важные замечания

- Имя файла пользовательских стилей должно быть `style.css`, и он должен находиться в каталоге `.czon/`
- После изменения стилей необходимо повторно запустить `czon build`, чтобы изменения вступили в силу
- Рекомендуется настраивать стили путем переопределения CSS-переменных, так как это обеспечивает совместимость со светлым и темным режимами
- CZON использует Tailwind CSS, поэтому для переопределения стилей, сгенерированных Tailwind, может потребоваться использование `!important`
