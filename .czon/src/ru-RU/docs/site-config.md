# Настройка сайта

CZON поддерживает настройку параметров сайта через файл `.czon/meta.json`. Эти настройки являются необязательными и не блокируют первоначальное использование.

## Расположение конфигурации

Параметры конфигурации находятся в поле `options.site` файла `.czon/meta.json`:

```json
{
  "version": "1.0.0",
  "options": {
    "langs": ["zh-Hans", "en-US"],
    "site": {
      "baseUrl": "https://example.com",
      "title": "My Docs",
      "home": "guide.html",
      "gaID": "G-XXXXXXXXXX",
      "clarityID": "your-clarity-id",
      "navLinks": [
        { "title": "Главная", "href": "index.html" },
        { "title": "О нас", "href": "about.html" }
      ]
    }
  },
  "files": []
}
```

## Доступные параметры конфигурации

### `site.baseUrl`

Базовый URL сайта, используемый для генерации `sitemap.xml` и `robots.txt`.

- **Тип**: `string`
- **Формат**: Полный URL, например `https://example.com`

```json
{
  "options": {
    "site": {
      "baseUrl": "https://example.com"
    }
  }
}
```

После настройки будут автоматически сгенерированы:

- `sitemap.xml` — карта сайта, содержащая все страницы
- Объявление Sitemap в `robots.txt`

### `site.title`

Заголовок сайта, отображаемый в верхней части страницы.

- **Тип**: `string`
- **Значение по умолчанию**: `"CZON"`

```json
{
  "options": {
    "site": {
      "title": "Моя документация"
    }
  }
}
```

### `site.gaID`

Google Analytics Measurement ID, используемый для интеграции статистики Google Analytics.

- **Тип**: `string`
- **Формат**: `G-XXXXXXXXXX`

```json
{
  "options": {
    "site": {
      "gaID": "G-XXXXXXXXXX"
    }
  }
}
```

**Как получить**: Перейдите в [Google Analytics](https://analytics.google.com/), создайте ресурс и получите Measurement ID в разделе «Потоки данных».

### `site.clarityID`

Microsoft Clarity Project ID, используемый для интеграции анализа поведения пользователей Clarity.

- **Тип**: `string`

```json
{
  "options": {
    "site": {
      "clarityID": "your-project-id"
    }
  }
}
```

**Как получить**: Перейдите в [Microsoft Clarity](https://clarity.microsoft.com/), создайте проект и получите Project ID в настройках проекта.

### `site.home`

Настройка пути к главной странице, используется для настройки целевой страницы перехода.

- **Тип**: `string`
- **Значение по умолчанию**: `"index.html"`

```json
{
  "options": {
    "site": {
      "home": "guide.html"
    }
  }
}
```

**Описание поведения**:

- **При посещении корневой главной страницы**: Когда пользователь посещает `/index.html`, он будет автоматически перенаправлен на `/{определенный язык}/{home}` в зависимости от языка браузера.
- **При нажатии на заголовок в Header**: Происходит переход на путь `home` в текущей языковой директории.

**Сценарии использования**:

- Когда вы хотите, чтобы пользователи при первом посещении сразу попадали на определенную страницу (например, руководство по началу работы, описание продукта и т.д.).
- Когда главная страница сайта — это не список статей, а конкретная страница документации.

### `site.navLinks`

Настройка ссылок быстрой навигации, отображаемых в верхней части страницы.

- **Тип**: `Array<{ title: string, href: string }>`
- **Значение по умолчанию**: `undefined` (навигация не отображается)

```json
{
  "options": {
    "site": {
      "navLinks": [
        { "title": "Главная", "href": "index.html" },
        { "title": "Документация", "href": "docs.html" },
        { "title": "О нас", "href": "about.html" }
      ]
    }
  }
}
```

**Адаптивное поведение**:

- **Мобильные устройства**: Отображается значок гамбургер-меню, при нажатии раскрываются все ссылки навигации.
- **Десктопные устройства**: Ссылки навигации отображаются непосредственно в Header, но не более 40% ширины экрана; ссылки, выходящие за этот предел, отображаются через выпадающее меню «Ещё».

## Полный пример

```json
{
  "version": "1.0.0",
  "options": {
    "langs": ["zh-Hans", "en-US", "ja-JP"],
    "site": {
      "baseUrl": "https://example.com",
      "title": "Технический блог",
      "home": "getting-started.html",
      "gaID": "G-ABC123DEF4",
      "clarityID": "abc123xyz",
      "navLinks": [
        { "title": "Главная", "href": "index.html" },
        { "title": "Документация", "href": "docs.html" },
        { "title": "Блог", "href": "blog.html" }
      ]
    }
  },
  "files": []
}
```

## Важные замечания

- После изменения конфигурации необходимо повторно запустить `czon build`, чтобы изменения вступили в силу.
- Все параметры в разделе `site` являются необязательными, можно настроить только необходимые части.
- Инструменты аналитики (GA, Clarity) загружаются только при наличии соответствующего ID и не влияют на производительность страницы.
- Если `baseUrl` не настроен, генерация `sitemap.xml` будет пропущена.
