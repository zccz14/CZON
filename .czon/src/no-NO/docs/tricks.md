# Bruksteknikker

## Erklær dato i hovedteksten

I hovedteksten kan du bruke datoerklæringer som "I dag er det 8. januar 2026" (formatstil er fri), og CZON vil automatisk gjenkjenne og behandle det.

Tradisjonelle Markdown-dokumenter erklærer datoer via YAML Frontmatter, som krever at man husker de korresponderende feltene, ellers kan datoen ikke gjenkjennes riktig.

CZON støtter direkte datoerklæring i hovedteksten, noe som unngår problemet med å glemme å fylle ut Frontmatter-feltene.

AI vil automatisk trekke ut og utlede datoinformasjonen i hovedteksten og behandle den som dokumentets opprettelsesdato.

Denne metoden er mer fleksibel og intelligent, og forbedrer brukeropplevelsen.

Forresten, dokumenter med datoer kan generere tidslinjevisning, noe som gjør det enkelt å bla gjennom og administrere. Spesielt egnet for innholdstyper som dagbok, blogg osv., som krever tidslinje.
