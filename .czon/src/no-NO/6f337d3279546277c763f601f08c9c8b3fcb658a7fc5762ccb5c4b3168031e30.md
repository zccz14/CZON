# CZON - AI-Native Markdown innholdsengine

- **C**: **C**ontent oriented | Innhold er kongen, fokus på innhold
- **Z**: **Z**ero Configuration | Nullkonfigurasjonsskriving, reduserer forstyrrelser
- **O**: **O**rganic AI-Native | Organisk AI-nativ, dyp AI-integrasjon
- **N**: **N**-shaped Energy Curve | N-formet energikurve, involverer skaping-distribusjon-tilbakemelding på alle nivåer

[> Nettsted Demo](https://czon.zccz14.com/)

I AI-tiden kan vi som nettstedsinnholdsskapere ha en smartere innholdsskapingmotor.

**Tilbake til innhold: Minimaliser forstyrrelser, fokuser på skriving**

La dokumenter komme tilbake til essensen, la skriving komme tilbake til ro.

For det første, jeg vil ikke være bibliotekar. Noen ganger vil jeg skrive ned noe innhold, men jeg har kanskje ikke tenkt ut tittelen ennå, eller ikke dannet en spesiell organisering. Jeg ønsker at LLM automatisk skal hjelpe meg med å generere titler, lage sammendrag, klassifisere, navigere og andre organiseringsoppgaver.

For det andre, mitt skrivebord må være rent. Jeg vil ikke ha komplekse konfigurasjonsverktøy, krangle med komplekse dokumentkonfigurasjoner, eller like komplekse strukturer. Hver gang jeg ser konfigurasjonsfiler og prosjektstrukturer for verktøy som Docusaurus, VuePress, Astro, får jeg hodepine. Nå velger CZON å skjule all konfigurasjon i .czon-katalogen, feie den bort i et hjørne, slik at brukeren bare trenger å fokusere på å skrive innhold, og la CZON håndtere resten. Alle andre kataloger er din skriveplass, du kan organisere dine Markdown-filer som du vil.

**Tilbake til morsmål: Skriv på morsmålet, bygg flerspråklige versjoner sømløst**

Livet er kort, jeg gidder ikke oversette. Når man bruker morsmålet sitt, kan man utnytte sin egen tenkedybde best. Men samtidig er det nødvendig å forbli forbundet med verden, og jeg vil ikke gi opp flerspråklig kommunikasjon. Derfor ønsker jeg et verktøy som lar meg skrive på morsmålet mitt, samtidig som det lar flere se innholdet mitt. Nåværende i18n krever ikke bare at man oversetter selv, men også at man vedlikeholder innholdsopdateringer, det er for mye arbeid. Jeg velger å bruke LLM til å hjelpe meg med oversettelser, dette sparer meg mye tid og kan fullføre flerspråklig oversettelse med ett klikk.

## Grunnleggende funksjoner

1. 🌍 **Automatisk flerspråklig oversettelse**: Bruker AI for inkrementell oversettelse, lar brukeren skrive Markdown på morsmålet, men brukeren kan være flerspråklig.
2. 💭 **Automatisk sammendragsektrahering**: Bruker AI for innholdsanalyse og ekstrahering av originaltekst.
3. 🏷️ **Automatisk etikettklassifisering**: Bruker AI for innholdsetiketter og klassifiseringsuttrekk og administrasjon.
4. 🧭 **Intelligent klassifiseringsnavigasjon**: Bruker AI for å generere nettstedskart og navigasjon, kildefilplassering er ikke følsom.

## Statisk nettstedsgenerering (SSG)

CZON har en innebygd SSG-løsning som kan bygge en hvilken som helst git-mappe som inneholder Markdown til et statisk HTML-nettsted.

⚠️ Vær oppmerksom på at CZON ikke er en profesjonell statisk nettstedsgenerator (SSG), men en AI-drevet Markdown-innholdsengine som fokuserer på innholdsskaping og administrasjon.

✅ CZON har som mål å forenkle prosessen for innholdsskaping og publisering, slik at brukeren kan fokusere på selve skrivingen, i stedet for å bli forstyrret av komplekse konfigurasjoner og verktøy.

❌ CZON vil ikke tilby komplekse tema-tilpasninger og plugin-økosystemer, men fokuserer på å forbedre innholdskvalitet og tilgjengelighet gjennom AI.

🔔 Men CZON kan fortsatt generere statiske nettsteder, om nødvendig kan CZON brukes som en forbehandler, integrert med andre SSG-løsninger for å generere personlige, vakre nettsteder.

## Rask start

Forutsetninger:

- [Node.js](https://nodejs.org/) er installert (anbefalt versjon 18 eller høyere, må ha npx-kommando)
- Har fått [OpenAI API-nøkkel](https://platform.openai.com/account/api-keys), eller OPENAI-kompatibel API-nøkkel
- Git er installert (brukes for å liste Markdown-filer fra Git, ignorerer filer filtrert av .gitignore-regler)

Først, jobb i en mappe som allerede administreres av git:

Konfigurer miljøvariabler

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Påkrevd: erstatt med din OpenAI API-nøkkel
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Valgfri, bruker offisiell OpenAI API som standard
export OPENAI_MODEL="gpt-3.5-turbo"  # Valgfri, bruker gpt-3.5-turbo-modellen som standard
export OPENAI_MAX_TOKENS="4096"  # Valgfri, sett maksimal token-grense (ignorer for å bruke modellens standardverdi, for langtekstoversettelser anbefales høyere verdi, f.eks. 8192, avhengig av maksimalt antall tokens som modellen støtter)
```

Bygg nettsted, støtter flerspråklig oversettelse. Bruk gjeldende katalog som kildekatalog, output til `.czon/dist`-katalogen.

- Kan spesifisere språkversjoner som skal genereres ved å bruke `--lang`-parameteren flere ganger (f.eks. `--lang no-NO --lang en-US`).
- Trenger ikke konfigurere kilde språk, CZON vil automatisk oppdage.

```bash
npx czon@latest build --lang no-NO --lang en-US
```

**Se flere parametere eller hjelp**:

```bash
npx czon@latest
```
