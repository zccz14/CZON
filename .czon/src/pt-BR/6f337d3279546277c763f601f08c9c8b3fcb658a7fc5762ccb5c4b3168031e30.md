# CZON - Motor de Conteúdo Markdown Nativo em IA

- **C**: **C**ontent oriented | Orientado a conteúdo, foco no conteúdo
- **Z**: **Z**ero Configuration | Escrita com configuração zero, reduzindo interrupções
- **O**: **O**rganic AI-Native | Nativo em IA orgânico, integração profunda com IA
- **N**: **N**-shaped Energy Curve | Curva de energia em forma de N, envolvendo criação-distribuição-feedback em todos os aspectos

[> Demonstração do Site](https://czon.zccz14.com/)

Na era da IA, como criadores de conteúdo para sites, podemos ter um motor de criação de conteúdo mais inteligente.

**Retornar ao conteúdo: Minimizar interrupções, focar na escrita**

Deixe os documentos retornarem à sua essência, deixe a escrita retornar à tranquilidade.

Primeiro, não quero ser um bibliotecário. Às vezes quero escrever algum conteúdo, mas posso ainda não ter pensado em seu título, ainda não ter formado uma organização específica. Espero que o LLM me ajude automaticamente a gerar títulos, fazer resumos, classificar, navegar e outras tarefas de organização.

Segundo, meu escritório deve estar limpo. Não quero ferramentas de construção com configurações complexas, mexer em configurações complexas de documentos, não gosto de estruturas complicadas. Sempre que vejo os arquivos de configuração e estruturas de projeto de ferramentas como Docusaurus, VuePress, Astro, fico com dor de cabeça. Agora, o CZON opta por esconder todas as configurações no diretório .czon, varrendo para o canto, os usuários só precisam se concentrar em escrever o conteúdo, o resto é tratado pelo CZON. Os outros diretórios são seu espaço de escrita, você pode organizar seus arquivos Markdown como quiser.

**Retornar à língua materna: Escrever na língua materna, construir versões multilíngues suavemente**

A vida é curta, sou preguiçoso para traduzir. As pessoas só conseguem expressar sua profundidade de pensamento ao máximo quando usam sua língua materna. Mas ao mesmo tempo, manter conexão com o mundo é necessário, não quero desistir da comunicação multilíngue. Portanto, espero ter uma ferramenta que me permita escrever em minha língua materna, enquanto permite que mais pessoas vejam meu conteúdo. Atualmente, o i18n não só exige que você mesmo traduza, mas também que mantenha as atualizações de conteúdo, é muito trabalhoso. Escolho usar o LLM para me ajudar com a tradução, economizando muito tempo e podendo completar a tradução para vários idiomas com um clique.

## Funcionalidades Básicas

1. 🌍 **Tradução automática multilíngue**: Usa IA para tradução incremental, permitindo que os usuários escrevam Markdown em sua língua materna, mas os usuários podem ser multilíngues.
2. 💭 **Extração automática de resumos**: Usa IA para análise e extração de conteúdo do texto original.
3. 🏷️ **Classificação automática por tags**: Usa IA para extração e gerenciamento de tags e classificação de conteúdo.
4. 🧭 **Navegação inteligente por categorias**: Usa IA para gerar mapa do site e navegação, a localização dos arquivos de origem não é sensível.

## Geração de Sites Estáticos (SSG)

O CZON possui um esquema SSG integrado que pode transformar qualquer pasta git contendo Markdown em um site HTML estático.

⚠️ Observe que o CZON não é um gerador de sites estáticos (SSG) profissional, mas sim um motor de conteúdo Markdown movido por IA, focado na criação e gerenciamento de conteúdo.

✅ O CZON visa simplificar o fluxo de criação e publicação de conteúdo, permitindo que os usuários se concentrem na escrita em si, em vez de serem incomodados por configurações e ferramentas complexas.

❌ O CZON não fornecerá personalização complexa de temas e ecossistema de plugins, mas se concentrará em melhorar a qualidade e acessibilidade do conteúdo por meio da IA.

🔔 No entanto, o CZON ainda pode gerar sites estáticos, se necessário, o CZON pode ser usado como um pré-processador, integrado a outros esquemas SSG para gerar sites personalizados e bonitos.

## Começo Rápido

Pré-requisitos:

- [Node.js](https://nodejs.org/) instalado (versão 18 ou superior recomendada, precisa ter o comando npx)
- [Chave de API OpenAI](https://platform.openai.com/account/api-keys) obtida, ou chave de API compatível com OPENAI
- Git instalado (para listar arquivos Markdown do Git, ignorando arquivos filtrados pelas regras .gitignore)

Primeiro, trabalhe em uma pasta já gerenciada pelo git:

Configurar variáveis de ambiente

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Obrigatório: substitua pela sua chave de API OpenAI
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Opcional, usa a API oficial da OpenAI por padrão
export OPENAI_MODEL="gpt-3.5-turbo"  # Opcional, usa o modelo gpt-3.5-turbo por padrão
export OPENAI_MAX_TOKENS="4096"  # Opcional, define o limite máximo de tokens (se ignorado, usa o valor padrão do modelo, para tradução de textos longos recomenda-se definir um valor mais alto, como 8192, dependendo do número máximo de tokens suportado pelo modelo usado)
```

Construir o site, suportando tradução multilíngue. Use o diretório atual como diretório de origem, saída para o diretório `.czon/dist`.

- Pode especificar as versões de idioma a serem geradas usando o parâmetro `--lang` várias vezes (por exemplo `--lang pt-BR --lang en-US`).
- Não é necessário configurar o idioma de origem, o CZON detecta automaticamente.

```bash
npx czon@latest build --lang pt-BR --lang en-US
```

**Ver mais parâmetros ou ajuda**:

