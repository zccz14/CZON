# Embla-karusellin vaikutusten testaus

Tämä on asiakirja Embla-karusellin vaikutusten testaamiseen.

Useita peräkkäisiä kuvia esitetään karusellina, ja käyttäjät voivat vaihtaa näkymää klikkaamalla nuolia tai vetämällä kuvia.
