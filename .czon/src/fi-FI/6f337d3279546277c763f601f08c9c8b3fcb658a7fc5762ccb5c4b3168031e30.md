# CZON - AI-Native Markdown-sisältömoottori

- **C**: **C**ontent oriented | Sisältö on tärkeintä, keskittyy sisältöön
- **Z**: **Z**ero Configuration | Nollakonfiguraatiokirjoitus, vähemmän häiriöitä
- **O**: **O**rganic AI-Native | Orgaaninen AI-natiivi, syvä AI-integraatio
- **N**: **N**-shaped Energy Curve | N-muotoinen energiakäyrä, joka osallistuu luomisen-jakamisen-palautteen kaikkiin vaiheisiin

[> Verkkosivun demo](https://czon.zccz14.com/)

AI-aikakaudella, verkkosisällöntuottajina, meillä voi olla älykkäämpi sisällöntuotantomoottori.

**Palaa sisältöön: minimoi häiriöt, keskitty kirjoittamiseen**

Palauta dokumenttien olemus, palauta kirjoittamisen rauha.

Ensinnäkin, en halua olla kirjastonhoitaja. Joskus haluan kirjoittaa jotain sisältöä, mutta en ehkä ole vielä päättänyt sen otsikosta, eikä siitä ole muodostunut erityistä organisaatiota. Toivon, että LLM automaattisesti auttaisi minua luomaan otsikoita, tekemään yhteenvetoja, luokittelemaan ja navigoimaan järjestelytehtävissä.

Toiseksi, kirjastoni on siivottava. En halua monimutkaisia konfiguraatiotyökaluja, vaikeita dokumenttikokoonpanoja, enkä pidä monimutkaisista rakenteista. Joka kerta kun näen Docusaurusin, VuePressin, Astron ja muiden työkalujen konfiguraatiotiedostot ja projektirakenteet, minua alkaa särkeä pää. Nyt CZON valitsee piilottaa kaikki konfiguraatiot .czon-hakemistoon, nurkkaan, jotta käyttäjät voivat keskittyä vain kirjoittamiseen, ja loput jättää CZON:in käsiteltäväksi. Muut hakemistot ovat sinun kirjoitustilasi, voit järjestää Markdown-tiedostosi haluamallasi tavalla.

**Palaa äidinkieleen: kirjoita äidinkielellä, luo monikielisiä versioita sulavasti**

Elämä on lyhyt, en jaksa kääntää. Ihmiset pystyvät parhaiten käyttämään ajattelunsa syvyyttä äidinkielellään. Mutta yhteydenpito maailmaan on välttämätöntä, enkä halua luopua monikielisestä viestinnästä. Siksi toivon työkalua, joka antaisi minun kirjoittaa äidinkielelläni, mutta samalla antaisi useammille ihmisille nähdä sisältöni. Nykyinen i18n vaatii itse käännösten tekemisen ja sisällön päivittämisen, mikä on liian vaivalloista. Valitsen käyttää LLM:ää auttamaan käännöksissä, säästää paljon aikaa ja voi suorittaa monikieliset käännökset yhdellä napsautuksella.

## Perustoiminnot

1. 🌍 **Automaattinen monikielinen käännös**: Käytä AI:ta inkrementaaliseen käännökseen, anna käyttäjien kirjoittaa Markdown äidinkielellä, mutta käyttäjät voivat olla monikielisiä.
2. 💭 **Automaattinen yhteenvetojen poiminta**: Käytä AI:ta alkuperäisen tekstin sisällön analysointiin ja poimintaan.
3. 🏷️ **Automaattinen tagien luokittelu**: Käytä AI:ta sisällön tagien ja luokittelun poimintaan ja hallintaan.
4. 🧭 **Älykäs luokittelunavigointi**: Käytä AI:ta sivustokartan ja navigoinnin luomiseen, lähdetiedostojen sijainti ei ole herkkä.

## Staattinen sivuston generointi (SSG)

CZON sisältää SSG-ratkaisun, joka voi rakentaa minkä tahansa Markdown-tiedostoja sisältävän git-hakemiston staattiseksi HTML-sivustoksi.

⚠️ Huomaa, että CZON ei ole ammattimainen staattinen sivuston generaattori (SSG), vaan AI-vetoinen Markdown-sisältömoottori, joka keskittyy sisällöntuotantoon ja hallintaan.

✅ CZON pyrkii yksinkertaistamaan sisällöntuotannon ja julkaisun prosessia, antaen käyttäjien keskittyä itse kirjoittamiseen eikä monimutkaisiin konfiguraatioihin ja työkaluihin.

❌ CZON ei tarjoa monimutkaisia teeman mukautuksia ja liitännäisekosysteemiä, vaan keskittyy AI:n avulla parantamaan sisällön laatua ja saavutettavuutta.

🔔 Kuitenkin, CZON voi silti generoida staattisia sivustoja, ja tarvittaessa CZON:ia voidaan käyttää esikäsittelijänä, integroida muihin SSG-ratkaisuihin luodakseen personoituja, kauniita sivustoja.

## Nopea aloitus

Edellytykset:

- Asennettu [Node.js](https://nodejs.org/) (suositeltu versio 18 tai uudempi, tarvitaan npx-komento)
- Hankittu [OpenAI API Key](https://platform.openai.com/account/api-keys), tai OPENAI-yhteensopiva API-avain
- Asennettu Git (käytetään Markdown-tiedostojen listaukseen git:stä, .gitignore-sääntöjen suodattamat tiedostot ohitetaan)

Ensinnäkin, työskentele git-hallinnassa olevassa hakemistossa:

Konfiguroi ympäristömuuttujat

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Pakollinen: korvaa omalla OpenAI API-avaimellasi
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Valinnainen, käyttää oletuksena OpenAI:n virallista API:a
export OPENAI_MODEL="gpt-3.5-turbo"  # Valinnainen, käyttää oletuksena gpt-3.5-turbo-mallia
export OPENAI_MAX_TOKENS="4096"  # Valinnainen, aseta maksimi token-määrärajoitus (jätä pois käyttääksesi mallin oletusarvoa, pitkien tekstien käännöksiin suositellaan korkeampaa arvoa, esim. 8192, riippuen käytetyn mallin tukemasta maksimi token-määrästä)
```

Rakenna sivusto, tue monikielistä käännöstä. Käytä nykyistä hakemistoa lähdehakemistona, tulosta `.czon/dist`-hakemistoon.

- Voit määrittää tarvittavat kieliversiot useilla `--lang`-parametreilla (esim. `--lang fi-FI --lang en-US`).
- Lähdekieltä ei tarvitse konfiguroida, CZON havaitsee sen automaattisesti.

```bash
npx czon@latest build --lang fi-FI --lang en-US
```

**Katso lisää parametreja tai apua**:

```bash
npx czon@latest
```
