# Techniques d'utilisation

## Déclarer une date dans le corps du texte

Dans le corps du texte, vous pouvez utiliser une déclaration de date telle que "Aujourd'hui, nous sommes le 8 janvier 2026" (le format et le style sont libres). CZON la reconnaîtra et la traitera automatiquement.

Traditionnellement, dans les documents Markdown, la date est déclarée via le Frontmatter YAML, ce qui nécessite de se souvenir du champ correspondant, sans quoi la date risque de ne pas être correctement identifiée.

CZON prend en charge la déclaration directe de dates dans le corps du texte, évitant ainsi les problèmes liés à l'oubli de remplir les champs du Frontmatter.

L'IA extrait et déduit automatiquement les informations de date présentes dans le texte et les traite comme date de création du document.

Cette approche est plus flexible et intelligente, améliorant ainsi l'expérience utilisateur.

À noter que les documents possédant une date peuvent générer une vue chronologique, facilitant la navigation et la gestion. Cela est particulièrement adapté aux types de contenu nécessitant une chronologie, comme les journaux personnels ou les blogs.
