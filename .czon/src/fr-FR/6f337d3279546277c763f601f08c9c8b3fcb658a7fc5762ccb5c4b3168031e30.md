# CZON - Moteur de contenu Markdown AI-Native

- **C**: **C**ontent oriented | Contenu roi, concentré sur le contenu
- **Z**: **Z**ero Configuration | Écriture sans configuration, réduisant les interruptions
- **O**: **O**rganic AI-Native | IA native organique, intégration profonde de l'IA
- **N**: **N**-shaped Energy Curve | Courbe d'énergie en forme de N, intervenant dans les étapes création-distribution-feedback

[> Démo du site web](https://czon.zccz14.com/)

À l'ère de l'IA, en tant que créateur de contenu web, nous pouvons avoir un moteur de création de contenu plus intelligent.

**Retour au contenu : Minimiser les distractions, se concentrer sur l'écriture**

Rendre la documentation à son essence, rendre l'écriture paisible.

Premièrement, je ne veux pas être bibliothécaire. Parfois, je veux écrire du contenu, mais je n'ai peut-être pas encore pensé à son titre, je n'ai pas encore formé d'organisation particulière. Je souhaite que l'IA génère automatiquement des titres, crée des résumés, classe, navigue et organise.

Deuxièmement, mon espace de travail doit être propre. Je ne veux pas d'outils de construction complexes à configurer, je ne veux pas me battre avec des configurations de documentation complexes, je n'aime pas les structures complexes. Chaque fois que je vois les fichiers de configuration et les structures de projet d'outils comme Docusaurus, VuePress, Astro, j'ai mal à la tête. Maintenant, CZON choisit de cacher toutes les configurations dans le répertoire .czon, les balayant dans un coin, permettant aux utilisateurs de se concentrer uniquement sur l'écriture du contenu, le reste étant géré par CZON. Tous les autres répertoires sont votre espace d'écriture, vous pouvez organiser vos fichiers Markdown comme vous le souhaitez.

**Retour à la langue maternelle : Écrire dans sa langue maternelle, construire facilement des versions multilingues**

La vie est courte, je suis trop paresseux pour traduire. Les gens sont les plus profonds dans leur réflexion lorsqu'ils utilisent leur langue maternelle. Mais en même temps, rester connecté au monde est nécessaire, je ne veux pas abandonner la communication multilingue. J'espère donc avoir un outil qui me permette d'écrire dans ma langue maternelle tout en permettant à plus de personnes de voir mon contenu. Actuellement, l'i18n nécessite non seulement de traduire soi-même, mais aussi de maintenir les mises à jour du contenu, c'est trop fastidieux. Je choisis d'utiliser l'IA pour m'aider à traduire, ce qui me fait gagner beaucoup de temps et permet de réaliser des traductions multilingues en un clic.

## Fonctionnalités de base

1. 🌍 **Traduction multilingue automatique** : Utilise l'IA pour la traduction incrémentale, permettant aux utilisateurs d'écrire en Markdown dans leur langue maternelle, mais les utilisateurs peuvent être multilingues.
2. 💭 **Extraction automatique de résumés** : Utilise l'IA pour analyser et extraire le contenu du texte original.
3. 🏷️ **Classification automatique par tags** : Utilise l'IA pour extraire et gérer les tags et classifications du contenu.
4. 🧭 **Navigation intelligente par catégories** : Utilise l'IA pour générer des plans de site et de navigation, la position des fichiers sources n'est pas sensible.

## Génération de site statique (SSG)

CZON intègre une solution SSG qui peut transformer n'importe quel dossier git contenant des fichiers Markdown en un site HTML statique.

⚠️ Veuillez noter que CZON n'est pas un générateur de site statique (SSG) professionnel, mais un moteur de contenu Markdown piloté par l'IA, se concentrant sur la création et la gestion de contenu.

✅ CZON vise à simplifier le processus de création et de publication de contenu, permettant aux utilisateurs de se concentrer sur l'écriture elle-même, plutôt que d'être dérangés par des configurations et des outils complexes.

❌ CZON ne fournira pas de personnalisations de thèmes complexes ni d'écosystème de plugins, mais se concentrera sur l'amélioration de la qualité et de l'accessibilité du contenu grâce à l'IA.

🔔 Cependant, CZON peut toujours générer des sites statiques, si nécessaire, CZON peut être utilisé comme prétraitement, intégrant d'autres solutions SSG pour générer des sites personnalisés et esthétiques.

## Démarrage rapide

Prérequis :

- [Node.js](https://nodejs.org/) installé (version 18 ou supérieure recommandée, nécessite la commande npx)
- [Clé API OpenAI](https://platform.openai.com/account/api-keys) obtenue, ou clé API compatible OpenAI
- Git installé (pour lister les fichiers Markdown à partir de Git, en ignorant les fichiers filtrés par les règles .gitignore)

Tout d'abord, travaillez dans un dossier déjà géré par git :

Configurer les variables d'environnement

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Obligatoire : remplacez par votre clé API OpenAI
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Optionnel, utilise par défaut l'API officielle d'OpenAI
export OPENAI_MODEL="gpt-3.5-turbo"  # Optionnel, utilise par défaut le modèle gpt-3.5-turbo
export OPENAI_MAX_TOKENS="4096"  # Optionnel, définit la limite maximale de tokens (si ignoré, utilise la valeur par défaut du modèle, pour les traductions de textes longs, il est recommandé de définir une valeur plus élevée, par exemple 8192, selon le nombre maximum de tokens supporté par le modèle utilisé)
```

Construire le site, avec support de traduction multilingue. Utilise le répertoire courant comme répertoire source, sortie vers le répertoire `.czon/dist`.

- Vous pouvez spécifier les versions linguistiques à générer en utilisant plusieurs fois le paramètre `--lang` (par exemple `--lang fr-FR --lang en-US`).
- Aucune configuration de langue source n'est nécessaire, CZON détecte automatiquement.

```bash
npx czon@latest build --lang fr-FR --lang en-US
```

**Voir plus de paramètres ou d'aide** :

```bash
npx czon@latest
```
