# CZON - محرك محتوى Markdown الأصلي للذكاء الاصطناعي

- **C**: **C**ontent oriented | المحتوى هو الملك، التركيز على المحتوى
- **Z**: **Z**ero Configuration | الكتابة بدون تكوين، تقليل الإزعاج
- **O**: **O**rganic AI-Native | الذكاء الاصطناعي الأصلي العضوي، تكامل عميق مع الذكاء الاصطناعي
- **N**: **N**-shaped Energy Curve | منحنى الطاقة على شكل N، يتدخل في جميع مراحل الإنشاء-التوزيع-التغذية الراجعة

[> عرض الموقع الإلكتروني](https://czon.zccz14.com/)

في عصر الذكاء الاصطناعي، كمُنشئ محتوى للمواقع الإلكترونية، يمكننا الحصول على محرك إنشاء محتوى أكثر ذكاءً.

**العودة إلى المحتوى: تقليل الإزعاج إلى الحد الأدنى، التركيز على الكتابة**

دع المستندات تعود إلى جوهرها، دع الكتابة تعود إلى الهدوء.

أولاً، لا أريد أن أكون أمين مكتبة. أحيانًا أريد كتابة بعض المحتوى، لكن قد لا أكون قد فكرت في عنوانه بعد، أو لم أكون قد شكلت تنظيماً خاصاً. أريد أن يساعدني LLM تلقائيًا في إنشاء العناوين، وعمل الملخصات، والتصنيف، والتنقل، وغيرها من مهام التنظيم.

ثانيًا، يجب تنظيف مكتبتي. لا أريد أدوات بناء معقدة الإعدادات، أو التعامل مع تكوينات المستندات المعقدة، ولا أحب الهياكل المعقدة. كلما رأيت ملفات التكوين وهياكل المشاريع لأدوات مثل Docusaurus وVuePress وAstro، أشعر بالصداع. الآن، اختار CZON إخفاء جميع الإعدادات في دليل .czon، ودفعها إلى الزاوية، بحيث يحتاج المستخدم فقط إلى التركيز على كتابة المحتوى، ويترك الباقي لـ CZON للتعامل معه. جميع الأدلة الأخرى هي مساحة الكتابة الخاصة بك، ويمكنك تنظيم ملفات Markdown الخاصة بك كما تشاء.

**العودة إلى اللغة الأم: الكتابة بلغتك الأم، بناء إصدارات متعددة اللغات بسلاسة**

الحياة قصيرة، وأنا كسول للترجمة. عندما يستخدم الشخص لغته الأم، يكون قادرًا على استغلال عمق تفكيره إلى أقصى حد. لكن في نفس الوقت، من الضروري الحفاظ على الاتصال بالعالم، ولا أريد التخلي عن التواصل متعدد اللغات. لذلك أريد أداة تسمح لي بالكتابة بلغتي الأم، وفي نفس الوقت تسمح لمزيد من الأشخاص برؤية محتواي. حاليًا، يتطلب i18n الترجمة الذاتية بالإضافة إلى الحفاظ على تحديث المحتوى، وهذا مزعج للغاية. أختار استخدام LLM لمساعدتي في الترجمة، مما يوفر لي الكثير من الوقت، ويمكن إكمال ترجمة لغات متعددة بنقرة واحدة.

## الميزات الأساسية

1. 🌍 **الترجمة التلقائية متعددة اللغات**: استخدام الذكاء الاصطناعي للترجمة التدريجية، مما يسمح للمستخدمين بكتابة Markdown بلغتهم الأم، لكن يمكن للمستخدمين أن يكونوا متعددي اللغات.
2. 💭 **استخراج الملخصات التلقائي**: استخدام الذكاء الاصطناعي لتحليل المحتوى واستخراجه من النص الأصلي.
3. 🏷️ **تصنيف الوسوم التلقائي**: استخدام الذكاء الاصطناعي لاستخراج وإدارة الوسوم والتصنيفات للمحتوى.
4. 🧭 **التنقل الذكي حسب التصنيف**: استخدام الذكاء الاصطناعي لإنشاء خريطة الموقع والتنقل، حيث لا يكون موقع الملفات المصدر حساسًا.

## توليد المواقع الثابتة (SSG)

يحتوي CZON على حل SSG مدمج، يمكنه تحويل أي مجلد git يحتوي على Markdown إلى موقع HTML ثابت.

⚠️ يرجى ملاحظة أن CZON ليس أداة توليد مواقع ثابتة (SSG) احترافية، ولكنه محرك محتوى Markdown مدعوم بالذكاء الاصطناعي، يركز على إنشاء المحتوى وإدارته.

✅ يهدف CZON إلى تبسيط عملية إنشاء المحتوى ونشره، مما يسمح للمستخدمين بالتركيز على الكتابة نفسها، بدلاً من الانشغال بالإعدادات المعقدة والأدوات.

❌ لن يوفر CZON تخصيص قوالب معقدة ونظام إضافات، بل يركز على تحسين جودة المحتوى وإمكانية الوصول إليه من خلال الذكاء الاصطناعي.

🔔 ومع ذلك، لا يزال بإمكان CZON إنشاء مواقع ثابتة، إذا لزم الأمر، يمكن استخدام CZON كمعالج مسبق، ودمجه مع حلول SSG أخرى لإنشاء مواقع شخصية وجميلة.

## البدء السريع

المتطلبات المسبقة:

- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أعلى موصى به، يجب أن يحتوي على أمر npx)
- الحصول على [OpenAI API Key](https://platform.openai.com/account/api-keys)، أو مفتاح API متوافق مع OPENAI
- تثبيت Git (لإدراج ملفات Markdown من Git، وتجاهل الملفات التي تم تصفيتها بواسطة قواعد .gitignore)

أولاً، العمل في مجلد تمت إدارته بواسطة git بالفعل:

تكوين متغيرات البيئة

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # إلزامي: يرجى استبداله بمفتاح OpenAI API الخاص بك
export OPENAI_BASE_URL="https://api.openai.com/v1"  # اختياري، يستخدم API الرسمي لـ OpenAI افتراضيًا
export OPENAI_MODEL="gpt-3.5-turbo"  # اختياري، يستخدم نموذج gpt-3.5-turbo افتراضيًا
export OPENAI_MAX_TOKENS="4096"  # اختياري، تعيين الحد الأقصى لعدد الرموز (إذا تم تجاهله، يتم استخدام القيمة الافتراضية للنموذج، للترجمة الطويلة يوصى بتعيين قيمة أعلى، مثل 8192، اعتمادًا على الحد الأقصى لعدد الرموز المدعومة من النموذج المستخدم)
```

بناء الموقع، مع دعم الترجمة متعددة اللغات. استخدام الدليل الحالي كدليل مصدر، والإخراج إلى دليل `.czon/dist`.

- يمكن تحديد إصدارات اللغة المطلوبة إنشاؤها باستخدام معلمة `--lang` عدة مرات (مثل `--lang zh-Hans --lang en-US`).
- لا حاجة لتكوين اللغة المصدر، سيكتشف CZON تلقائيًا.

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

**عرض المزيد من المعلمات أو المساعدة**:

```bash
npx czon@latest
```
