# CZON - محرك محتوى Markdown الأصلي للذكاء الاصطناعي

- **C**: **C**ontent oriented | المحتوى هو الملك، التركيز على المحتوى
- **Z**: **Z**ero Configuration | الكتابة بدون تكوين، تقليل الإزعاج
- **O**: **O**rganic AI-Native | أصلي للذكاء الاصطناعي بشكل عضوي، تكامل عميق مع الذكاء الاصطناعي
- **N**: **N**-shaped Energy Curve | منحنى الطاقة على شكل N، يتدخل في جميع مراحل الإنشاء-التوزيع-التغذية الراجعة

[> عرض تجريبي للموقع](https://czon.zccz14.com/)

في عصر الذكاء الاصطناعي، يمكننا كمنشئي محتوى للمواقع أن نحصل على محرك إنشاء محتوى أكثر ذكاءً.

**العودة إلى المحتوى: تقليل الإزعاج إلى الحد الأدنى، التركيز على الكتابة**

دع المستندات تعود إلى جوهرها، ودع الكتابة تعود إلى الهدوء.

أولاً، لا أريد أن أكون أمين مكتبة. أحيانًا أريد كتابة بعض المحتوى، لكن قد لا أكون قد فكرت في عنوانه بعد، أو لم أقم بتنظيمه بشكل خاص. أتمنى أن يساعدني الذكاء الاصطناعي اللغوي الكبير (LLM) تلقائيًا في إنشاء العناوين، وعمل الملخصات، والتصنيف، والتنقل، وغيرها من مهام التنظيم.

ثانيًا، يجب تنظيف مكتبتي. لا أريد أدوات بناء معقدة التكوين، أو التعامل مع تكوينات المستندات المعقدة، ولا أحب الهياكل المعقدة. كلما رأيت ملفات التكوين وهياكل المشاريع لأدوات مثل Docusaurus و VuePress و Astro، أشعر بالصداع. الآن، اختار CZON إخفاء جميع التكوينات في دليل `.czon`، ودفعها إلى الزاوية، بحيث يحتاج المستخدم فقط إلى التركيز على كتابة المحتوى، ويترك الباقي لـ CZON للتعامل معه. جميع الأدلة الأخرى هي مساحة الكتابة الخاصة بك، يمكنك تنظيم ملفات Markdown الخاصة بك كما تشاء.

**العودة إلى اللغة الأم: الكتابة باللغة الأم، بناء إصدارات متعددة اللغات بسلاسة**

الحياة قصيرة، أنا كسول للترجمة. عندما يستخدم الشخص لغته الأم، يكون قادرًا على استغلال عمق تفكيره إلى أقصى حد. ولكن في نفس الوقت، من الضروري الحفاظ على الاتصال بالعالم، ولا أريد التخلي عن التواصل متعدد اللغات. لذلك، أتمنى أن يكون هناك أداة تسمح لي بالكتابة بلغتي الأم، وفي نفس الوقت تسمح للمزيد من الأشخاص برؤية محتواي. حاليًا، يتطلب i18n منك الترجمة بنفسك، بالإضافة إلى الحفاظ على تحديث المحتوى، وهذا مزعج جدًا. أختار استخدام الذكاء الاصطناعي اللغوي الكبير (LLM) لمساعدتي في الترجمة، مما يوفر لي الكثير من الوقت، ويمكن إكمال ترجمة لغات متعددة بنقرة واحدة.

## الوظائف الأساسية

1. 🌍 **ترجمة تلقائية متعددة اللغات**: استخدام الذكاء الاصطناعي للترجمة التدريجية، مما يسمح للمستخدم بكتابة Markdown بلغته الأم، ولكن يمكن للمستخدم أن يكون متعدد اللغات.
2. 💭 **استخراج ملخص تلقائي**: استخدام الذكاء الاصطناعي لتحليل المحتوى واستخراجه من النص الأصلي.
3. 🏷️ **تصنيف وسوم تلقائي**: استخدام الذكاء الاصطناعي لاستخراج وإدارة الوسوم والتصنيفات للمحتوى.
4. 🧭 **تنقل تصنيف ذكي**: استخدام الذكاء الاصطناعي لإنشاء خريطة موقع وتنقل، حيث لا يكون موقع الملفات المصدر حساسًا.

## توليد الموقع الثابت (SSG)

يحتوي CZON على مخطط SSG مدمج، يمكنه تحويل أي مجلد git يحتوي على Markdown إلى موقع HTML ثابت.

⚠️ يرجى ملاحظة أن CZON ليس أداة توليد مواقع ثابتة (SSG) احترافية، بل هو محرك محتوى Markdown مدعوم بالذكاء الاصطناعي، يركز على إنشاء المحتوى وإدارته.

✅ يهدف CZON إلى تبسيط عملية إنشاء المحتوى ونشره، مما يسمح للمستخدمين بالتركيز على الكتابة نفسها، بدلاً من أن يكونوا محاصرين بالتكوينات والأدوات المعقدة.

❌ لن يوفر CZON تخصيص قوالب معقدة ونظامًا بيئيًا للإضافات، بل سيركز على تحسين جودة وإمكانية الوصول إلى المحتوى من خلال الذكاء الاصطناعي.

🔔 ومع ذلك، لا يزال بإمكان CZON توليد مواقع ثابتة، إذا لزم الأمر، يمكن استخدام CZON كمعالج مسبق، ودمجه مع مخططات SSG أخرى لتوليد مواقع شخصية وجميلة.

## البدء السريع

المتطلبات المسبقة:

-   تثبيت [Node.js](https://nodejs.org/) (يُقترح الإصدار 18 أو أعلى، يجب أن يحتوي على أمر npx)
-   الحصول على [مفتاح OpenAI API](https://platform.openai.com/account/api-keys)، أو مفتاح API متوافق مع OPENAI
-   تثبيت Git (لإدراج ملفات Markdown من Git، وتجاهل الملفات التي تمت تصفيتها بواسطة قواعد .gitignore)

أولاً، العمل في مجلد تمت إدارته بالفعل بواسطة git:

تكوين متغيرات البيئة

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # إلزامي: يرجى استبداله بمفتاح OpenAI API الخاص بك
export OPENAI_BASE_URL="https://api.openai.com/v1"  # اختياري، يستخدم API الرسمي لـ OpenAI افتراضيًا
export OPENAI_MODEL="gpt-3.5-turbo"  # اختياري، يستخدم نموذج gpt-3.5-turbo افتراضيًا
export OPENAI_MAX_TOKENS="4096"  # اختياري، تعيين الحد الأقصى لعدد الرموز (إذا تم تجاهله، سيتم استخدام القيمة الافتراضية للنموذج، للترجمة الطويلة يُنصح بتعيين قيمة أعلى، مثل 8192، اعتمادًا على الحد الأقصى لعدد الرموز المدعومة من النموذج المستخدم)
```

بناء الموقع، مع دعم الترجمة متعددة اللغات. استخدام الدليل الحالي كدليل مصدر، والإخراج إلى دليل `.czon/dist`.

-   يمكن تحديد إصدارات اللغة المطلوبة عن طريق استخدام معلمة `--lang` عدة مرات (على سبيل المثال `--lang zh-Hans --lang en-US`).
-   لا حاجة لتكوين لغة المصدر، سيكتشف CZON تلقائيًا.

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

**عرض المزيد من المعلمات أو المساعدة**:

```bash
npx czon@latest
```
