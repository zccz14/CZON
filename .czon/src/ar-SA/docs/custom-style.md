# تخصيص الأنماط

يدعم CZON تخصيص أنماط الموقع من خلال ملف `.czon/style.css`، مما يتيح لك تجاوز الأنماط الافتراضية أو إضافة مظهر شخصي.

## طريقة الاستخدام

1.  قم بإنشاء ملف `style.css` في دليل `.czon` الخاص بالمشروع:

```
your-project/
├── .czon/
│   ├── meta.json
│   └── style.css    <-- إنشاء هذا الملف
├── README.md
└── docs/
```

2.  اكتب CSS المخصص الخاص بك في `style.css`:

```css
/* مثال: تعديل لون الروابط */
:root {
  --link-color: #0066cc;
}

/* مثال: تعديل الخلفية في وضع الظلام */
html.dark {
  --bg-primary: #0d1117;
}
```

3.  أعد تشغيل `czon build`، وسيتم تطبيق الأنماط المخصصة تلقائيًا على جميع الصفحات.

## آلية العمل

-   أثناء البناء، سيكتشف CZON وجود ملف `.czon/style.css`
-   إذا كان الملف موجودًا، فسيتم نسخه إلى دليل الإخراج `.czon/dist/style.css`
-   في كل صفحة HTML يتم إنشاؤها، سيتم إضافة رابط الأنماط داخل `<head>`:
    ```html
    <link rel="stylesheet" href="style.css" />
    ```
-   يتم تحميل الأنماط المخصصة بعد الأنماط المدمجة، وبالتالي يمكنها تجاوز الأنماط الافتراضية

## متغيرات CSS المتاحة

يستخدم CZON متغيرات CSS لتحديد ألوان السمة، يمكنك تعديل الألوان بسرعة عن طريق تجاوز هذه المتغيرات:

```css
:root {
  /* ألوان الخلفية */
  --bg-primary: #ffffff;
  --bg-secondary: #f8f9fa;
  --bg-tertiary: #e9ecef;

  /* ألوان النص */
  --text-primary: #333333;
  --text-secondary: #6c757d;
  --text-muted: #adb5bd;

  /* ألوان الروابط والتأكيد */
  --link-color: #007bff;
  --link-hover-color: #0056b3;

  /* ألوان الحدود */
  --border-color: #dee2e6;
}

/* متغيرات وضع الظلام */
html.dark {
  --bg-primary: #1a1a1a;
  --bg-secondary: #2d2d2d;
  --bg-tertiary: #404040;

  --text-primary: #e5e5e5;
  --text-secondary: #a0a0a0;
  --text-muted: #6c6c6c;

  --link-color: #58a6ff;
  --link-hover-color: #79b8ff;

  --border-color: #404040;
}
```

## أمثلة

### تخصيص لون العلامة التجارية

```css
:root {
  --link-color: #e91e63;
  --link-hover-color: #c2185b;
}

html.dark {
  --link-color: #f48fb1;
  --link-hover-color: #f8bbd9;
}
```

### ضبط عرض منطقة المحتوى

```css
.content {
  max-width: 60rem;
}
```

### تخصيص نمط كتل الكود

```css
pre code {
  font-family: 'Fira Code', 'JetBrains Mono', monospace;
  font-size: 0.875rem;
}
```

### إخفاء عناصر محددة

```css
/* إخفاء شريط المحتويات الجانبي الأيمن */
.sidebar-right {
  display: none;
}
```

## ملاحظات هامة

-   يجب أن يكون اسم ملف الأنماط المخصص هو `style.css`، ويوضع في دليل `.czon/`
-   بعد تعديل الأنماط، يجب إعادة تشغيل `czon build` لتصبح التعديلات سارية المفعول
-   يُنصح باستخدام طريقة تجاوز متغيرات CSS لتخصيص الأنماط، لأن ذلك يتوافق مع كل من وضعي الضوء والظلام
-   يستخدم CZON إطار Tailwind CSS، إذا كنت بحاجة إلى تجاوز الأنماط التي يولدها Tailwind، فقد تحتاج إلى استخدام `!important`
