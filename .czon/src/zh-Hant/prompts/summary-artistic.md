# 文藝感性風格分析報告

## 閱讀關注點

閱讀每個文件時，重點提取：

- 文件路徑和標題
- 情感表達和情緒波動
- 富有畫面感的描述
- 有感染力的句子（可引用）
- 人物形象和性格特徵
- 故事性元素（起承轉合）
- 意象和比喻

**特別關注**：第一人稱敘述、情感詞彙、生動描寫、人生感悟

## 壓縮策略

當需要壓縮知識庫時：

1.  **必須保留**：文件索引、金句索引、情感脈絡
2.  **可以精簡**：意象索引（保留核心意象）、人物素描（保留主要人物）
3.  **可以丟棄**：次要的情感細節

## 風格定位

透過細膩的描寫和情感表達，營造身臨其境的感覺，讓讀者感受內容中的情感和氛圍。

**目標讀者**：喜歡文學性表達的讀者、尋求情感共鳴的讀者
**寫作語氣**：詩意、感性、富有畫面感
**目的**：激發共鳴和情感反應，讓內容更有感染力

## 核心原則

- ✅ 使用生動的語言和形象的比喻
- ✅ 創造畫面感和意境
- ✅ 講述故事，引導讀者進入情境
- ✅ 表達情感，但基於內容事實
- ❌ 不脫離原文內容虛構

## 必需章節結構

### 引言（詩意開場）

用富有意境的語言開場，設定情感基調

```markdown
在程式碼與文字交織的數位森林裡，有一位旅人正在記錄他的足跡...
```

### 主題篇章

每個主題用敘事性段落展開：

```markdown
## [詩意的章節標題]

[用故事化的方式描述主題內容，融入情感和意象]

當 [人物] 寫下 [內容] 時，彷彿能看到 [意象描寫]...

> "[引用原文中有感染力的句子]"
> —— [來源](../path/to/file.md)

[繼續敘事，連接到下一個要點]
```

### 人物素描

用文學性語言描繪人物形象

### 時間的河流

用敘事方式描述時間線上的變化

### 結語（情感昇華）

總結性的詩意結尾，留下回味

```markdown
這不僅僅是一個程式碼倉庫，更是一個思想者在數位時代留下的足跡...
```

## 寫作技巧

- 使用比喻：將抽象概念具象化
- 使用意象：創造視覺畫面
- 使用節奏：長短句交替，創造韻律感
- 引用原文：選擇有感染力的句子
