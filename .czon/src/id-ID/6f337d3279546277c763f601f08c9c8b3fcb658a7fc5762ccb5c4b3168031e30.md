# CZON - Mesin Konten Markdown AI-Native

- **C**: **C**ontent oriented | Berorientasi konten, fokus pada konten
- **Z**: **Z**ero Configuration | Penulisan tanpa konfigurasi, mengurangi gangguan
- **O**: **O**rganic AI-Native | AI-native organik, integrasi AI mendalam
- **N**: **N**-shaped Energy Curve | Kurva energi berbentuk N, terlibat dalam setiap tahap penciptaan-distribusi-umpan balik

[> Demo Situs Web](https://czon.zccz14.com/)

Di era AI, sebagai pembuat konten situs web, kita dapat memiliki mesin pembuatan konten yang lebih cerdas.

**Kembali ke Konten: Minimalkan Gangguan, Fokus pada Penulisan**

Kembalikan dokumen ke esensinya, kembalikan ketenangan dalam menulis.

Pertama, saya tidak ingin menjadi pustakawan. Terkadang saya ingin menulis sesuatu, tetapi mungkin saya belum memikirkan judulnya, belum membentuk organisasi khusus. Saya berharap LLM akan secara otomatis membantu saya membuat judul, membuat ringkasan, mengklasifikasikan, navigasi, dan pekerjaan pengorganisasian lainnya.

Kedua, ruang kerja saya harus bersih. Saya tidak ingin alat pembangun dengan konfigurasi kompleks, mengutak-atik konfigurasi dokumen yang rumit, tidak menyukai struktur yang kompleks. Setiap kali saya melihat file konfigurasi dan struktur proyek dari alat seperti Docusaurus, VuePress, Astro, saya pusing. Sekarang, CZON memilih untuk menyembunyikan semua konfigurasi ke dalam direktori .czon, menyimpannya di sudut, pengguna hanya perlu fokus pada penulisan konten, sisanya diserahkan kepada CZON untuk diproses. Direktori lainnya adalah ruang penulisan Anda, Anda dapat mengatur file Markdown Anda sesuka hati.

**Kembali ke Bahasa Ibu: Menulis dalam Bahasa Ibu, Membangun Versi Multibahasa dengan Lancar**

Hidup ini singkat, saya malas menerjemahkan. Orang paling dapat mengungkapkan kedalaman pemikirannya ketika menggunakan bahasa ibu. Tetapi tetap terhubung dengan dunia juga diperlukan, saya tidak ingin melepaskan komunikasi multibahasa. Oleh karena itu, saya berharap ada alat yang memungkinkan saya menulis dalam bahasa ibu, sementara juga memungkinkan lebih banyak orang melihat konten saya. i18n saat ini tidak hanya mengharuskan Anda menerjemahkan sendiri, tetapi juga harus memelihara pembaruan konten sendiri, terlalu merepotkan. Saya memilih menggunakan LLM untuk membantu saya menerjemahkan, menghemat banyak waktu saya, dan dapat menyelesaikan terjemahan multibahasa dengan satu klik.

## Fitur Dasar

1. 🌍 **Terjemahan Multibahasa Otomatis**: Menggunakan AI untuk terjemahan inkremental, memungkinkan pengguna menulis Markdown dalam bahasa ibu, tetapi pengguna dapat multibahasa.
2. 💭 **Ekstraksi Ringkasan Otomatis**: Menggunakan AI untuk analisis dan ekstraksi konten dari teks asli.
3. 🏷️ **Klasifikasi Tag Otomatis**: Menggunakan AI untuk ekstraksi dan manajemen tag dan klasifikasi konten.
4. 🧭 **Navigasi Klasifikasi Cerdas**: Menggunakan AI untuk menghasilkan peta situs dan navigasi, lokasi file sumber tidak sensitif.

## Pembuatan Situs Statis (SSG)

CZON memiliki skema SSG bawaan yang dapat membangun folder git yang berisi Markdown menjadi situs HTML statis.

⚠️ Harap diperhatikan, CZON bukan pembuat situs statis (SSG) profesional, melainkan mesin konten Markdown yang digerakkan oleh AI, berfokus pada pembuatan dan manajemen konten.

✅ CZON bertujuan untuk menyederhanakan proses pembuatan dan publikasi konten, memungkinkan pengguna fokus pada penulisan itu sendiri, bukan terganggu oleh konfigurasi dan alat yang kompleks.

❌ CZON tidak akan menyediakan kustomisasi tema dan ekosistem plugin yang kompleks, melainkan berfokus pada peningkatan kualitas dan aksesibilitas konten melalui AI.

🔔 Namun, CZON tetap dapat menghasilkan situs statis, jika diperlukan, CZON dapat digunakan sebagai preprocessor, diintegrasikan dengan skema SSG lain untuk menghasilkan situs yang personal dan indah.

## Mulai Cepat

Prasyarat:

- Sudah menginstal [Node.js](https://nodejs.org/) (disarankan versi 18 ke atas, perlu memiliki perintah npx)
- Sudah mendapatkan [OpenAI API Key](https://platform.openai.com/account/api-keys), atau API Key yang kompatibel dengan OPENAI
- Sudah menginstal Git (untuk mendaftar file Markdown dari Git, mengabaikan file yang difilter oleh aturan .gitignore)

Pertama, bekerja di folder yang sudah dikelola oleh git:

Konfigurasi variabel lingkungan

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Wajib: harap ganti dengan OpenAI API Key Anda
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Opsional, default menggunakan API resmi OpenAI
export OPENAI_MODEL="gpt-3.5-turbo"  # Opsional, default menggunakan model gpt-3.5-turbo
export OPENAI_MAX_TOKENS="4096"  # Opsional, atur batas maksimum token (abaikan untuk menggunakan nilai default model, untuk terjemahan teks panjang disarankan untuk mengatur nilai yang lebih tinggi, misalnya 8192, tergantung pada jumlah token maksimum yang didukung oleh model yang digunakan)
```

Bangun situs, mendukung terjemahan multibahasa. Gunakan direktori saat ini sebagai direktori sumber, output ke direktori `.czon/dist`.

- Dapat menentukan versi bahasa yang perlu dihasilkan dengan menggunakan parameter `--lang` beberapa kali (misalnya `--lang id-ID --lang en-US`).
- Tidak perlu mengonfigurasi bahasa sumber, CZON akan mendeteksi secara otomatis.

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

**Lihat parameter atau bantuan lainnya**:

```bash
npx czon@latest
```
