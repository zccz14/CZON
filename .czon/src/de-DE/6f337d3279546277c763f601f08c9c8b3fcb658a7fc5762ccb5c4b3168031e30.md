Im AI-Zeitalter können wir als Website-Content-Ersteller eine intelligentere Content-Erstellungs-Engine haben.

**Zurück zum Inhalt: Minimale Störungen, Fokus aufs Schreiben**

Lassen Sie Dokumente zu ihrem Wesen zurückkehren, lassen Sie das Schreiben zur Ruhe kommen.

Erstens möchte ich kein Bibliothekar sein. Manchmal möchte ich etwas aufschreiben, aber ich habe vielleicht noch keinen Titel festgelegt oder eine spezielle Organisation entwickelt. Ich möchte, dass LLM automatisch Titel generiert, Zusammenfassungen erstellt, klassifiziert, navigiert und andere Organisationsaufgaben übernimmt.

Zweitens muss mein Arbeitsbereich sauber sein. Ich möchte keine komplexen Build-Tools konfigurieren, keine komplizierten Dokumentenkonfigurationen herumhantieren und keine komplexen Strukturen. Jedes Mal, wenn ich die Konfigurationsdateien und Projektstrukturen von Tools wie Docusaurus, VuePress, Astro sehe, bekomme ich Kopfschmerzen. Jetzt wählt CZON, alle Konfigurationen im .czon-Verzeichnis zu verstecken, in eine Ecke zu schieben, sodass Nutzer sich nur auf den Inhalt konzentrieren müssen und den Rest CZON überlassen können. Alle anderen Verzeichnisse sind Ihr Schreibbereich, Sie können Ihre Markdown-Dateien beliebig organisieren.

**Zurück zur Muttersprache: In der Muttersprache schreiben, nahtlos mehrsprachige Versionen erstellen**

Das Leben ist kurz, ich bin zu faul zum Übersetzen. Menschen können ihre Denktiefe am besten entfalten, wenn sie ihre Muttersprache verwenden. Gleichzeitig ist es notwendig, mit der Welt verbunden zu bleiben, und ich möchte den mehrsprachigen Austausch nicht aufgeben. Daher wünsche ich mir ein Tool, das mir ermöglicht, in meiner Muttersprache zu schreiben und gleichzeitig mehr Menschen meinen Inhalt zugänglich zu machen. Aktuelle i18n-Lösungen erfordern nicht nur eigene Übersetzungen, sondern auch eigene Inhaltsaktualisierungen - das ist zu aufwändig. Ich wähle LLM, um Übersetzungen für mich zu erledigen, was mir viel Zeit spart und mit einem Klick mehrsprachige Übersetzungen ermöglicht.

## Grundfunktionen

1. 🌍 **Automatische mehrsprachige Übersetzung**: Nutzt AI für inkrementelle Übersetzungen, ermöglicht Nutzern, Markdown in ihrer Muttersprache zu schreiben, während die Inhalte mehrsprachig sein können.
2. 💭 **Automatische Zusammenfassungsextraktion**: Nutzt AI zur Inhaltsanalyse und -extraktion des Originaltextes.
3. 🏷️ **Automatische Tag-Klassifizierung**: Nutzt AI zur Extraktion und Verwaltung von Tags und Kategorien für Inhalte.
4. 🧭 **Intelligente Kategorienavigation**: Nutzt AI zur Generierung von Sitemaps und Navigation, unabhängig von der Position der Quelldateien.

## Statische Site-Generierung (SSG)

CZON verfügt über ein integriertes SSG-Schema, das jeden Git-Ordner mit Markdown-Dateien in eine statische HTML-Site umwandeln kann.

⚠️ Bitte beachten Sie: CZON ist kein professioneller statischer Site-Generator (SSG), sondern eine AI-gesteuerte Markdown-Content-Engine, die sich auf Content-Erstellung und -Management konzentriert.

✅ CZON zielt darauf ab, den Content-Erstellungs- und Veröffentlichungsprozess zu vereinfachen, sodass Nutzer sich auf das Schreiben selbst konzentrieren können, anstatt von komplexen Konfigurationen und Tools überfordert zu werden.

❌ CZON bietet keine komplexen Theme-Anpassungen und Plugin-Ökosysteme, sondern konzentriert sich darauf, durch AI die Qualität und Zugänglichkeit von Inhalten zu verbessern.

🔔 Dennoch kann CZON statische Sites generieren. Bei Bedarf kann CZON als Preprozessor verwendet werden, um andere SSG-Schemata zu integrieren und personalisierte, ansprechende Sites zu erstellen.

## Schnellstart

Voraussetzungen:

- [Node.js](https://nodejs.org/) installiert (empfohlene Version 18 oder höher, npx-Befehl erforderlich)
- [OpenAI API Key](https://platform.openai.com/account/api-keys) erhalten oder OPENAI-kompatibler API Key
- Git installiert (zum Auflisten von Markdown-Dateien aus Git, ignoriert durch .gitignore-Regeln gefilterte Dateien)

Zuerst arbeiten Sie in einem bereits von Git verwalteten Ordner:

Umgebungsvariablen konfigurieren

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Erforderlich: Bitte durch Ihren OpenAI API Key ersetzen
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Optional, standardmäßig wird die offizielle OpenAI API verwendet
export OPENAI_MODEL="gpt-3.5-turbo"  # Optional, standardmäßig wird das gpt-3.5-turbo Modell verwendet
export OPENAI_MAX_TOKENS="4096"  # Optional, setzt die maximale Token-Anzahl (wenn nicht gesetzt, wird der Standardwert des Modells verwendet, für lange Textübersetzungen wird ein höherer Wert empfohlen, z.B. 8192, abhängig von der maximalen Token-Anzahl des verwendeten Modells)
```

Site mit mehrsprachiger Übersetzung erstellen. Verwendet das aktuelle Verzeichnis als Quellverzeichnis, Ausgabe in das `.czon/dist` Verzeichnis.

- Mehrere Sprachversionen können durch wiederholte Verwendung des `--lang` Parameters angegeben werden (z.B. `--lang de-DE --lang en-US`).
- Keine Konfiguration der Quellsprache erforderlich, CZON erkennt diese automatisch.

```bash
npx czon@latest build --lang de-DE --lang en-US
```

**Weitere Parameter oder Hilfe anzeigen**:

```bash
npx czon@latest
```
