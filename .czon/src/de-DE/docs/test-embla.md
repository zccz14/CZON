# Embla-Karussell-Effekttest

Dies ist ein Dokument zum Testen der Effekte des Embla-Karussells.

Mehrere aufeinanderfolgende Bilder werden als Karussell angezeigt. Benutzer können die Ansicht wechseln, indem sie auf Pfeile klicken oder die Bilder ziehen.

![Bild1](../logo.png)
![Bild2](../logo.png)
![Bild3](../logo.png)

Wenn jedoch Textinhalte dazwischen eingefügt werden, wird die Kontinuität des Karussells unterbrochen und es bildet sich eine neue Karussellgruppe.
