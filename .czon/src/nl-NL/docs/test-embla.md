# Embla Carousel Effect Test

Dit is een document voor het testen van de Embla carousel-effecten.

Meerdere opeenvolgende afbeeldingen worden weergegeven als een carousel. Gebruikers kunnen van weergave wisselen door op pijlen te klikken of afbeeldingen te slepen.

![Afbeelding1](../logo.png)
![Afbeelding2](../logo.png)
![Afbeelding3](../logo.png)

Als er echter tekstinhoud tussen wordt ingevoegd, wordt de continuïteit van de carousel onderbroken, waardoor een nieuwe carouselgroep ontstaat.
