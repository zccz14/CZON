# CZON - AI-नेटिव Markdown कंटेंट इंजन

- **C**: **C**ontent oriented | कंटेंट सर्वोपरि, कंटेंट पर ध्यान केंद्रित
- **Z**: **Z**ero Configuration | ज़ीरो कॉन्फ़िगरेशन लेखन, व्यवधान कम करें
- **O**: **O**rganic AI-Native | जैविक AI-नेटिव, AI का गहरा एकीकरण
- **N**: **N**-shaped Energy Curve | N-आकार की ऊर्जा वक्र, निर्माण-वितरण-प्रतिक्रिया के हर चरण में हस्तक्षेप

[> वेबसाइट डेमो](https://czon.zccz14.com/)

AI युग में, एक वेबसाइट कंटेंट क्रिएटर के रूप में, हमारे पास अधिक बुद्धिमान कंटेंट निर्माण इंजन हो सकता है।

**कंटेंट पर वापसी: न्यूनतम व्यवधान, लेखन पर ध्यान केंद्रित**

दस्तावेज़ों को उनके मूल सार तक वापस लाएं, लेखन को शांति से वापस लाएं।

पहला, मैं पुस्तकालयाध्यक्ष नहीं बनना चाहता। मैं कभी-कभी कुछ सामग्री लिखना चाहता हूं, लेकिन हो सकता है कि मैंने अभी तक इसका शीर्षक तय न किया हो, कोई विशेष संगठन न बनाया हो। मैं चाहता हूं कि LLM स्वचालित रूप से मेरी मदद करे शीर्षक जनरेट करने, सारांश बनाने, वर्गीकरण करने, नेविगेशन आदि व्यवस्थित करने का काम।

दूसरा, मेरे अध्ययन कक्ष को साफ-सुथरा रखना होगा। मुझे जटिल कॉन्फ़िगरेशन वाले बिल्ड टूल्स, जटिल दस्तावेज़ कॉन्फ़िगरेशन में उलझना, जटिल संरचनाएं पसंद नहीं हैं। हर बार जब मैं Docusaurus, VuePress, Astro जैसे टूल्स के कॉन्फ़िगरेशन फ़ाइलों और प्रोजेक्ट संरचनाओं को देखता हूं, तो मेरा सिर दर्द करने लगता है। अब, CZON ने सभी कॉन्फ़िगरेशन को `.czon` डायरेक्टरी में छिपाकर, कोने में सरका देने का विकल्प चुना है, उपयोगकर्ता को केवल लेखन सामग्री पर ध्यान केंद्रित करने की आवश्यकता है, बाकी सब CZON संभाल लेगा। अन्य सभी निर्देशिकाएं आपकी लेखन जगह हैं, आप अपनी Markdown फ़ाइलों को मनमाने ढंग से व्यवस्थित कर सकते हैं।

**मातृभाषा पर वापसी: मातृभाषा में लिखें, बहुभाषी संस्करणों का सहज निर्माण करें**

जीवन छोटा है, मैं अनुवाद करने में आलसी हूं। व्यक्ति अपनी मातृभाषा का उपयोग करते समय ही अपनी सोच की गहराई का सर्वोत्तम उपयोग कर सकता है। लेकिन साथ ही दुनिया से जुड़े रहना भी आवश्यक है, मैं बहुभाषी संचार को छोड़ना नहीं चाहता। इसलिए मैं एक ऐसे टूल की कामना करता हूं जो मुझे मातृभाषा में लिखने दे, साथ ही मेरी सामग्री को और अधिक लोगों तक पहुंचने दे। वर्तमान i18n में न केवल खुद अनुवाद करना पड़ता है, बल्कि सामग्री अपडेट भी खुद से बनाए रखनी पड़ती है, यह बहुत परेशानी भरा है। मैंने अनुवाद करने के लिए LLM का उपयोग करने का विकल्प चुना है, इससे मेरा बहुत समय बचता है, और एक क्लिक में कई देशों की भाषाओं में अनुवाद पूरा किया जा सकता है।

## मूलभूत कार्यक्षमताएं

1. 🌍 **स्वचालित बहुभाषी अनुवाद**: AI का उपयोग करके वृद्धिशील अनुवाद, उपयोगकर्ता मातृभाषा में Markdown लिख सकते हैं, लेकिन उपयोगकर्ता बहुभाषी हो सकते हैं।
2. 💭 **स्वचालित सारांश निष्कर्षण**: AI का उपयोग करके मूल पाठ का विश्लेषण और सारांश निकालना।
3. 🏷️ **स्वचालित टैग वर्गीकरण**: AI का उपयोग करके सामग्री के लिए टैग और वर्गीकरण का निष्कर्षण और प्रबंधन।
4. 🧭 **स्मार्ट वर्गीकरण नेविगेशन**: AI का उपयोग करके साइटमैप और नेविगेशन जनरेट करना, स्रोत फ़ाइलों के स्थान से असंवेदनशील।

## स्टैटिक साइट जनरेशन (SSG)

CZON में एक SSG समाधान अंतर्निहित है, जो Markdown युक्त किसी भी git फ़ोल्डर को एक स्टैटिक HTML साइट में बदल सकता है।

⚠️ कृपया ध्यान दें, CZON एक पेशेवर स्टैटिक साइट जनरेटर (SSG) नहीं है, बल्कि एक AI-संचालित Markdown कंटेंट इंजन है, जो कंटेंट निर्माण और प्रबंधन पर केंद्रित है।

✅ CZON का उद्देश्य कंटेंट निर्माण और प्रकाशन की प्रक्रिया को सरल बनाना है, ताकि उपयोगकर्ता लेखन पर ही ध्यान केंद्रित कर सकें, न कि जटिल कॉन्फ़िगरेशन और टूल्स से परेशान हों।

❌ CZON जटिल थीम अनुकूलन और प्लगइन इकोसिस्टम प्रदान नहीं करेगा, बल्कि AI के माध्यम से कंटेंट की गुणवत्ता और पहुंच को बढ़ाने पर ध्यान केंद्रित करेगा।

🔔 हालांकि, CZON फिर भी स्टैटिक साइट जनरेट कर सकता है, यदि आवश्यक हो तो CZON को प्रीप्रोसेसर के रूप में उपयोग करके, अन्य SSG समाधानों के साथ एकीकृत कर व्यक्तिगत, सुंदर साइट जनरेट की जा सकती है।

## त्वरित प्रारंभ

पूर्वापेक्षाएँ:

- [Node.js](https://nodejs.org/) इंस्टॉल है (सुझाई गई संस्करण 18 या उससे ऊपर, npx कमांड की आवश्यकता है)
- [OpenAI API Key](https://platform.openai.com/account/api-keys) प्राप्त है, या OPENAI संगत API Key
- Git इंस्टॉल है (Git से Markdown फ़ाइलों को सूचीबद्ध करने के लिए, .gitignore नियमों द्वारा फ़िल्टर की गई फ़ाइलों को अनदेखा करने के लिए)

सबसे पहले, एक ऐसे फ़ोल्डर में काम करें जो पहले से ही git द्वारा प्रबंधित है:

पर्यावरण चर कॉन्फ़िगर करें

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # आवश्यक: कृपया अपने OpenAI API Key से बदलें
export OPENAI_BASE_URL="https://api.openai.com/v1"  # वैकल्पिक, डिफ़ॉल्ट रूप से OpenAI आधिकारिक API का उपयोग करता है
export OPENAI_MODEL="gpt-3.5-turbo"  # वैकल्पिक, डिफ़ॉल्ट रूप से gpt-3.5-turbo मॉडल का उपयोग करता है
export OPENAI_MAX_TOKENS="4096"  # वैकल्पिक, अधिकतम टोकन संख्या सीमा सेट करें (अनदेखा करने पर मॉडल का डिफ़ॉल्ट मान उपयोग होता है, लंबे पाठ अनुवाद के लिए अधिक मान सेट करने की सलाह दी जाती है, जैसे 8192, यह उपयोग किए जा रहे मॉडल द्वारा समर्थित अधिकतम टोकन संख्या पर निर्भर करता है)
```

साइट बनाएं, बहुभाषी अनुवाद का समर्थन करता है। स्रोत निर्देशिका के रूप में वर्तमान निर्देशिका का उपयोग करें, आउटपुट `.czon/dist` निर्देशिका में होगा।

- `--lang` पैरामीटर का बार-बार उपयोग करके आवश्यक भाषा संस्करण निर्दिष्ट किए जा सकते हैं (उदाहरण के लिए `--lang zh-Hans --lang en-US`)।
- स्रोत भाषा कॉन्फ़िगर करने की आवश्यकता नहीं है, CZON स्वचालित रूप से पता लगा लेगा।

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

**अधिक पैरामीटर या सहायता देखें**:

```bash
npx czon@latest
```
