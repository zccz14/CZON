# कस्टम स्टाइल

CZON `.czon/style.css` फ़ाइल के माध्यम से साइट स्टाइल को कस्टमाइज़ करने का समर्थन करता है, जिससे आप डिफ़ॉल्ट स्टाइल को ओवरराइड कर सकते हैं या व्यक्तिगत लुक जोड़ सकते हैं।

## उपयोग विधि

1. प्रोजेक्ट की `.czon` डायरेक्टरी में `style.css` फ़ाइल बनाएं:

```
your-project/
├── .czon/
│   ├── meta.json
│   └── style.css    <-- यह फ़ाइल बनाएं
├── README.md
└── docs/
```

2. `style.css` में अपना कस्टम CSS लिखें:

```css
/* उदाहरण: लिंक कलर बदलें */
:root {
  --link-color: #0066cc;
}

/* उदाहरण: डार्क मोड में बैकग्राउंड बदलें */
html.dark {
  --bg-primary: #0d1117;
}
```

3. `czon build` को फिर से चलाएं, कस्टम स्टाइल स्वचालित रूप से सभी पेजों पर लागू हो जाएगी।

## कार्य सिद्धांत

- बिल्ड करते समय, CZON `.czon/style.css` के अस्तित्व का पता लगाएगा
- यदि मौजूद है, तो इसे आउटपुट डायरेक्टरी `.czon/dist/style.css` में कॉपी कर देगा
- प्रत्येक जनरेट किए गए HTML पेज में, `<head>` के अंदर स्टाइल लिंक जोड़ा जाएगा:
  ```html
  <link rel="stylesheet" href="style.css" />
  ```
- कस्टम स्टाइल बिल्ट-इन स्टाइल के बाद लोड होती है, इसलिए यह डिफ़ॉल्ट स्टाइल को ओवरराइड कर सकती है

## उपलब्ध CSS वेरिएबल्स

CZON थीम कलर को परिभाषित करने के लिए CSS वेरिएबल्स का उपयोग करता है, आप इन वेरिएबल्स को ओवरराइड करके रंग योजना को जल्दी से समायोजित कर सकते हैं:

```css
:root {
  /* बैकग्राउंड कलर */
  --bg-primary: #ffffff;
  --bg-secondary: #f8f9fa;
  --bg-tertiary: #e9ecef;

  /* टेक्स्ट कलर */
  --text-primary: #333333;
  --text-secondary: #6c757d;
  --text-muted: #adb5bd;

  /* लिंक और एक्सेंट कलर */
  --link-color: #007bff;
  --link-hover-color: #0056b3;

  /* बॉर्डर कलर */
  --border-color: #dee2e6;
}

/* डार्क मोड वेरिएबल्स */
html.dark {
  --bg-primary: #1a1a1a;
  --bg-secondary: #2d2d2d;
  --bg-tertiary: #404040;

  --text-primary: #e5e5e5;
  --text-secondary: #a0a0a0;
  --text-muted: #6c6c6c;

  --link-color: #58a6ff;
  --link-hover-color: #79b8ff;

  --border-color: #404040;
}
```

## उदाहरण

### कस्टम ब्रांड कलर

```css
:root {
  --link-color: #e91e63;
  --link-hover-color: #c2185b;
}

html.dark {
  --link-color: #f48fb1;
  --link-hover-color: #f8bbd9;
}
```

### कंटेंट एरिया की चौड़ाई समायोजित करें

```css
.content {
  max-width: 60rem;
}
```

### कोड ब्लॉक स्टाइल कस्टमाइज़ करें

```css
pre code {
  font-family: 'Fira Code', 'JetBrains Mono', monospace;
  font-size: 0.875rem;
}
```

### विशिष्ट एलिमेंट्स छिपाएं

```css
/* दाईं ओर की साइडबार छिपाएं */
.sidebar-right {
  display: none;
}
```

## सावधानियां

- कस्टम स्टाइल फ़ाइल का नाम `style.css` होना चाहिए, और `.czon/` डायरेक्टरी में रखी जानी चाहिए
- स्टाइल संशोधित करने के बाद इसे प्रभावी करने के लिए `czon build` को फिर से चलाना आवश्यक है
- स्टाइल कस्टमाइज़ेशन के लिए CSS वेरिएबल्स को ओवरराइड करने की विधि का उपयोग करने की सलाह दी जाती है, इससे लाइट और डार्क दोनों मोड्स के साथ संगतता बनी रहती है
- CZON Tailwind CSS का उपयोग करता है, यदि Tailwind द्वारा जनरेट की गई स्टाइल को ओवरराइड करने की आवश्यकता है, तो `!important` का उपयोग करना पड़ सकता है
