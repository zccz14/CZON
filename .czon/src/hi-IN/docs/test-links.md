# साइट-आंतरिक लिंक परीक्षण

## साइट-आंतरिक Markdown लिंक परीक्षण

यह साइट-आंतरिक लिंक की शुद्धता सत्यापित करने के लिए एक परीक्षण दस्तावेज़ है।

परीक्षण करने के लिए कृपया निम्नलिखित लिंक पर क्लिक करें:

- [KaTeX परीक्षण दस्तावेज़ से लिंक](test-katex.md)
- [Mermaid आरेख उदाहरण से लिंक](test-mermaid.md)

## फ़ुटनोट परीक्षण:

यह एक फ़ुटनोट का परीक्षण है[^1]।

[^1]: यह फ़ुटनोट की सामग्री है, फ़ुटनोट की सामग्री पृष्ठ के निचले भाग में सही ढंग से प्रदर्शित होनी चाहिए।

## संसाधन फ़ाइल लिंक

एक गैर-Markdown फ़ाइल या छवि के सामान्य लिंक का परीक्षण, जो मूल संसाधन की ओर इशारा करना चाहिए:

[यह JSON की ओर इशारा करने वाला एक लिंक है](../package.json)
