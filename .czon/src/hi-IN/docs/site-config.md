# साइट कॉन्फ़िगरेशन

CZON `.czon/meta.json` फ़ाइल के माध्यम से साइट विकल्पों को कॉन्फ़िगर करने का समर्थन करता है। ये कॉन्फ़िगरेशन वैकल्पिक हैं और प्रारंभिक उपयोग को ब्लॉक नहीं करेंगे।

## कॉन्फ़िगरेशन स्थान

कॉन्फ़िगरेशन आइटम `.czon/meta.json` फ़ाइल के `options.site` फ़ील्ड में स्थित हैं:

```json
{
  "version": "1.0.0",
  "options": {
    "langs": ["zh-Hans", "en-US"],
    "site": {
      "baseUrl": "https://example.com",
      "title": "My Docs",
      "home": "guide.html",
      "gaID": "G-XXXXXXXXXX",
      "clarityID": "your-clarity-id",
      "navLinks": [
        { "title": "होमपेज", "href": "index.html" },
        { "title": "के बारे में", "href": "about.html" }
      ]
    }
  },
  "files": []
}
```

## उपलब्ध कॉन्फ़िगरेशन आइटम

### `site.baseUrl`

साइट बेस URL, sitemap.xml और robots.txt जनरेट करने के लिए उपयोग किया जाता है।

- **प्रकार**: `string`
- **प्रारूप**: पूर्ण URL, जैसे `https://example.com`

```json
{
  "options": {
    "site": {
      "baseUrl": "https://example.com"
    }
  }
}
```

कॉन्फ़िगर होने पर स्वचालित रूप से जनरेट होगा:

- `sitemap.xml` - सभी पृष्ठों वाली साइटमैप
- `robots.txt` में Sitemap घोषणा

### `site.title`

साइट शीर्षक, पृष्ठ हेडर में प्रदर्शित होता है।

- **प्रकार**: `string`
- **डिफ़ॉल्ट मान**: `"CZON"`

```json
{
  "options": {
    "site": {
      "title": "मेरा डॉक्स साइट"
    }
  }
}
```

### `site.gaID`

Google Analytics Measurement ID, Google Analytics सांख्यिकी एकीकृत करने के लिए उपयोग किया जाता है।

- **प्रकार**: `string`
- **प्रारूप**: `G-XXXXXXXXXX`

```json
{
  "options": {
    "site": {
      "gaID": "G-XXXXXXXXXX"
    }
  }
}
```

प्राप्त करने का तरीका: [Google Analytics](https://analytics.google.com/) पर जाकर एक मीडिया संपत्ति बनाएं, "डेटा स्ट्रीम" में Measurement ID प्राप्त करें।

### `site.clarityID`

Microsoft Clarity Project ID, Clarity उपयोगकर्ता व्यवहार विश्लेषण एकीकृत करने के लिए उपयोग किया जाता है।

- **प्रकार**: `string`

```json
{
  "options": {
    "site": {
      "clarityID": "your-project-id"
    }
  }
}
```

प्राप्त करने का तरीका: [Microsoft Clarity](https://clarity.microsoft.com/) पर जाकर एक प्रोजेक्ट बनाएं, प्रोजेक्ट सेटिंग्स में Project ID प्राप्त करें।

### `site.home`

होमपेज पथ कॉन्फ़िगरेशन, कस्टम होमपेज रीडायरेक्ट लक्ष्य के लिए उपयोग किया जाता है।

- **प्रकार**: `string`
- **डिफ़ॉल्ट मान**: `"index.html"`

```json
{
  "options": {
    "site": {
      "home": "guide.html"
    }
  }
}
```

**व्यवहार विवरण**:

- **रूट होमपेज पर जाने पर**: उपयोगकर्ता `/index.html` पर जाने पर, ब्राउज़र भाषा के आधार पर स्वचालित रूप से `/{पता चली भाषा}/{home}` पर रीडायरेक्ट होगा
- **हेडर शीर्षक पर क्लिक करने पर**: वर्तमान भाषा निर्देशिका के तहत `home` पथ पर रीडायरेक्ट होगा

**उपयोग परिदृश्य**:

- चाहते हैं कि उपयोगकर्ता पहली बार आने पर सीधे किसी विशिष्ट पृष्ठ (जैसे प्रारंभ गाइड, उत्पाद परिचय आदि) पर जाएं
- साइट होमपेज लेख सूची नहीं है, बल्कि कोई विशिष्ट दस्तावेज़ पृष्ठ है

### `site.navLinks`

त्वरित नेविगेशन लिंक कॉन्फ़िगरेशन, पृष्ठ हेडर में नेविगेशन लिंक प्रदर्शित करता है।

- **प्रकार**: `Array<{ title: string, href: string }>`
- **डिफ़ॉल्ट मान**: `undefined` (नेविगेशन प्रदर्शित नहीं होगा)

```json
{
  "options": {
    "site": {
      "navLinks": [
        { "title": "होमपेज", "href": "index.html" },
        { "title": "दस्तावेज़", "href": "docs.html" },
        { "title": "के बारे में", "href": "about.html" }
      ]
    }
  }
}
```

**प्रतिक्रियाशील व्यवहार**:

- **मोबाइल**: हैमबर्गर मेनू आइकन प्रदर्शित करता है, क्लिक करने पर सभी नेविगेशन लिंक विस्तृत होते हैं
- **डेस्कटॉप**: हेडर में सीधे नेविगेशन लिंक प्रदर्शित करता है, लेकिन स्क्रीन चौड़ाई के 40% से अधिक नहीं; अतिरिक्त लिंक "More" ड्रॉपडाउन मेनू के माध्यम से प्रदर्शित होते हैं

## पूर्ण उदाहरण

```json
{
  "version": "1.0.0",
  "options": {
    "langs": ["zh-Hans", "en-US", "ja-JP"],
    "site": {
      "baseUrl": "https://example.com",
      "title": "तकनीकी ब्लॉग",
      "home": "getting-started.html",
      "gaID": "G-ABC123DEF4",
      "clarityID": "abc123xyz",
      "navLinks": [
        { "title": "होमपेज", "href": "index.html" },
        { "title": "दस्तावेज़", "href": "docs.html" },
        { "title": "ब्लॉग", "href": "blog.html" }
      ]
    }
  },
  "files": []
}
```

## ध्यान देने योग्य बातें

- कॉन्फ़िगरेशन संशोधित करने के बाद `czon build` को पुनः चलाने की आवश्यकता होती है
- सभी `site` कॉन्फ़िगरेशन आइटम वैकल्पिक हैं, आवश्यक भागों को ही कॉन्फ़िगर किया जा सकता है
- विश्लेषण उपकरण (GA, Clarity) केवल संबंधित ID कॉन्फ़िगर होने पर ही लोड होंगे, पृष्ठ प्रदर्शन प्रभावित नहीं होता
- `baseUrl` कॉन्फ़िगर न होने पर, sitemap.xml जनरेशन छोड़ दी जाएगी
