# GitHub Pages पर तैनात करें

यह मार्गदर्शन बताता है कि कैसे GitHub CLI के माध्यम से CZON द्वारा जनरेट की गई बहुभाषी स्टैटिक साइट को GitHub Pages पर तैनात किया जाए।

सबसे पहले [GitHub CLI](https://cli.github.com/) टूल इंस्टॉल करें (यदि पहले से इंस्टॉल नहीं है), और सुनिश्चित करें कि आप लॉग इन हैं (यदि अभी तक नहीं हैं):

```bash
$ gh --version # संस्करण देखें, सफल इंस्टॉलेशन सुनिश्चित करें
```

सुनिश्चित करें कि आप लॉग इन हैं, और लक्षित रिपॉजिटरी तक `repo` पहुँच की अनुमति है:

```bash
$ gh auth login -s repo # GitHub अकाउंट में लॉग इन करें, ब्राउज़र लॉगिन या टोकन का उपयोग करने का संकेत मिलेगा
$ gh auth status # लॉगिन स्थिति देखें, सुनिश्चित करें कि लॉगिन सफल हुआ है और लक्षित रिपॉजिटरी तक repo अनुमति है
```

बाकी सिर्फ नीचे दी गई कमांड चलाने और संकेतों का पालन करने की ज़रूरत है:

```bash
$ npx czon@latest config github
```

यह कमांड आपको निम्नलिखित चरणों के माध्यम से ले जाएगी:

1. gh की अनुमतियों की जाँच करें कि क्या उसमें repo शामिल है, यदि नहीं तो पुनः लॉगिन करने और repo अनुमति जोड़ने का संकेत दें।
2. यदि स्थानीय डायरेक्टरी Git रिपॉजिटरी नहीं है, तो एक नई Git रिपॉजिटरी इनिशियलाइज़ करने का संकेत दें।
3. स्थानीय डायरेक्टरी की रिमोट Git रिपॉजिटरी सेटिंग जाँचें, देखें कि क्या कोई GitHub रिमोट रिपॉजिटरी है। यदि कोई GitHub रिमोट रिपॉजिटरी नहीं है, तो एक नई रिमोट रिपॉजिटरी बनाने और उसे रिमोट origin के रूप में जोड़ने का संकेत दें। यदि origin पहले से मौजूद है लेकिन GitHub रिपॉजिटरी नहीं है, तो एक नई GitHub रिमोट रिपॉजिटरी को upstream के रूप में जोड़ने का संकेत दें।
4. जाँचें कि GitHub Pages सक्षम है या नहीं, और क्या यह workflow प्रकार का है। यदि नहीं, तो API `gh api` के माध्यम से इसे सक्षम करें और Actions से तैनाती के लिए सही करें। साथ ही CNAME सेट करें (यदि आपके पास कस्टम डोमेन है तो)।
5. GitHub Workflow फ़ाइल जाँचें। यदि नहीं बनी है, तो Pages Workflow फ़ाइल बनाएँ; यदि पहले से मौजूद है लेकिन नवीनतम संस्करण नहीं है, तो Workflow फ़ाइल अपडेट करने का संकेत दें।
6. Workflow फ़ाइल कमिट करें, और परिवर्तनों को रिमोट रिपॉजिटरी पर पुश करें।
7. GitHub Pages वेबसाइट के URL पर जाने का संकेत दें, gh api के माध्यम से नवीनतम Pages URL प्राप्त करें।
