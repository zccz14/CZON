# Embla कैरोसेल प्रभाव परीक्षण

यह Embla कैरोसेल प्रभावों का परीक्षण करने के लिए एक दस्तावेज़ है।

कई लगातार चित्रों को एक कैरोसेल के रूप में प्रदर्शित किया जाएगा, उपयोगकर्ता तीर पर क्लिक करके या चित्रों को खींचकर दृश्य बदल सकते हैं।
