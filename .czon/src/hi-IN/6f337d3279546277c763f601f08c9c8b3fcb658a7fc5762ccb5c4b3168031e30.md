# CZON - AI-Native Markdown कंटेंट इंजन

- **C**: **C**ontent oriented | कंटेंट केंद्रित, कंटेंट पर ध्यान
- **Z**: **Z**ero Configuration | ज़ीरो कॉन्फ़िगरेशन लेखन, व्यवधान कम करें
- **O**: **O**rganic AI-Native | ऑर्गेनिक AI-नेटिव, गहन AI एकीकरण
- **N**: **N**-shaped Energy Curve | N-आकार की ऊर्जा वक्र, क्रिएशन-वितरण-प्रतिक्रिया के सभी चरणों में हस्तक्षेप

[> वेबसाइट डेमो](https://czon.zccz14.com/)

AI युग में, वेबसाइट सामग्री रचनाकारों के रूप में, हमारे पास अधिक बुद्धिमान सामग्री निर्माण इंजन हो सकते हैं।

**सामग्री की ओर वापसी: न्यूनतम व्यवधान, लेखन पर ध्यान केंद्रित**

दस्तावेज़ों को उनके सार में वापस लाएं, लेखन को शांति में वापस लाएं।

पहला, मैं पुस्तकालयाध्यक्ष नहीं बनना चाहता। कभी-कभी मैं कुछ सामग्री लिखना चाहता हूं, लेकिन हो सकता है कि मैंने अभी तक इसका शीर्षक नहीं सोचा हो, या विशेष संगठन नहीं बनाया हो। मैं चाहता हूं कि LLM स्वचालित रूप से मेरे लिए शीर्षक उत्पन्न करे, सारांश बनाए, वर्गीकरण करे, नेविगेशन आदि व्यवस्थित कार्य करे।

दूसरा, मेरे अध्ययन कक्ष को साफ रखना चाहिए। मुझे जटिल कॉन्फ़िगरेशन वाले निर्माण उपकरण, जटिल दस्तावेज़ कॉन्फ़िगरेशन, या जटिल संरचनाएं नहीं चाहिए। हर बार जब मैं Docusaurus, VuePress, Astro जैसे उपकरणों के कॉन्फ़िगरेशन फ़ाइलों और प्रोजेक्ट संरचनाओं को देखता हूं, तो मेरा सिर दर्द करने लगता है। अब, CZON ने सभी कॉन्फ़िगरेशन को .czon डायरेक्टरी में छुपाने का विकल्प चुना है, कोने में साफ कर दिया है, उपयोगकर्ताओं को केवल लेखन सामग्री पर ध्यान केंद्रित करने की आवश्यकता है, बाकी सब CZON को संभालने दें। अन्य निर्देशिकाएं आपका लेखन स्थान हैं, आप अपनी Markdown फ़ाइलों को मनचाहे तरीके से व्यवस्थित कर सकते हैं।

**मातृभाषा की ओर वापसी: मातृभाषा में लिखें, बहुभाषी संस्करणों का सहज निर्माण**

जीवन छोटा है, मैं अनुवाद करने में आलसी हूं। जब व्यक्ति अपनी मातृभाषा का उपयोग करता है, तभी वह अपनी सोच की गहराई का पूरा उपयोग कर सकता है। लेकिन साथ ही दुनिया से जुड़े रहना भी आवश्यक है, मैं बहुभाषी संचार को छोड़ना नहीं चाहता। इसलिए मैं एक ऐसे उपकरण की कामना करता हूं जो मुझे मातृभाषा में लिखने दे, साथ ही मेरी सामग्री को अधिक लोगों तक पहुंचाए। वर्तमान i18n में न केवल स्वयं अनुवाद करना पड़ता है, बल्कि सामग्री अपडेट भी स्वयं बनाए रखना पड़ता है, यह बहुत परेशानी भरा है। मैं अनुवाद के लिए LLM का उपयोग करना चुनता हूं, जिससे मेरा बहुत समय बचता है, और एक क्लिक में कई देशों की भाषाओं में अनुवाद पूरा किया जा सकता है।

## मूलभूत सुविधाएं

1. 🌍 **स्वचालित बहुभाषी अनुवाद**: AI का उपयोग करके इंक्रीमेंटल अनुवाद, उपयोगकर्ता मातृभाषा में Markdown लिख सकते हैं, लेकिन उपयोगकर्ता बहुभाषी हो सकते हैं।
2. 💭 **स्वचालित सारांश निष्कर्षण**: AI का उपयोग करके मूल पाठ का कंटेंट विश्लेषण और निष्कर्षण।
3. 🏷️ **स्वचालित टैग वर्गीकरण**: AI का उपयोग करके कंटेंट का टैग और वर्गीकरण निष्कर्षण और प्रबंधन।
4. 🧭 **स्मार्ट वर्गीकरण नेविगेशन**: AI का उपयोग करके साइटमैप और नेविगेशन जनरेशन, स्रोत फ़ाइलों का स्थान संवेदनशील नहीं है।

## स्टैटिक साइट जनरेशन (SSG)

CZON में एक SSG समाधान अंतर्निहित है, जो Markdown युक्त किसी भी git फ़ोल्डर को एक स्टैटिक HTML साइट में बदल सकता है।

⚠️ कृपया ध्यान दें, CZON एक पेशेवर स्टैटिक साइट जनरेटर (SSG) नहीं है, बल्कि एक AI-संचालित Markdown कंटेंट इंजन है, जो कंटेंट क्रिएशन और प्रबंधन पर केंद्रित है।

✅ CZON का उद्देश्य कंटेंट क्रिएशन और प्रकाशन की प्रक्रिया को सरल बनाना है, ताकि उपयोगकर्ता लेखन पर ही ध्यान केंद्रित कर सकें, न कि जटिल कॉन्फ़िगरेशन और टूल्स से परेशान हों।

❌ CZON जटिल थीम कस्टमाइज़ेशन और प्लगइन इकोसिस्टम प्रदान नहीं करेगा, बल्कि AI के माध्यम से कंटेंट की गुणवत्ता और पहुंच को बढ़ाने पर केंद्रित रहेगा।

🔔 हालांकि, CZON अभी भी स्टैटिक साइट जनरेट कर सकता है, यदि आवश्यक हो तो CZON को प्रीप्रोसेसर के रूप में उपयोग किया जा सकता है, अन्य SSG समाधानों के साथ एकीकृत करके व्यक्तिगत, सुंदर साइटें जनरेट की जा सकती हैं।

## त्वरित प्रारंभ

पूर्वापेक्षाएं:

- [Node.js](https://nodejs.org/) स्थापित है (सुझाई गई संस्करण 18 और उससे ऊपर, npx कमांड की आवश्यकता है)
- [OpenAI API Key](https://platform.openai.com/account/api-keys) प्राप्त है, या OPENAI संगत API Key
- Git स्थापित है (Git से Markdown फ़ाइलों को सूचीबद्ध करने के लिए, .gitignore नियमों द्वारा फ़िल्टर की गई फ़ाइलों को अनदेखा करने के लिए)

सबसे पहले, एक ऐसे फ़ोल्डर में काम करें जो पहले से ही git द्वारा प्रबंधित है:

पर्यावरण चर कॉन्फ़िगर करें

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # आवश्यक: कृपया अपने OpenAI API Key से बदलें
export OPENAI_BASE_URL="https://api.openai.com/v1"  # वैकल्पिक, डिफ़ॉल्ट रूप से OpenAI आधिकारिक API का उपयोग करता है
export OPENAI_MODEL="gpt-3.5-turbo"  # वैकल्पिक, डिफ़ॉल्ट रूप से gpt-3.5-turbo मॉडल का उपयोग करता है
export OPENAI_MAX_TOKENS="4096"  # वैकल्पिक, अधिकतम टोकन संख्या सीमा सेट करें (अनदेखा करने पर मॉडल की डिफ़ॉल्ट मान का उपयोग करता है, लंबे पाठ अनुवाद के लिए उच्च मान सेट करने की सलाह दी जाती है, उदाहरण के लिए 8192, उपयोग किए जा रहे मॉडल द्वारा समर्थित अधिकतम टोकन संख्या पर निर्भर करता है)
```

साइट बनाएं, बहुभाषी अनुवाद का समर्थन करें। स्रोत डायरेक्टरी के रूप में वर्तमान डायरेक्टरी का उपयोग करें, `.czon/dist` डायरेक्टरी में आउटपुट करें।

- `--lang` पैरामीटर का कई बार उपयोग करके आवश्यक भाषा संस्करण निर्दिष्ट किए जा सकते हैं (उदाहरण के लिए `--lang hi-IN --lang en-US`)।
- स्रोत भाषा कॉन्फ़िगर करने की आवश्यकता नहीं है, CZON स्वचालित रूप से पता लगाएगा।

```bash
npx czon@latest build --lang hi-IN --lang en-US
```

**अधिक पैरामीटर या सहायता देखें**:

```bash
npx czon@latest
```
