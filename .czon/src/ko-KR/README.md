# CZON - AI 네이티브 Markdown 콘텐츠 엔진

- **C**: **C**ontent oriented | 콘텐츠 중심, 콘텐츠에 집중
- **Z**: **Z**ero Configuration | 제로 구성 글쓰기, 방해 최소화
- **O**: **O**rganic AI-Native | 유기적인 AI 네이티브, AI 깊이 통합
- **N**: **N**-shaped Energy Curve | N형 에너지 곡선, 제작-배포-피드백의 모든 단계에 개입

AI 시대에, 웹사이트 콘텐츠 크리에이터로서 우리는 더 지능적인 콘텐츠 제작 엔진을 가질 수 있습니다.

**콘텐츠로의 회귀: 방해 최소화, 글쓰기에 집중**

문서의 본질로 돌아가고, 글쓰기의 평온함으로 돌아갑니다.

첫째, 나는 도서관 사서가 되고 싶지 않습니다. 때로는 내용을 적고 싶지만, 아직 제목을 정하지 못했거나 특별한 체계를 잡지 못한 경우가 있습니다. LLM이 자동으로 제목을 생성하고, 요약을 만들고, 분류하고, 네비게이션 등의 정리 작업을 해주길 바랍니다.

둘째, 내 서재는 반드시 깨끗해야 합니다. 복잡한 구성 도구, 복잡한 문서 설정, 복잡한 구조를 다루고 싶지 않습니다. Docusaurus, VuePress, Astro 같은 도구들의 설정 파일과 프로젝트 구조를 볼 때마다 머리가 아픕니다. 이제 CZON은 모든 구성을 `.czon` 디렉토리 안에 숨겨 구석으로 치우기로 선택했습니다. 사용자는 글쓰기 콘텐츠에만 집중하면 되며, 나머지는 CZON이 처리합니다. 다른 디렉토리들은 여러분의 글쓰기 공간이며, Markdown 파일을 자유롭게 구성할 수 있습니다.

**모국어로의 회귀: 모국어로 글쓰기, 부드러운 다국어 버전 구축**

인생은 짧습니다. 나는 번역하기가 귀찮습니다. 사람은 모국어를 사용할 때 가장 깊이 생각할 수 있습니다. 하지만 동시에 세계와 연결을 유지하는 것도 필요하며, 다국어 소통을 포기하고 싶지 않습니다. 그래서 저는 모국어로 글을 쓰면서도 더 많은 사람들이 제 콘텐츠를 볼 수 있게 해주는 도구를 원했습니다. 현재의 i18n은 직접 번역해야 할 뿐만 아니라 콘텐츠 업데이트도 직접 관리해야 하니 너무 번거롭습니다. 저는 LLM을 사용하여 번역을 도와주도록 선택했고, 많은 시간을 절약하며 한 번의 클릭으로 여러 국가 언어 번역을 완료할 수 있습니다.

## ✨ 핵심 기능

1. 🌍 **AI 다국어 번역**: AI를 사용한 증분 번역으로 사용자가 모국어로 Markdown을 작성하지만, 사용자는 다국어가 될 수 있습니다.
2. 📊 **AI 메타데이터 추출**: 제목, 설명, 요약, 키워드, 대상 독자, URL 친화적 별칭 등을 자동으로 추출합니다.
3. 🏷️ **AI 태그 분류**: AI를 사용하여 콘텐츠의 태그와 분류를 추출하고 관리합니다.
4. 🧭 **AI 분류 네비게이션**: AI를 사용하여 사이트맵과 네비게이션을 생성하며, 소스 파일의 위치에 민감하지 않습니다.
5. 🤖 **AI 전체 사이트 요약**: 다양한 스타일로 전체 사이트 요약을 생성할 수 있습니다.

그리고 몇 가지 비 AI 기능:

1. ⚙️ **제로 구성**: 모든 구성과 캐시가 `.czon` 디렉토리에 숨겨져 프로젝트 구조를 깔끔하게 유지합니다.
2. 🔄 **증분 빌드**: 콘텐츠 해시 기반 변경 감지로 변경된 파일만 처리합니다.
3. 📚 **Markdown 확장 지원**: KaTeX 수식, Mermaid 차트, Embla 캐러셀, 각주 등을 기본 지원합니다.
4. 🚀 **정적 사이트 생성**: React 기반 SSG를 내장하여 다국어 정적 사이트를 생성합니다.
5. 🌐 **방문자 언어 기반 자동 라우팅**: 방문자의 언어에 따라 해당 언어 버전으로 자동 라우팅합니다.

## 📦 빠른 시작

### 필수 조건

- [Node.js](https://nodejs.org/) 설치됨 (LTS 버전 24 또는 버전 18 이상 권장, npx 명령어 필요)
- [OpenAI API Key](https://platform.openai.com/account/api-keys) 획득, 또는 OPENAI 호환 API Key
- Git 설치됨 (Git에서 Markdown 파일 목록을 가져오고, .gitignore 규칙으로 필터링된 파일을 무시하기 위해)

### 환경 변수 설정

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # 필수: 귀하의 OpenAI API Key로 교체하세요
export OPENAI_BASE_URL="https://api.openai.com/v1"  # 선택 사항, 기본값은 OpenAI 공식 API 사용
export OPENAI_MODEL="gpt-3.5-turbo"  # 선택 사항, 기본값은 gpt-3.5-turbo 모델 사용
export OPENAI_MAX_TOKENS="4096"  # 선택 사항, 최대 토큰 수 제한 설정 (생략 시 모델 기본값 사용, 긴 텍스트 번역의 경우 더 높은 값(예: 8192) 설정 권장, 사용 모델이 지원하는 최대 토큰 수에 따라 다름)

# OpenAI API 접근에 HTTP 프록시가 필요한 경우 다음 변수를 설정할 수 있습니다
export HTTPS_PROXY="http://your-proxy.com:8080"  # 선택 사항, HTTPS 프록시 설정
export HTTP_PROXY="http://your-proxy.com:8080"   # 선택 사항, HTTP 프록시 설정
```

### 다국어 사이트 빌드

Git으로 관리되는 임의의 폴더에서 실행:

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

언어 코드는 이후 정적 사이트 생성에서 여러 기능의 일부로 사용되므로 BCP 47 표준 언어 코드를 사용해야 합니다. 예를 들어, `zh-Hans`는 간체 중국어를, `en-US`는 미국 영어를 나타냅니다. 필요에 따라 더 많은 언어를 추가할 수 있습니다. 예: `es-ES` (스페인어) `ja-JP` (일본어), `ko-KR` (한국어) 등.
표준 언어 코드 목록은 [IETF language tag - Wikipedia](https://en.wikipedia.org/wiki/IETF_language_tag#List_of_common_primary_language_subtags)를 참조하세요.

출력 디렉토리: `.czon/dist`, 이후 이 디렉토리 아래의 내용을 정적 사이트 호스팅 플랫폼에 배포해야 합니다.

자세한 사용법은 `npx czon@latest --help`를 실행하세요.
