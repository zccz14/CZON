# 역사적 시간 범위 스타일 분석 보고서

## 읽기 포커스

각 파일을 읽을 때 다음을 중점적으로 추출하세요:

- 파일 경로와 제목
- **정확한 날짜** (최우선 순위)
- 사건 설명
- 이전/이후 사건과의 연관성
- 변화와 전환
- 버전 반복 정보
- 계획과 예상

**특별히 주목할 점**: 시간 표시, "이전/이후", "시작/종료", "전환/변화", 버전 번호 등의 어휘

## 지식 베이스 구조

```
### 파일 인덱스 (날짜순 정렬)
| 날짜 | 파일 경로 | 제목 | 주요 사건 |
|------|----------|------|----------|

### 타임라인 (핵심)
| 날짜 | 사건 | 유형 | 영향 | 출처 파일 |
|------|------|------|------|----------|
(유형: 프로젝트 시작, 버전 출시, 사상 전환, 외부 사건 등)

### 단계 구분
| 단계명 | 시작/종료 날짜 | 특징 | 핵심 파일 |
|--------|----------|------|----------|

### 전환점 인덱스
| 날짜 | 전환 설명 | 이전 상태 | 이후 상태 | 출처 파일 |
|------|----------|--------|--------|----------|

### 주제 진화 인덱스
| 주제 | 초기 상태 | 중기 상태 | 현재 상태 | 관련 파일 |
|------|----------|----------|----------|----------|
```

## 압축 전략

지식 베이스를 압축해야 할 때:

1. **반드시 유지**: 파일 인덱스(날짜 포함), 타임라인, 전환점 인덱스
2. **간소화 가능**: 단계 구분(유사 단계 병합), 주제 진화(주요 주제 유지)
3. **삭제 가능**: 부차적 사건의 상세 설명

## 스타일 포지셔닝

타임라인을 정리하고, 역사적 발전의 관점에서 내용의 변화를 바라보세요.

**목표 독자**: 발전 흐름을 이해하려는 독자, 연구자
**글의 어조**: 객관적, 깊이 있음, 통찰력 있음
**목적**: 독자가 내용의 역사적 배경과 발전 과정을 이해하도록 돕기

## 핵심 원칙

- ✅ 시간 순서에 따라 내용 구성
- ✅ 변화와 발전 추세 분석
- ✅ 핵심 전환점 식별
- ✅ 합리적인 미래 방향 추측
- ❌ 사실을 벗어난 추측 금지

## 필수 섹션 구조

### 개요

분석한 시간 범위와 주요 발견 사항을 간략히 소개

### 단계 구분

내용을 시간에 따라 여러 단계로 구분:

```markdown
## 제1단계: [단계명] (YYYY-MM-DD ~ YYYY-MM-DD)

### 단계 특징

[이 단계의 주요 특징 설명]

### 핵심 사건

| 날짜       | 사건                           | 의의               |
| ---------- | ------------------------------ | ------------------ |
| YYYY-MM-DD | [사건 설명](../path/to/file.md) | [후속 발전에 미친 영향] |

### 주요 산출물

- [산출물1](../path/to/file.md): [간략한 설명]
- [산출물2](../path/to/file.md): [간략한 설명]

### 사상/방법론의 변화

[이 단계의 사상/방법론 변화 분석]
```

### 핵심 전환점

중요한 전환점을 식별하고 분석:

```markdown
### 전환점 1: [전환점명]

**시간**: YYYY-MM-DD

**배경**: [전환이 발생한 배경]

**사건**: [구체적으로 무슨 일이 일어났는지]

**영향**: [후속 발전에 미친 영향]

**증거**: [관련 글](../path/to/file.md)
```

### 주제 진화

주요 주제가 시간에 따라 어떻게 진화했는지 추적:

```markdown
### [주제명]의 진화

**초기** (YYYY-MM): [초기 상태]
**중기** (YYYY-MM): [중기 변화]
**최근** (YYYY-MM): [현재 상태]

**진화 추세**: [추세 요약]
```

### 미래 궤적 예측

기존 내용을 바탕으로 합리적으로 미래 방향 추측:

```markdown
### 단기 예측 (1-3개월)

[증거](../path/to/file.md)를 바탕으로, 예상되는 것은...

### 중기 예측 (3-12개월)

[추세 분석]에 따르면, 가능성 있는 것은...

### 장기 전망

[전체 흐름]에서 볼 때...
```
