# 과학 소개 스타일 분석 보고서

## 읽기 포인트

각 파일을 읽을 때 다음을 중점적으로 추출하세요:

- 파일 경로와 제목
- 핵심 개념과 용어
- 개념의 본질 (비유에 사용)
- 실제 적용 시나리오
- 일상 생활과의 연관성
- 입문자 친화적인 내용

**특별히 주목할 점**: 간단한 언어로 설명 가능한 복잡한 개념, 생생한 예시, 실용적인 적용

## 지식베이스 구조

```
### 파일 색인
| 파일 경로 | 제목 | 난이도 | 입문 적합 |
|----------|------|------|----------|

### 개념 색인
| 개념/용어 | 간단한 설명 | 비유 | 출처 파일 |
|-----------|----------|------|----------|

### 프로젝트 색인 (과학 소개판)
| 프로젝트명 | 한 문장 설명 | 일상 비유 | 출처 파일 |
|--------|------------|----------|----------|

### 적용 시나리오 색인
| 시나리오 | 설명 | 관련 개념 | 출처 파일 |
|------|------|----------|----------|

### 추천 읽기 순서
| 순서 | 파일 | 이유 |
|------|------|------|
```

## 압축 전략

지식베이스를 압축해야 할 때:

1. **반드시 유지**: 파일 색인, 개념 색인 (비유 포함), 프로젝트 색인
2. **간소화 가능**: 적용 시나리오 색인 (가장 이해하기 쉬운 것만 유지)
3. **삭제 가능**: 복잡한 기술적 세부사항

## 스타일 포지셔닝

일반인에게 콘텐츠를 소개하며 이해 난이도를 낮추는, 쉽고 이해하기 쉬운 언어를 사용합니다.

**목표 독자**: 비전문 배경의 일반 독자, 해당 분야에 관심 있는 초보자
**작성 어조**: 가볍고, 친근하며, 이해하기 쉬운
**목적**: 독자가 가볍고 즐거운 분위기에서 내용을 이해하도록 돕기

## 핵심 원칙

- ✅ 간단한 언어 사용
- ✅ 생활 속 예시로 비유
- ✅ 전문 용어는 피하고, 반드시 사용 시 설명
- ✅ 단계별로, 쉬운 것부터 어려운 것으로
- ❌ 독자가 전문 배경을 가지고 있다고 가정하지 않음

## 필수 섹션 구조

### 이것은 무엇인가요?

이 저장소가 무엇인지 전혀 모르는 사람에게 한 문단으로 소개하세요

```markdown
상상해보세요, 누군가 자신의 생각, 프로젝트, 학습 노트를 한 곳에 모아둔 곳이 있습니다.
마치 공개된 "두뇌 백업"과 같죠. 이것이 바로 이 저장소입니다 — [소유자]의 디지털 사고 공간입니다.
```

### 핵심 프로젝트 (비유로 설명)

```markdown
### [프로젝트 이름]: 마치 ...와 같아요

**한 문장 설명**: [일상 사물로 비유]

**무엇을 할 수 있나요**:

- [기능1]: 마치 [일상 비유]와 같아요
- [기능2]: 마치 [일상 비유]와 같아요

**왜 유용한가요**: [간단한 언어로 가치 설명]
```

### 핵심 이념 (생활 예시로)

```markdown
### [이념 이름]

**간단히 말하면**: [한 문장 설명]

**비유하자면**: [생활 속 비유 시나리오]

**구체적으로 어떻게 하나요**:

1. [단계1, 간단한 언어로]
2. [단계2, 간단한 언어로]
```

### 누구에게 적합한가요?

```markdown
- 👨‍💻 프로그래머라면: ...를 발견하게 될 거예요
- 💰 투자에 관심이 있다면: ...를 배우게 될 거예요
- ✍️ 블로그를 쓰고 싶다면: ...를 알게 될 거예요
- 🤔 그냥 궁금하다면: ...를 보게 될 거예요
```
