# CZON - Công cụ Tạo Nội Dung Markdown Bản Địa AI

- **C**: **C**ontent oriented | Nội dung là vua, tập trung vào nội dung
- **Z**: **Z**ero Configuration | Viết không cần cấu hình, giảm phiền nhiễu
- **O**: **O**rganic AI-Native | Bản địa AI hữu cơ, tích hợp sâu AI
- **N**: **N**-shaped Energy Curve | Đường cong năng lượng hình chữ N, can thiệp vào mọi khâu sáng tạo - phân phối - phản hồi

Trong thời đại AI, với tư cách là người sáng tạo nội dung trang web, chúng ta có thể có một công cụ sáng tạo nội dung thông minh hơn.

**Trở về với nội dung: Tối thiểu hóa phiền nhiễu, tập trung viết lách**

Hãy để tài liệu trở về bản chất, để việc viết lách trở nên yên tĩnh.

Thứ nhất, tôi không muốn làm thủ thư. Đôi khi tôi muốn viết ra một số nội dung, nhưng có thể tôi chưa nghĩ ra tiêu đề cho nó, chưa hình thành tổ chức đặc biệt. Tôi hy vọng LLM sẽ tự động giúp tôi tạo tiêu đề, tóm tắt, phân loại, điều hướng và các công việc sắp xếp khác.

Thứ hai, phòng sách của tôi phải được dọn dẹp sạch sẽ. Tôi không muốn các công cụ xây dựng cấu hình phức tạp, mất công với cấu hình tài liệu phức tạp, không thích cấu trúc phức tạp. Mỗi lần nhìn thấy tệp cấu hình và cấu trúc dự án của các công cụ như Docusaurus, VuePress, Astro, tôi lại đau đầu. Bây giờ, CZON chọn cách ẩn tất cả cấu hình vào thư mục `.czon`, quét vào góc, người dùng chỉ cần tập trung vào việc viết nội dung, phần còn lại để CZON xử lý. Các thư mục khác là không gian viết của bạn, bạn có thể tổ chức các tệp Markdown của mình tùy ý.

**Trở về với tiếng mẹ đẻ: Viết bằng tiếng mẹ đẻ, xây dựng phiên bản đa ngôn ngữ mượt mà**

Đời người ngắn ngủi, tôi lười dịch. Khi sử dụng tiếng mẹ đẻ, con người mới có thể phát huy tối đa chiều sâu tư duy của mình. Nhưng đồng thời việc giữ kết nối với thế giới là cần thiết, tôi không muốn từ bỏ giao tiếp đa ngôn ngữ. Vì vậy, tôi hy vọng có một công cụ cho phép tôi viết bằng tiếng mẹ đẻ, đồng thời để nhiều người hơn thấy được nội dung của tôi. Hiện tại, i18n không chỉ cần tự dịch mà còn phải tự duy trì cập nhật nội dung, quá phiền phức. Tôi chọn sử dụng LLM để giúp tôi dịch, tiết kiệm rất nhiều thời gian và có thể hoàn thành dịch đa ngôn ngữ chỉ với một cú nhấp chuột.

## ✨ Tính năng chính

1. 🌍 **Dịch đa ngôn ngữ bằng AI**: Sử dụng AI để dịch tăng dần, cho phép người dùng viết Markdown bằng tiếng mẹ đẻ, nhưng người dùng có thể là đa ngôn ngữ.
2. 📊 **Trích xuất siêu dữ liệu bằng AI**: Tự động trích xuất tiêu đề, mô tả, tóm tắt, từ khóa, đối tượng độc giả, bí danh thân thiện với URL, v.v.
3. 🏷️ **Phân loại thẻ bằng AI**: Sử dụng AI để trích xuất và quản lý thẻ và phân loại nội dung.
4. 🧭 **Điều hướng phân loại bằng AI**: Sử dụng AI để tạo sơ đồ trang web và điều hướng, vị trí tệp nguồn không nhạy cảm.
5. 🤖 **Tóm tắt toàn trang bằng AI**: Có thể tạo tóm tắt toàn trang với nhiều phong cách khác nhau.

Và một số tính năng không phải AI:

1. ⚙️ **Không cần cấu hình**: Tất cả cấu hình và bộ nhớ đệm được ẩn trong thư mục `.czon`, cấu trúc dự án luôn gọn gàng.
2. 🔄 **Xây dựng tăng dần**: Phát hiện thay đổi dựa trên mã băm nội dung, chỉ xử lý các tệp thay đổi.
3. 📚 **Hỗ trợ mở rộng Markdown**: Hỗ trợ gốc công thức toán học KaTeX, biểu đồ Mermaid, băng chuyền ảnh Embla, chú thích cuối trang, v.v.
4. 🚀 **Tạo trang web tĩnh**: SSG dựa trên React tích hợp sẵn, tạo trang web tĩnh đa ngôn ngữ.
5. 🌐 **Tự động định tuyến theo ngôn ngữ của người truy cập**: Tự động định tuyến đến phiên bản ngôn ngữ tương ứng dựa trên ngôn ngữ của người truy cập.

## 📦 Bắt đầu nhanh

### Điều kiện tiên quyết

- Đã cài đặt [Node.js](https://nodejs.org/) (khuyến nghị sử dụng phiên bản LTS 24, hoặc phiên bản 18 trở lên, cần có lệnh npx)
- Đã lấy [OpenAI API Key](https://platform.openai.com/account/api-keys), hoặc API Key tương thích OPENAI
- Đã cài đặt Git (để liệt kê tệp Markdown từ Git, bỏ qua các tệp bị lọc bởi quy tắc .gitignore)

### Cấu hình biến môi trường

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Bắt buộc: Vui lòng thay thế bằng OpenAI API Key của bạn
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Tùy chọn, mặc định sử dụng API chính thức của OpenAI
export OPENAI_MODEL="gpt-3.5-turbo"  # Tùy chọn, mặc định sử dụng mô hình gpt-3.5-turbo
export OPENAI_MAX_TOKENS="4096"  # Tùy chọn, đặt giới hạn số lượng token tối đa (bỏ qua sẽ sử dụng giá trị mặc định của mô hình, đối với dịch văn bản dài khuyến nghị đặt giá trị cao hơn, ví dụ 8192, tùy thuộc vào số lượng token tối đa mà mô hình sử dụng hỗ trợ)

# Nếu cần sử dụng proxy HTTP để truy cập OpenAI API, có thể đặt các biến sau
export HTTPS_PROXY="http://your-proxy.com:8080"  # Tùy chọn, đặt proxy HTTPS
export HTTP_PROXY="http://your-proxy.com:8080"   # Tùy chọn, đặt proxy HTTP
```

### Xây dựng trang web đa ngôn ngữ

Chạy trong bất kỳ thư mục nào được quản lý bởi Git:

```bash
npx czon@latest build --lang zh-Hans --lang en-US
```

Vì mã ngôn ngữ sau này sẽ được sử dụng trong nhiều tính năng của quá trình tạo trang web tĩnh, vui lòng đảm bảo sử dụng mã ngôn ngữ chuẩn BCP 47. Ví dụ, `zh-Hans` đại diện cho tiếng Trung giản thể, `en-US` đại diện cho tiếng Anh Mỹ. Bạn có thể thêm nhiều ngôn ngữ hơn nếu cần, ví dụ `es-ES` (tiếng Tây Ban Nha), `ja-JP` (tiếng Nhật), `ko-KR` (tiếng Hàn), v.v.
Danh sách mã ngôn ngữ chuẩn vui lòng tham khảo [IETF language tag - Wikipedia](https://en.wikipedia.org/wiki/IETF_language_tag#List_of_common_primary_language_subtags).

Thư mục đầu ra: `.czon/dist`, sau này cần triển khai nội dung trong thư mục này lên nền tảng lưu trữ trang web tĩnh.

Để biết cách sử dụng chi tiết, vui lòng chạy `npx czon@latest --help`.
