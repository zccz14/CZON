# CZON - AI-Nativ Markdown-innehållsmotor

- **C**: **C**ontent oriented | Innehåll är kung, fokus på innehåll
- **Z**: **Z**ero Configuration | Nollkonfigurationsskrivande, minskar störningar
- **O**: **O**rganic AI-Native | Organisk AI-nativ, djupintegrerad AI
- **N**: **N**-shaped Energy Curve | N-formad energikurva, involverar skapande-distribution-feedback i alla länkar

[> Webbplatsdemo](https://czon.zccz14.com/)

I AI-eran kan vi som webbplatsinnehållsskapare ha en smartare innehållsskaparmotor.

**Återgå till innehåll: Minimera störningar, fokusera på skrivande**

Låt dokument återgå till sin essens, låt skrivande återgå till lugn.

För det första vill jag inte vara bibliotekarie. Ibland vill jag skriva ner något innehåll, men jag kanske inte har tänkt ut dess rubrik ännu, eller format en särskild organisation. Jag vill att LLM automatiskt ska hjälpa mig att generera rubriker, göra sammanfattningar, klassificera, navigera och andra organisatoriska uppgifter.

För det andra måste mitt arbetsrum vara rent. Jag vill inte ha komplexa byggverktyg, krångla med komplicerade dokumentkonfigurationer, ogillar komplexa strukturer. Varje gång jag ser konfigurationsfiler och projektstrukturer för verktyg som Docusaurus, VuePress, Astro får jag huvudvärk. Nu väljer CZON att dölja all konfiguration i .czon-katalogen, sopa undan i ett hörn, så att användaren bara behöver fokusera på att skriva innehåll, resten lämnas till CZON att hantera. Alla andra kataloger är ditt skrivutrymme, du kan organisera dina Markdown-filer fritt.

**Återgå till modersmål: Skriv på modersmål, smidig byggning av flerspråkiga versioner**

Livet är kort, jag är för lat för att översätta. Människor uttrycker sina tankar bäst på sitt modersmål. Men samtidigt är det nödvändigt att hålla kontakt med världen, jag vill inte ge upp flerspråkig kommunikation. Därför hoppas jag att det finns ett verktyg som låter mig skriva på mitt modersmål, samtidigt som fler kan se mitt innehåll. Nuvarande i18n kräver inte bara att man översätter själv, utan också att man underhåller innehållsuppdateringar, för besvärligt. Jag väljer att använda LLM för att hjälpa mig med översättning, sparar mycket tid och kan slutföra flerspråkig översättning med ett klick.

## Grundläggande funktioner

1. 🌍 **Automatisk flerspråkig översättning**: Använder AI för inkrementell översättning, låter användare skriva Markdown på modersmål, men användare kan vara flerspråkiga.
2. 💭 **Automatisk sammanfattningsextraktion**: Använder AI för innehållsanalys och extrahering av originaltext.
3. 🏷️ **Automatisk taggklassificering**: Använder AI för att extrahera och hantera taggar och kategorier för innehåll.
4. 🧭 **Intelligent kategorinavigering**: Använder AI för att generera webbplatsskarta och navigering, känslig för källfilens position.

## Statisk webbplatsgenerering (SSG)

CZON har en inbyggd SSG-lösning som kan bygga vilken git-mapp som helst som innehåller Markdown till en statisk HTML-webbplats.

⚠️ Observera att CZON inte är en professionell statisk webbplatsgenerator (SSG), utan en AI-driven Markdown-innehållsmotor som fokuserar på innehållsskapande och hantering.

✅ CZON syftar till att förenkla processen för innehållsskapande och publicering, så att användare kan fokusera på själva skrivandet, istället för att störas av komplex konfiguration och verktyg.

❌ CZON kommer inte att erbjuda komplex temaanpassning och plugin-ekosystem, utan fokuserar på att förbättra innehållets kvalitet och tillgänglighet genom AI.

🔔 Men CZON kan fortfarande generera statiska webbplatser, om nödvändigt kan CZON användas som förprocessor, integrerad med andra SSG-lösningar för att generera personliga, vackra webbplatser.

## Snabbstart

Förutsättningar:

- [Node.js](https://nodejs.org/) installerad (rekommenderad version 18 eller högre, behöver npx-kommando)
- Har fått [OpenAI API-nyckel](https://platform.openai.com/account/api-keys), eller OPENAI-kompatibel API-nyckel
- Git installerat (används för att lista Markdown-filer från Git, ignorerar filer som filtreras av .gitignore-regler)

Först, arbeta i en mapp som redan hanteras av git:

Konfigurera miljövariabler

```bash
export OPENAI_API_KEY="sk-xxxxxx"  # Obligatoriskt: ersätt med din OpenAI API-nyckel
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Valfritt, använder officiell OpenAI API som standard
export OPENAI_MODEL="gpt-3.5-turbo"  # Valfritt, använder gpt-3.5-turbo-modellen som standard
export OPENAI_MAX_TOKENS="4096"  # Valfritt, ställ in max token-gräns (ignorera för att använda modellens standardvärde, för lång textöversättning rekommenderas högre värde, t.ex. 8192, beroende på modellens max token-stöd)
```

Bygg webbplats, stöder flerspråkig översättning. Använd aktuell katalog som källkatalog, skicka ut till `.czon/dist`-katalogen.

- Kan ange språkversioner som behöver genereras genom att använda `--lang`-parametern flera gånger (t.ex. `--lang sv-SE --lang en-US`).
- Ingen källspråkskonfiguration behövs, CZON upptäcker automatiskt.

```bash
npx czon@latest build --lang sv-SE --lang en-US
```

**Visa fler parametrar eller hjälp**:

```bash
npx czon@latest
```
